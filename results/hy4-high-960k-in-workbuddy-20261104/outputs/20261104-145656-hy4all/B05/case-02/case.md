# case-02 · 此刻的城市 · 实时积水地图首页

- **受众**：临江市通勤者林岚，17:46 下班前查看全城积水
- **使用场景 / 目标观看环境**：760×1520 竖屏手机 App 首页，单手握持、户外强光下快速扫视
- **用户目标**：一眼看清全城哪些路段积水、自己附近风险如何
- **内容范围**：虚构演示：6 个监测点水位与风险分级，数值与 case-03/08 一致
- **视觉选择**：全屏深色地图 + 彩色风险热力晕 + 毛玻璃底部浮层，营造「实时态势」沉浸感
- **本画面承担的需求 / 状态**：态势感知：打开 App 后第一屏，理解「现在城市怎么样」
- **DSL 能力**：LINEAR 渐变、c.line 街道网格、ClipPath C 曲线河道、Opacity 热力晕、ClipRRect+ImageFiltered 毛玻璃浮层、chip、圆角卡片
- **尺寸**：760×1520
- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材；本题 asset_policy 允许辅助素材，但本作品未使用。
- **完成标准**：见 `plan.json`（B05-plan-v1）与 `portfolio.json` 的 `completion_criteria`，逐条结果见 `criterion_results`。
- **虚构声明**：虚构演示数据 / fictional demo content
