# B05 作品集 · 泊 / ANCHOR

策展逻辑：用一条可信的暴雨使用旅程组织 10 件**独立完整**的静态画面，
而不是同一个界面模板换文案。每件有不同的受众、设备、状态、决策与结果，
并刻意更换画布尺寸、配色系统与信息结构。

## 逐件用途

### 01 · 水位之上 · 品牌概念主视觉

- 受众：第一次听说「泊」的临江市民、应用商店访客、社区宣传栏读者
- 使用场景：1200×1200 方形海报，手机应用商店头图 / 社区公告栏 / 发布会主视觉
- 用户目标：在几秒内理解「泊」是做什么的、为什么暴雨天需要它
- 视觉主张：以同心水位环 + 城市天际线 + 贯穿的水位线建立原创视觉隐喻；中央仪表盘给出可信数据锚点
- 文件：`case-01/final.png` / `case-01/final.snapshot` / `case-01/case.md`

### 02 · 此刻的城市 · 实时积水地图首页

- 受众：临江市通勤者林岚，17:46 下班前查看全城积水
- 使用场景：760×1520 竖屏手机 App 首页，单手握持、户外强光下快速扫视
- 用户目标：一眼看清全城哪些路段积水、自己附近风险如何
- 视觉主张：全屏深色地图 + 彩色风险热力晕 + 毛玻璃底部浮层，营造「实时态势」沉浸感
- 文件：`case-02/final.png` / `case-02/final.snapshot` / `case-02/case.md`

### 03 · 三条路，怎么走 · 出门决策卡

- 受众：准备从公司回家的通勤者林岚
- 使用场景：760×1460 竖屏手机，室内/地铁口短暂停留时做一次决策
- 用户目标：在 3 条路线中选出安全可通行的一条并直接开始导航
- 视觉主张：浅色卡片对比清单，用等宽三列指标并列比较，推荐项用绿色描边与角标突出，底部深色结论条收束决策
- 文件：`case-03/final.png` / `case-03/final.snapshot` / `case-03/case.md`

### 04 · 前方 300 米 · 45 厘米 · 途中预警

- 受众：正走在回家路上的林岚，手机锁屏 / 通知横幅
- 使用场景：700×1400 竖屏极简锁屏通知，雨中单手、强光、只有 2 秒注意力
- 用户目标：立刻知道前方路不能走，并一键改道
- 视觉主张：整屏橙红渐变 + 一个 220px 的巨大数字 + 一条水位标尺，把信息压缩到单一焦点与单一动作
- 文件：`case-04/final.png` / `case-04/final.snapshot` / `case-04/case.md`

### 05 · 接单前的风险叠加 · 骑手横屏视图

- 受众：外卖骑手周骁，电动车支架上的横屏设备
- 使用场景：1440×900 横屏车载/支架，骑行中高震动、强光、需高对比一眼可读
- 用户目标：接单前判断哪些订单会被积水阻断、什么时候再接更安全
- 视觉主张：黑底 + 琥珀黄与荧光绿高对比；左地图右分栏，风险时间窗用红/绿横向色带表达
- 文件：`case-05/final.png` / `case-05/final.snapshot` / `case-05/case.md`

### 06 · 把水位告诉邻居 · 众包上报表单

- 受众：在梧桐里东门、愿意花 30 秒上报积水的市民林岚
- 使用场景：800×1500 竖屏手机表单，雨中站立、单手操作、屏幕有水渍
- 用户目标：把看到的水深准确报给系统，让邻居的路线建议更可靠
- 视觉主张：米白纸质 + 深蓝取景框，把「拍照 + 标尺」做成一张像表格一样好填的卡片；蓝色大标尺是核心控件
- 文件：`case-06/final.png` / `case-06/final.snapshot` / `case-06/case.md`

### 07 · 哪里能进去避一避 · 避险点列表

- 受众：雨势加大、需要临时避险的林岚与附近居民
- 使用场景：780×1480 竖屏手机列表，雨中边走边看、需要快速判断「哪个还进得去」
- 用户目标：找到最近、还开放、有位置的避险点并知道怎么走
- 视觉主张：浅青绿底色 + 方位缩略环 + 容量进度条；把「开放/满员」和「还有多少位置」做成一眼可判的视觉信号
- 文件：`case-07/final.png` / `case-07/final.snapshot` / `case-07/case.md`

### 08 · 梧桐里辖区监测 · 物业值班大屏

- 受众：临江街道梧桐里物业站值班人员
- 使用场景：1600×1000 横屏值班室大屏，3 米外观看，需同屏显示多源信息
- 用户目标：同时掌握 6 个监测点水位、处置状态与最新流水，及时封控危险点
- 视觉主张：深海军蓝密集信息驾驶舱：KPI 行 + 排序柱图 + 分级表 + 处置时间线，30cm 警戒虚线贯穿主图
- 文件：`case-08/final.png` / `case-08/final.snapshot` / `case-08/case.md`

### 09 · 妈，我改走东门了 · 家庭平安屏

- 受众：在家等待的母亲林秀芳（68 岁）与孩子陈小满
- 使用场景：1200×900 家中智能屏 / 冰箱贴横屏，客厅远距离、暖光环境观看
- 用户目标：不用打电话就知道家人是否平安、何时到家，并能一键回应
- 视觉主张：暖米色 + 橙棕的柔和情感化界面；大圆形肖像 + 竖时间轴 + 一个大号「回个平安」按钮，字号与点击区都为长者放大
- 文件：`case-09/final.png` / `case-09/final.snapshot` / `case-09/case.md`

### 10 · 这场雨，我们一起记下 · 雨后复盘

- 受众：雨后第二天回看自己贡献的市民林岚与社区
- 使用场景：1200×1200 方形数据海报，App 内分享页 / 社区公告 / 社交分享
- 用户目标：理解自己上报的价值、这次预警的效果，以及下次会怎样更好
- 视觉主张：清爽白底数据海报收尾：4 个大数字 + 采纳率环形 + 雨量/水位双曲线 + 深色结论条，把「结果」讲清楚
- 文件：`case-10/final.png` / `case-10/final.snapshot` / `case-10/case.md`
