# case-01 · 水位之上 · 品牌概念主视觉

- **受众**：第一次听说「泊」的临江市民、应用商店访客、社区宣传栏读者
- **使用场景 / 目标观看环境**：1200×1200 方形海报，手机应用商店头图 / 社区公告栏 / 发布会主视觉
- **用户目标**：在几秒内理解「泊」是做什么的、为什么暴雨天需要它

- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材；本题 asset_policy 允许辅助素材，但本作品未使用。
