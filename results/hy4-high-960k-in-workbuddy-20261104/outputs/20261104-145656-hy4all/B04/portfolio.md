# B04 · 八颗行星 · 尺度的读本 — 策展说明

本特辑自选真实主题「太阳系八大行星的尺度差异」，亲自研究 NASA 三个页面，把可核查的数值编辑成十件连贯的视觉作品。每件信息结构不同，合起来是一条从「为什么画不准」到「逐项核查」的阅读路线。

## 资料基础

- S1 NASA NSSDCA《Planetary Fact Sheet – Metric》（更新 2025-03-18）
- S2 《Planetary Fact Sheet Notes》（字段定义，更新 2021-12-20）
- S3 NASA《About the Planets》（分类与八颗行星清单）

逐条主张、定位、数据集与不确定项见 `sources.json`；编辑思路见 `editorial-note.md`。所有数值直接取自 S1，未改动；倍数、AU、地球年、对数映射与求和为标注过的编辑计算。

## 各作品用途

- **case-01 八颗行星 · 尺度的读本（封面/导览）**：特辑首页 / 展览导览屏 / 在线专题封面。受众对天文感兴趣的普通读者与科普展览观众；希望完成：理解本特辑要回答的问题与十章阅读路线。以太阳光晕与轨道弧建立宇宙语境，右侧标题与十章目录给出编辑路线
- **case-02 大小 · 真实直径比例**：科普读物跨页 / 课堂投影。受众中学以上科普读者与教师；希望完成：读出八颗行星直径的真实相对大小。八条共用同一线性比例的横条，让 29 倍差距一目了然
- **case-03 距离 · 线性与对数**：科普读物 / 数据可视化教学。受众科普读者与信息图设计学习者；希望完成：理解为何常见等距示意图会误导，并读出真实距日距离与 AU。上下两条刻度轴对照，线性轴上内四颗重叠、对数轴上均匀展开
- **case-04 一年 · 公转周期**：科普读物 / 展板。受众科普读者；希望完成：读出公转周期从 88 天到 59,800 天并换算地球年。对数条让 680 倍跨度同屏可读，右侧给出天数与年数双标注
- **case-05 一天 · 自转、逆行与昼夜**：科普读物 / 展板。受众科普读者与天文爱好者；希望完成：区分恒星自转周期与太阳日，识别逆行行星。双列对照表 + 逆行红色标注，把两个易混淆的时间概念分开
- **case-06 引力与密度 · 两个家族**：科普读物 / 课堂。受众科普读者；希望完成：看出内行星与外行星在密度上的系统性差异。两组共用刻度的并列条，暖/冷色区分家族
- **case-07 温度 · 从 +464°C 到 −200°C**：科普读物 / 展板。受众科普读者；希望完成：读出平均温度排序并理解「平均值不代表局部」。连续热力色带 + 引导线标签卡，突出金星最热而非水星
- **case-08 卫星与环 · 数量极不平均**：科普读物 / 展板。受众科普读者；希望完成：读出卫星数、环系统与磁场的分布差异。同一线性刻度的卫星条 + 环/磁场图标，突出 3 颗 vs 413 颗
- **case-09 分类 · 内与外**：科普读物 / 教学。受众科普读者与教师；希望完成：理解内行星/外行星的分类依据与两个来源的口径差异。双栏家族卡 + 五维交叉对照表，明确标注来源观点与编辑归纳
- **case-10 数据总表与来源**：特辑末页 / 可打印数据表。受众需要核查数值的读者、教师与评审；希望完成：核查全部数值、单位、口径与来源。浅底密集表格便于逐行核查，附口径、来源与不确定项

封面行星圆点为示意大小（已标注），其余九件不使用演示数据；四颗巨行星表面气压在来源中为 Unknown，未收录、未估算。
