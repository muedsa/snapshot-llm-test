# case-02 · 3 号投放点导视立牌

- **项目**：城市沃土 URBAN LOAM · 社区堆肥与屋顶菜园（自拟演示项目）
- **触点 / 媒介**：巷道口竖立式导视牌
- **受众**：提着厨余袋寻找投放点的居民
- **观看环境**：狭窄长条形立牌，2–5 米行走中扫视
- **使用者要完成的事**：确认投放点编号、方向与开放时间
- **内容来源**：自拟品牌、人物、点位、数值与活动，均为虚构演示，不宣称真实部署
- **视觉选择**：深绿信息头 + 巨大点位编号「03」 + DSL 箭头 + 四条信息卡
- **实际使用的 DSL 能力**：LINEAR 渐变、ClipPath 箭头(line+arrow_head)、sprout 徽标、信息卡、brand_footer
- **画布尺寸**：700 × 1500 px
- **复用设计系统**：`loam.py`（色板、字体、sprout 徽标、brand_header/brand_footer、chip/tag/card、soil_dots）
  —— 本件按自身密度与比例复用其中组件，验证不同媒介下的一致性。
- **辅助素材**：无。全部主体由 Snapshot DSL 构造，未使用外部图片；点阵码/条码为装饰性示意。
- **计划版本**：plan-v1（首次渲染前建立，见 `tmp/20261104-145656-hy4all/B02/plan.md`）。
