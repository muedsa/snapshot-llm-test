# B02 作品集策展说明 · 城市沃土 URBAN LOAM

**一个项目，十个触点。**「城市沃土」是一个把社区厨余就地堆肥、再用于屋顶菜园的自拟社区项目。本作品集不是十张不同颜色的海报，而是把同一个视觉系统放进用户真正会遇见它的十个地方：从第一次听说、找到投放点、判断能不能投、成为志愿者、日常用 App、看月度成效、参加工作坊、兑换蔬菜、查地图，到把种子带回家。

| 触点 | 作品 | 受众 / 使用任务 | 最有辨识度的视觉选择 |
|---|---|---|---|
| case-01 | 第 3 期志愿者招募主视觉海报 | 尚未参与的社区居民 / 被吸引并知道如何报名成为志愿者 | 超大衬线标语 + 巨型 sprout 徽标 + 三步参与 + 深绿 CTA 招募带 |
| case-02 | 3 号投放点导视立牌 | 提着厨余袋寻找投放点的居民 / 确认投放点编号、方向与开放时间 | 深绿信息头 + 巨大点位编号「03」 + DSL 箭头 + 四条信息卡 |
| case-03 | 厨余分类指南卡 | 正要打开堆肥箱的居民 / 3 秒内判断手里的东西能不能投 | 绿/陶土双栏对照 + 勾选/叉号 DSL 图标 + 12 条示例 |
| case-04 | 志愿者会员卡 | 已注册的社区志愿者 / 出示身份、查看积分与等级 | 深绿渐变卡面 + 大字号持卡人 + 三格统计 + 条码 + 旋转全息角标 |
| case-05 | App 首页界面 | 日常使用 App 的注册居民 / 查看积分进度并快速记录投放或报名 | 圆角屏幕容器 + 积分主卡与 arc 进度环 + 三格本周概览 + 双快捷按钮 + 动态列表 + 底部标签栏 |
| case-06 | 十月影响力数据简报 | 项目资助方、社区管委会与居民 / 了解当月回收量、堆肥去向与减碳成效 | 四 KPI 卡 + 零起点月度柱图 + 环形堆肥去向图 + 深绿结论带 |
| case-07 | 周六工作坊日程表 | 已报名或考虑报名工作坊的居民 / 知道每个时段做什么、谁带、在哪 | 日期徽章 + 三格概要 + 纵向时间轴四场会话 + 主讲人胶囊 |
| case-08 | 收获兑换券 | 用积分兑换蔬菜的居民 / 核验权益并在有效期内兑换 | 深绿 SVG 凹口票券 + 虚线撕口 + 点阵码/条码 + 面额胶囊 |
| case-09 | 社区投放点地图 | 想找最近投放点的新居民 / 定位 6 个投放点并理解推荐步行路线 | 参数化街道网格 + 波浪河道 + 推荐路线 + 6 个编号节点 + 图例侧栏 |
| case-10 | 种子包标签 | 领取种子回家播种的居民 / 知道品种、播种深度、间距与收获期 | 森林绿顶带 + 手绘式植株插画(叶/茎/果实) + 2×2 参数格 + 批次条码 |

## 统一与差异

- **统一**：森林绿 / 叶绿 / 陶土 / 奶油 / 琥珀色板；Noto Sans CJK SC + Inter + Noto Serif CJK SC 字体层级；由两片叶与种子构成的 sprout 徽标；品牌页眉与页脚；胶囊标签、卡片与土壤点阵底纹。
- **差异**：十种媒介形制、十种尺寸（720×1400 到 1600×1000）、十种信息结构（标语 / 编号导视 / 双栏对照 / 身份卡 / 仪表盘 / 时间轴 / 票券 / 地图 / 标签）。
- **复用组件压力测试**：sprout 徽标在 52px（App）到 236px（海报）之间复用；brand_header 在 1200–1600px 横版与 640px 小标签上分别验证；arc 进度环在 63% 积分环与堆肥去向环形图两种密度下复用。

逐件场景、DSL 能力、完成标准与真实看图证据见 `portfolio.json` 与 `case-*/case.md`；项目问题见 `project-brief.md`，系统规则见 `design-system.json`，触点情境映射见 `touchpoint-map.json`；逐图预览见 `gallery.md`。
