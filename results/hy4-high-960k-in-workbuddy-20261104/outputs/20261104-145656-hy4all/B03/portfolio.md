# B03 · 用十件作品探索 DSL 的创意边界 — 策展说明

本套十件作品均为真实使用场景下的完整成品，而非能力示范板。每件先确定受众、使用环境与要完成的事，再选择一种已在本服务验证成立的手法作为结构核心；手法服务于信息，不遮盖内容。

策展线索：从「氛围与叙事」（01）到「分类与谱系」（02、09），经「监测与测量」（03、05、07），到「空间与地形」（04、08），再到「身份与生成」（06、10）——逐件更换媒介、构图、配色与信息结构。

## 各作品用途

- **case-01 潮汐 · 当代艺术展海报**：展馆入口竖版印刷海报 / 手机竖屏推送。受众美术馆观众与社交媒体浏览者；希望完成：快速识别展名、档期、地点并被氛围吸引到馆。以模糊月晕与多层贝塞尔波浪构成潮汐节律，标题压在浪上形成纵深
- **case-02 ORIGIN · 杯测风味轮**：吧台挂图 / 培训手册单页 / 平板。受众精品咖啡店杯测培训学员与吧台工作人员；希望完成：按色相定位风味主类目并核对该类子风味。以扫描渐变色轮承载八大类目，极坐标排布标签，中心留出品读说明
- **case-03 城市心跳 · 地铁客流看板**：控制中心大屏 / 站台信息屏。受众地铁运营控制中心调度员与站台乘客；希望完成：读出全天客流曲线、峰值与重点站拥挤度并据此调度。渐变填充的面积图表达客流起伏，右侧站点条与状态点承担决策信息
- **case-04 等高线 · 云脊徒步路线卡**：参赛手册插页 / 路书卡片 / 离线打印。受众户外徒步者与越野赛参赛者；希望完成：读出路线、爬升、海拔与检查点位置并规划行程。12 圈程序化平滑闭合等高线构成地形，虚线路线与 CP 点叠加其上
- **case-05 光谱 · 摄影色温速查卡**：灯光间墙面速查卡 / 平板对照卡。受众摄影棚灯光师与影视现场摄影师；希望完成：按光源快速定位色温 K 值并选定白平衡档位。一条连续色温带承担全部核心信息，下方光源定位与白平衡卡片给出可执行结论
- **case-06 夜读 · 月相会员卡**：实体会员卡 / 活动折页 / 手机凭证。受众独立书店夜读俱乐部会员；希望完成：查看八夜主题与会员权益并确认参与进度。八个月相轮纵向排布，暗圆偏移形成盈亏，星点与金色构成夜读气质
- **case-07 共振 · 声学频谱报告**：测量报告插图 / 产品白皮书。受众声学实验室工程师与音频产品评审；希望完成：读出频响曲线、峰值与指标并判断是否需 EQ 修正。竖向渐变频谱柱 + 参考虚线 + 旋转峰值标签构成工程报告主图
- **case-08 折光 · 建筑玻璃样板册页**：材料样板册单页 / 客户提案附页。受众建筑师与幕墙材料选型客户；希望完成：理解玻璃层叠的折射观感并读出材料参数。四块倾斜半透明玻璃板叠影产生折射与色散，下方表格给出可核查参数
- **case-09 年轮 · 精酿季节菜单**：吧台菜单板 /  printed 季节酒单。受众精酿酒吧顾客与吧台点单员；希望完成：按季节与风味挑选酒款并读出 ABV / IBU。同心年轮圆环以木色阶隐喻四季，右侧八款酒按季节分组对齐
- **case-10 参数 · 生成艺术展签**：作品旁展签 / 限量版海报。受众生成艺术展观众与版藏家；希望完成：读懂作品的参数配方并据此复现图像。极坐标线网以透明度叠印产生干涉密度，右侧参数表即作品配方

所有品牌、展讯、运营/测量/材料/酒款数值均为自拟演示内容，已在 portfolio.json 的 content_basis 标注；色温颜色映射为近似示意，非精确黑体辐射计算。
