# case-05 · 台风「海燕」· 路径预警图

- **场景 / 受众**：沿海社区居民与应急值守人员
- **使用环境（媒介、距离、观看条件）**：社区公告屏/手机推送的方形预警图、中距离阅读
- **使用者要完成的事**：判断台风当前强度、移动路径与未来 24 小时影响
- **内容来源**：自拟台风名、路径、气压与风速，均为演示，非真实气象发布
- **视觉选择**：雷达同心环 + 螺旋路径与箭头 + 橙色预警等级标尺 + 实况/时间轴侧栏
- **实际使用的 DSL 能力**：RADIAL 渐变、ClipPath 同心环(EVEN_ODD)、arrow_head 箭头、ImageFiltered 光晕、polyline 螺旋、三角形标记
- **画布尺寸**：1080 × 1080 px（横/竖比按场景选择）
- **辅助素材**：无。本作品全部主体、图形、文字、图表与图标均由 Snapshot DSL 构造，
  未使用外部照片、纹理或生成整图；题面允许局部辅助素材，但本套采用纯 DSL 以保证可复现。
- **点阵码 / 码制**：如出现点阵码或条码，均为装饰性示意图形，非可扫描编码。
- **计划版本**：plan-v1（建立于首次渲染前，见 `../../../tmp/20261104-145656-hy4all/B01/plan.md`，
  基准 suite_root；完成标准见 portfolio.json 的 completion_criteria）。
- **最终自检**：见下方「实际看图自检」与 portfolio.json 的 criterion_results。
