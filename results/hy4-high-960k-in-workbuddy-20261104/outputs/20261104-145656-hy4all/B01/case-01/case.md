# case-01 · 滨江公园站 · 实时到站信息牌

- **场景 / 受众**：晚高峰在站台候车的通勤乘客
- **使用环境（媒介、距离、观看条件）**：地铁站台悬挂 LED 屏、约 3–8 米远距离站立观看
- **使用者要完成的事**：在几十秒内确认下一班车还有几分钟、在哪一站台上车
- **内容来源**：自拟站名/线路/时刻，均为演示数据，非实际运营信息
- **视觉选择**：深色 LED 点阵质感 + 琥珀色倒计时数字 + 四行分割翻页式信息带
- **实际使用的 DSL 能力**：Stack/Positioned 绝对布局、Container 圆角与边框、LINEAR 渐变、Opacity、dot_grid 点阵、Text 字距、dashed 线

- **辅助素材**：无。本作品全部主体、图形、文字、图表与图标均由 Snapshot DSL 构造，
  未使用外部照片、纹理或生成整图；题面允许局部辅助素材，但本套采用纯 DSL 以保证可复现。
- **点阵码 / 码制**：如出现点阵码或条码，均为装饰性示意图形，非可扫描编码。
- **计划版本**：plan-v1（建立于首次渲染前，见 `../../../tmp/20261104-145656-hy4all/B01/plan.md`，
  基准 suite_root；完成标准见 portfolio.json 的 completion_criteria）。
