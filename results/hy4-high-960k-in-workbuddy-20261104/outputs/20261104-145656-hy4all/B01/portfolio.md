# B01 作品集策展说明 · 十张真实场景的炫酷用例

本作品集把 Snapshot 结构化 DSL 放进十个可被真实用户使用的场景。每件先确定「谁、在何时何地、要完成什么」，再决定媒介形制、观看距离与视觉语言；十件的构图、配色、信息结构与视觉隐喻彼此独立，不是同一模板换文字。

| 用例 | 作品 | 受众 / 使用任务 | 最有辨识度的视觉选择 |
|---|---|---|---|
| case-01 | 滨江公园站 · 实时到站信息牌 | 晚高峰在站台候车的通勤乘客 / 在几十秒内确认下一班车还有几分钟、在哪一站台上车 | 深色 LED 点阵质感 + 琥珀色倒计时数字 + 四行分割翻页式信息带 |

| case-03 | ECHO 回声音乐节 · 霓虹电子票 | 入场口的音乐节观众与检票员 / 快速核验场次、区域与票号并撕下副券入场 | 近黑底 + 品红/青霓虹光晕 + SVG 凹口票券 + 全息渐变条 + 点阵码 |

## 策展逻辑

- **广度优先**：从公共信息、饮食、娱乐、运动、应急、音乐、医疗、零售、教育到公益，覆盖十类任务。
- **形制驱动**：按真实观看环境选择横屏、竖版、超宽腕带、方形卡与横版海报，尺寸不统一。
- **信息结构各异**：表格行、时间轴、圆环仪表、雷达、同心圆、网格、清单、星图、隐喻式进度，彼此不重复。
- **DSL 能力覆盖**：渐变、SVG 裁剪路径、变换、光晕滤镜、透明度、富文本、参数化点阵与几何图元。
- **诚实标注**：所有自拟内容在画面与 case.md 中标注为演示；点阵码标明为装饰性示意、不可扫码。

逐件场景、内容、DSL 能力、完成标准与真实看图证据见 `portfolio.json` 与各 `case-*/case.md`；逐图预览见 `gallery.md`。
