# case-04 · 三环限额 · 一包零食占多少

- **原本卡在哪**：营养成分表用 NRV% 小字表格呈现，用户要自己在脑子里把「每 100g」换算成「这一包」，很难形成整体判断
- **重构如何改善**：换算成「这一包占每日上限的百分比」，用三个同心环 + 一句中心结论代替表格
- **受众**：想快速判断零食能不能多吃、但看不懂 NRV% 表格的普通消费者
- **使用场景 / 目标观看环境**：1000×1200 竖屏图，包装背面替代说明 / 手机扫码页
- **用户目标**：不用读表格就知道糖、钠、脂肪各占一天建议上限多少、该不该吃整包
- **视觉选择**：三个同心环分别表达三种营养素占日上限的比例，中心直接给出「钠偏高」的判断，下方三行保留可核查的精确数值
- **演示数据**：自拟演示：糖 12/50g、钠 1560/2000mg、脂肪 22/60g 与百分比由脚本计算
- **DSL 能力**：三层 donut + arc 同心仪表、EVEN_ODD 镂空、进度条、百分比脚本计算、阈值标记圆点
- **尺寸**：1000×1200
- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材。
- **完成标准**：见 `plan.json`（B06-plan-v1）与 `portfolio.json` 的 `completion_criteria`。
- **虚构声明**：自拟演示数据 / fictional demo content（非真实测量、报价、时刻或官方规则）
