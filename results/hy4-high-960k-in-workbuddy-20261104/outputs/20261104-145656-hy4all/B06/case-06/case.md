# case-06 · 末班钟 · 还能赶上哪班

- **原本卡在哪**：公交站牌按时间顺序列出末班时刻，乘客要自己把每一班和「现在」相减，才能判断赶不赶得上、要等多久
- **重构如何改善**：以当前时刻为圆心，把剩余班次重构为按倒计时排列的放射扇区，把减法结果直接写成「3 分钟 / 还来得及」
- **受众**：晚上 22:28 站在梧桐里站、只想快点知道要不要跑的乘客
- **使用场景 / 目标观看环境**：1100×1100 方形图，电子站牌 / 手机到站提醒卡片
- **用户目标**：不逐行比对时刻表，立刻知道剩几班车、各要等多久、来不来得及
- **视觉选择**：把「现在」放在圆心，把还能赶上的班次做成放射状扇形扇区，倒计时直接写在扇区里；赶不上的班次灰掉，形成一眼可判的极坐标时钟
- **演示数据**：自拟演示：4 班车、3/15/37 分钟倒计时与「已发走」均为脚本设定
- **DSL 能力**：RADIAL 渐变、donut 环、arc A 弧扇段、ring_ticks、极坐标标签卡、8 位色半透明边框
- **尺寸**：1100×1100
- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材。
- **完成标准**：见 `plan.json`（B06-plan-v1）与 `portfolio.json` 的 `completion_criteria`。
- **虚构声明**：自拟演示数据 / fictional demo content（非真实测量、报价、时刻或官方规则）
