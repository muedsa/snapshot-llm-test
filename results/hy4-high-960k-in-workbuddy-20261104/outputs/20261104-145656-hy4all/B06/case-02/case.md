# case-02 · 同价尺 · 每 100g 统一标尺

- **原本卡在哪**：货架价签只标总价，不同净含量之间无法直接比较，购物者要么心算要么凭感觉
- **重构如何改善**：统一到每 100g 单价并排序，把「比价」从一个计算题变成一个看长度的动作
- **受众**：在超市货架前想买划算、但不想心算的普通购物者
- **使用场景 / 目标观看环境**：1200×900 横屏图，手机比价页 / 货架电子价签旁的小屏
- **用户目标**：不用心算就知道 5 种规格里哪一袋单价最低、能省多少
- **视觉选择**：把 5 种包装换算到同一把「每 100g」标尺，按单价排序成横向条形，最划算项用金色高亮并在底部给出可执行的省钱结论
- **演示数据**：自拟演示：5 个虚构品牌、规格与总价，单价由脚本计算
- **DSL 能力**：脚本计算单价并排序、排序条形图、金色高亮描边、chip 角标、LINEAR 渐变头部、深色结论条
- **尺寸**：1200×900
- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材。
- **完成标准**：见 `plan.json`（B06-plan-v1）与 `portfolio.json` 的 `completion_criteria`。
- **虚构声明**：自拟演示数据 / fictional demo content（非真实测量、报价、时刻或官方规则）

## 逐图看图结论

**最终版本**：v2（该用例经过视觉迭代修复）

v1 基线发现 5 行单价数值压在条形末端（「¥4.70 / 100g」被条形边缘切割），且底部「按每周买 3 袋算」文案与脚本 ×20 估算口径不一致。v2 把条形宽度收窄到独立绘图区、单价数值移到右侧专属列、「最划算」角标右移，并把结论文案改为「按每月 20 份的单价差累计估算」。v2 实际打开复查：5 个单价数值全部在条形外完整可读，金色高亮行与角标分离，条形仍按单价从低到高正确排序，底部结论与 ¥16.50 大数字清晰。
