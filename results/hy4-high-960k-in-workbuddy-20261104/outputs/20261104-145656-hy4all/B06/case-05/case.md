# case-05 · 一条轨 · 把 8 条时间戳压成一条线

- **原本卡在哪**：物流页把每一次扫描都列成一行时间戳，用户要在 8 行里自己找「现在在哪」和「什么时候能到」
- **重构如何改善**：按语义归并成阶段，用一条轨 + 高亮 ETA 窗口表达进度，并把结论写成一句话
- **受众**：等快递、只想知道「现在到哪、还要多久、什么时候在家」的收件人
- **使用场景 / 目标观看环境**：900×1400 竖屏图，物流 App 详情页 / 短信里的图片摘要
- **用户目标**：不逐条读时间戳就知道包裹进度与需要采取的行动
- **视觉选择**：把 8 条原始时间戳归并成 4 阶段 + 1 个 ETA 窗口的垂直单轨，当前节点与预计窗口用底色高亮，底部直接给出「14:00 后在家」的行动结论
- **演示数据**：自拟演示：5 个阶段、时间、网点与 ETA 窗口均为脚本设定
- **DSL 能力**：垂直时间轨 rect/circle、高亮底色卡、chip 状态、LINEAR 渐变头部、深色结论卡
- **尺寸**：900×1400
- **素材情况**：纯 DSL 构造，无外部图片、纹理或生成素材。
- **完成标准**：见 `plan.json`（B06-plan-v1）与 `portfolio.json` 的 `completion_criteria`。
- **虚构声明**：自拟演示数据 / fictional demo content（非真实测量、报价、时刻或官方规则）
