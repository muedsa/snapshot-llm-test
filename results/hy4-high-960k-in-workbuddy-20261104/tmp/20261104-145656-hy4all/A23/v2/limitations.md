# A23 · 格式边界说明与后续接口

主题:结构汇聚成图像。客户原始请求包含「文字可编辑 SVG、CMYK 印刷稿、6 帧透明 GIF 动画、PNG 封面」,并限定只用 Snapshot 类 DOM DSL 与 open-snapshot 服务作图。

## 0. 总判定:服务只能输出静态栅格图

`POST /snapshot` 的请求体是一份 UTF-8 纯文本 DSL(`text/plain`),成功响应是**单张静态图片二进制**;`type` 仅 `png` / `jpg` / `webp`(ai-guide.md 第 3、49 行;openapi.yaml `/snapshot` 200 响应 `image/png|image/jpeg|image/webp`)。接口与 DSL 没有多帧容器、帧延时、循环次数、时间轴、矢量导出或 CMYK 色彩空间等参数。因此服务**不能**原生输出动画 GIF、可编辑 SVG 或 CMYK 印刷稿,也不能在一次响应里给出多个带时序的帧。

本题不因『不支持』而结束,而是按授权完成**完整替代交付**:1 张 1200×800 RGB PNG 封面 + 6 张 600×600 真透明 RGBA PNG 关键帧(各存完整 DSL)+ `timing.json`(250ms/帧、loop、帧序)+ `frame-data.json`(逐帧几何/轨迹/接缝)+ `contact-sheet.png` 逐帧接触表。动作与时间轴由 6 个静态分镜逐帧完整表达,而非伪造目标格式文件。

## 2. 逐帧动作 / 时间轴(可核验帧序)

帧序:`frame-01 → frame-06`,时刻 t = 0 / 250 / 500 / 750 / 1000 / 1250 ms,每帧 250ms,循环周期 1500ms。插值进度 p(k)=(1−cos(πk/5))/2,六帧 p = [0.0000, 0.0955, 0.3455, 0.6545, 0.9045, 1.0000](仅说明设计轨迹,未渲染中间帧)。

| 帧 | 文件 | t | p | 动作 |
|---|---|---|---|---|
| 1 | `frame-01.png` | 0 ms | 0.0000 | 12 个结构碎片散布画布四周,朝向各异 |
| 2 | `frame-02.png` | 250 ms | 0.0955 | 开始向中心缓慢聚拢,余弦缓动起步 |
| 3 | `frame-03.png` | 500 ms | 0.3455 | 明显收拢,旋转角朝放射方向对齐 |
| 4 | `frame-04.png` | 750 ms | 0.6545 | 接近环状,角度基本对齐,间隙收窄 |
| 5 | `frame-05.png` | 1000 ms | 0.9045 | 几乎到位,单元逼近最终花位 |
| 6 | `frame-06.png` | 1250 ms | 1.0000 | 12 瓣放射星花成型,末帧构成可识别图形 |

12 个单元使用稳定 ID U01–U12,每帧各出现一次,ID 不印在图中。每个 ID 的几何类型(4 顶点菱形花瓣)、未旋转宽高 60×140 px、RGB 颜色与自身 alpha(=1.0)跨帧恒定;仅几何中心 (x,y) 与绕自身中心的顺时针旋转角变化,不用缩放、变形、变色或渐隐代替汇聚。位置以 4×3 散布锚点为起点,向中心 (300,300) 半径 145px 的 12 等分(30°)花位余弦缓动汇聚;旋转按最短弧对齐到放射角。末帧 12 瓣构成可识别的放射星花。逐单元相邻帧位移、角差与缓动公式见 `frame-data.json#trajectories`。

## 3. 循环接缝(如实记录跳变)

设计轨迹是单向『分散→汇聚』、**非闭合**:frame-06(1250ms,汇聚完成)与 frame-01(0ms,分散)在位置与旋转上不一致。循环在 1250→1500/0ms 处由汇聚态跳回分散态,出现一次可见的『爆散/重置』跳变。

- 逐 ID 的接缝位移与旋转差(按 360° 等价)见 `frame-data.json#seam.per_unit`。
- 接缝最大位移 413.4 px,约为帧间最大步长 127.7 px 的 3.24 倍,且方向与 5 个向心帧步相反(汇聚→散开),速度与方向均不连续。
- 因此 `timing.json` 中 `seamless=false`,`loop=true` 仅表示播放方式,**不**表示无缝;不能仅因 loop 就宣称无缝。
- 影响:每次循环末尾一次视觉重置,不影响 6 帧内部的连续汇聚。若要无缝循环,需外部补一段『散开』过渡帧或重新设计闭合轨道,本题未做,亦未假称已做。

## 4. 仍需外部后续工作(汇总)

1. 用外部工具把 6 张关键帧合成 GIF/APNG/WebP 动画,设置 250ms 延时与 loop;如需平滑循环,补间或重设计闭合轨迹。
2. 如需可编辑 SVG:外部矢量重排并保留文字层/字体。
3. 如需印刷:外部 RGB→CMYK 转换、分色、出血与打样。
4. 服务限制(单张静态位图、无动画/矢量/CMYK 参数)属平台能力边界,不能靠 DSL 绕过;以上均以『完整替代交付 + 明确后续接口』处理,未创建假的目标格式文件。
