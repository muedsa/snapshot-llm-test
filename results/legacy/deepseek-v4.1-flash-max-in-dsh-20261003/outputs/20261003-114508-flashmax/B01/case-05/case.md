# case-05 · 月相与深空观测窗口月历

- 主图：`final.png`（1560×1120，服务原始响应字节）
- DSL：`final.snapshot`（版本 v3，UTF-8 无 BOM）
- 渲染请求：B01-REQ-0009(fail)、B01-REQ-0013、B01-REQ-0017、B01-REQ-0020(fail-replay)、B01-REQ-0037
- 迭代记录：c05-v1-elements-fail、c05-v2-visual、c05-v3-visual

## 场景

| 项目 | 内容 |
|---|---|
| 受众 | 业余天文爱好者 / 天文社团排期者 |
| 使用环境 | 电脑屏幕或打印成 A3 贴在观测站墙上，暗光环境 |
| 要完成的事 | 挑出本月最适合出摊的夜晚，并知道当晚月亮有多亮、有多少小时全暗 |
| 内容来源 | 简化朔望月模型计算月相（误差约 ±0.5 天）；天文暗夜时长由太阳 −18° 时角解算出；行星窗口为演示星历 |

## 视觉选择

月相用逐行扫描的晨昏线几何真正画出来，而不是用圆形遮挡假装；每个日期格子同时给出月相、照亮比例与暗夜长度条

## 用到的 DSL 能力

逐行构建的月相盘、圆弧与圆环、日历网格、水平条形评分、深色多层次面板

## 自定完成标准

月相盘形状必须与照亮比例一致（凸月必须真的凸）；最佳观测夜排序必须由「暗夜时长 ×（1−照亮）^1.5」算出；日期不得溢出月历卡

## 实际自检

1. `final.png` 已用 `read_image` 打开本体逐项核对：月相盘形状必须与照亮比例一致（凸月必须真的凸）；最佳观测夜排序必须由「暗夜时长 ×（1−照亮）^1.5」算出；日期不得溢出月历卡
2. 最终 PNG 与临时目录中被审查通过的渲染结果 SHA-256 完全一致（`tmp/.../B01/verify_final.py`）。
3. 所有数值由 `cases/c05.py` 计算并写入 `tmp/.../B01/data/c05-lunar-calendar.json`，未手工填写。

## 素材情况

纯 DSL 构造，无外部图片、无嵌入素材；主体图形（曲线、网格、弧带、版型、航迹）全部由 `Container` / `Text` / `Transform` 组合生成。
