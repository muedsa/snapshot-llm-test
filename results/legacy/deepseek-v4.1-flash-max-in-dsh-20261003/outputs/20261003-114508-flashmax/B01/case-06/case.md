# case-06 · 手工皮具版型技术图（蓝图样式）

- 主图：`final.png`（1400×1010，服务原始响应字节）
- DSL：`final.snapshot`（版本 v3，UTF-8 无 BOM）
- 渲染请求：B01-REQ-0021、B01-REQ-0026、B01-REQ-0032、B01-REQ-0038
- 迭代记录：c06-v1-baseline、c06-v2-visual、c06-v3-visual

## 场景

| 项目 | 内容 |
|---|---|
| 受众 | 独立皮具工作室 / 手工爱好者 |
| 使用环境 | 工作台上平铺打印，边裁边看，30–50 cm 距离 |
| 要完成的事 | 按 1:1 版型裁断、打孔、缝合一件 A6 笔记本封套 |
| 内容来源 | 虚构图号 LP-A6-02 的封套版型；缝份、针距、孔数、用料面积均由 mm 尺寸换算 |

## 视觉选择

青色蓝图 + 网格 + 尺寸线，用工程制图语言表达手工艺；缝孔以真实针距沿内轮廓排布，可以直接数

## 用到的 DSL 能力

像素网格、毫米→像素换算、尺寸线与箭头、旋转尺寸数字、沿轮廓的参数化打孔、比例尺

## 自定完成标准

裁断线必须含缝份；孔数必须由周长与针距算出；尺寸数字不得被尺寸线穿过，也不得压住相邻版型

## 实际自检

1. `final.png` 已用 `read_image` 打开本体逐项核对：裁断线必须含缝份；孔数必须由周长与针距算出；尺寸数字不得被尺寸线穿过，也不得压住相邻版型
2. 最终 PNG 与临时目录中被审查通过的渲染结果 SHA-256 完全一致（`tmp/.../B01/verify_final.py`）。
3. 所有数值由 `cases/c06.py` 计算并写入 `tmp/.../B01/data/c06-leather-pattern.json`，未手工填写。

## 素材情况

纯 DSL 构造，无外部图片、无嵌入素材；主体图形（曲线、网格、弧带、版型、航迹）全部由 `Container` / `Text` / `Transform` 组合生成。
