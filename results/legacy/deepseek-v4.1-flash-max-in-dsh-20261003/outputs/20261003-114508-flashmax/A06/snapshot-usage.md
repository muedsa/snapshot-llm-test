## 3. 设计选择

1. **行 = 拓扑层，自上而下**。这样「先决边不能指向过去层」由版式本身保证：每条边的终点层号恒大于起点层号（`assert` 已校验）。
2. **同层两张卡 = 并行分支**，图例里写明。哪些节点同层来自审计，不是目测排的。
3. **箭头是用 3 条旋转小线段拼的三角形**，不依赖任何路径/多边形标签；`Transform.matrix` 用的是列主序「先抵消局部中心、再旋转、再平移」的写法（A02/A03 已验证）。
4. **反馈边专用视觉**：琥珀色虚线 + 独立图例 + 右侧回流通道，绝不与先决边同形；图内解释区直接写出两条回路的中文说明。
5. **交叉无连接点**：长边的横段与竖段都在空白带内走，交叉处只有线段交叠、没有端点，因此不构成新的依赖（脚注写明）。
6. **卡片信息**：编号 + 层号 + 中文标签 + 入/出度，一屏可读；节点字号 22px、注释 20px。
