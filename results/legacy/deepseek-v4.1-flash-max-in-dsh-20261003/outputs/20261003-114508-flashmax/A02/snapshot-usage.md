## 2. 用到的 DSL 能力

- `Stack` + `Positioned` 绝对定位完成泳道与卡片网格；
- `Container` 的 `color` / `borderRadius` / `border` / `boxShadow` 做卡片与活动块；块左侧色条用 `borderRadiusTopLeft` + `borderRadiusBottomLeft` 做成圆角竖条；
- 半透明色带：`#FDE68A66` 作为跨三泳道的午休带，叠在泳道底色之上；
- 1px 竖线 `Container` 作为 15 分钟刻度，小时刻度用较深的 `#CBD5E1FF`；
- `Transform matrix` 在本套共享渲染器里已有正确实现，本题未使用旋转（宽图不需要倾斜标签）。

## 3. 设计选择

1. **一块一会场**：三条水平泳道（A / B / C）共用 09:00—16:00 的线性时间轴，块左边缘 = 开始时间、块宽 = 时长 ÷ 420 × 轴宽，输入时间未做任何调整。
2. **短活动的文字空间**：块内只放编号，块上方一行放起止时间（≥18px）；标题 / 讲者 / 类别统一放到下方 15 张索引卡，避免「为塞字把 40 分钟画成 60 分钟」。
3. **午休独立**：12:00—13:00 用琥珀色横带跨三泳道，并在页头与索引标题行注明「不并入任何会议」。
4. **空档保留**：每个会场的空闲区间画成灰底块，可直接看出 A 会场 11:50—13:00 与 C 会场 11:45—13:20 的空档。
5. **手机图重新排版**：不做缩放或裁切，改为「上午 / 午休 / 下午」三段列表，15 项都带编号、标题、会场、起止时间，并明确写「讲者详见完整日程」。

## 5. 实际遇到的问题与修复

| 问题 | 现象 | 修复 |
|---|---|---|
| 纵向预算超支 | 首版泳道面板过高，C 泳道块压住「活动索引」标题 | 重算：泳道高 100→72、间距 10→8，块内只留编号与时间，索引区下移 |
| 说明文字越界 | 「读图方法」单行过长被右侧裁掉 | 缩短到 70 字，并单独占一行，不与容量/图例行混排 |
| 文本盒换行不可控 | 给说明文字设了过窄的 `width`，自动换成两行压住下一行内容（午休说明、索引副标题各踩一次） | 取消过窄的文本盒，或把盒宽加到单行所需宽度（午休说明 354→694px） |
| 午休说明无处安放 | 试过面板内、轴标签行、类别图例行、索引标题行四处，前三处都相撞 | 最终放在索引标题行右侧，与副标题留 166px 间距 |
| 请求编号重复 | 第一次渲染请求与 A01 的 `REQ-0001` 撞号 | 渲染器新增 `_suite/shared/reqseq-<prefix>.txt` 序列文件；本题 12 条编号天然唯一 |
