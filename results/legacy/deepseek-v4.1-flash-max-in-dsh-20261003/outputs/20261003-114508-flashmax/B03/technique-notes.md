# technique-notes.md — 12 件作品的独到手法、依据、证据与边界

本题交付 12 件作品；下面每件说明「用什么独到手法」「依据什么实测」「看了什么图之后改成现在这样」
「在什么场景有价值」「已经确认的边界」。所有数字来自真实探针与真实响应，探针原图与 DSL 保留在
`tmp/20261003-114508-flashmax/B03/probe/`。

## 0. 三条把 12 件作品串起来的地基

1. **Transform 落点规则（probe-04 实测）**：本构建把子节点**左上角**映射到 `(tx,ty)`，
   线性部分以该点为原点，没有 `w/2,h/2` 预平移。手写矩阵证据（box 200×14）：
   `R0 t=(400,200)`→bbox x 400..599 / y 200..213；`R90 t=(100,320)`→x 100..113 / y 120..319；
   `s(3,2) t=(700,560)`（子 40×20）→x 700..819 / y 560..599。
   于是把 `w×h` 方块以 `deg` 绕 `(cx,cy)` 摆放应写
   `tx = cx − cos·w/2 + sin·h/2`，`ty = cy − sin·w/2 − cos·h/2`。
   9 角位自动审计（probe-08）显示全部落点误差 < 0.6px。这是 case-01 的箭头与冲突标、
   case-07 的菱形绣线、case-08 的鸥与斜桁、case-10 的符头与符干、case-11 的角饰
   共同的几何基础。
2. **文字宽度模型（probe-10/12/14）**：CJK 墨迹 ≈ 0.94em、等宽 ≈ 0.49em、拉丁 0.175–0.98em。
   模型故意过估（CJK 1.00em、mono 0.60em、拉丁逐字符表），真实句子过估 1.002–1.033 倍。
   因为宽约束下的 `Text` 会**换行**而不是截断，过估只会浪费空间，低估会毁掉整行。
3. **预算（probe-11/15/16 + 多次 400）**：请求体 ≤ 1 MiB、文档 ≤ 4096 个**标签**、高度 ≤ 4096px。
   `Positioned`+`Container` = 2 个元素，所以「画一个点」也要算账。`sk.guard()` 在本地
   按标签解析预检，最高交付作品为 3852 要素。

## 1. case-01 夜间封锁计划表（时间-空间图）
- 手法：4 条轨道泳道 × 22:00–05:00 时间轴的**时间-空间图**，而不是甘特条堆叠；每条泳道内部
  再分为「作业类型标签 / 封锁色带 / 工程车胶囊 / 明细行」四个互不重叠的纵向带；
  斜纹用隔一根的竖条做出「封锁」质感；冲突标用两个 45° 方块叠成菱形并配底色圆。
- 依据：矩阵规则（箭头、菱形）；宽度模型（明细行截断）。
- 看图后的改动：v1 的 112px 菱形盖住 BALLAST 带、胶囊压住区块标签 → v2 分区；
  v3 发现 `clock()` 只印整点，所有封锁起止都变成 `22:00–00:00` → 改为 `hh:mm`；
  v4 标记又落进上方泳道 → v5 移到 DOWN MAIN 末端空白并被质心测量确认（1585,482）。
- 价值：控制室要在发令前一眼看出「哪条轨封多久、哪里撞车」。
- 边界：时间轴精度受列宽限制，30 分钟刻度以下不建议再细分。

## 2. case-02 面包房发酵排程（单日双序列 + 步骤表）
- 手法：发酵曲线用**实心面积带**（互不重叠的 2.05px 分箱）承担体量，室温用虚线；
  两条曲线都用旋转条折线并补圆接头；标注改为贴在曲线上的短签并钳制在绘图区内。
- 依据：接头空隙与 alpha 二次合成是自己踩出来的（见第 4 节记录），宽度模型用于表格截断。
- 看图后的改动：v1/v2 断成虚线 → 补接头；v3 标注互相压 → 改短签；
  v4 试图用裁剪层 → 整体塌缩（**边界**）；v6 消除条纹并平滑序列。
- 价值：面包房每天照着做，曲线形状本身就是「面团现在长什么样」的指令。
- 边界：**裁剪层不能与绝对定位共存**——在裁剪 `Container` 内再嵌 `Stack` 会把所有
  绝对定位子节点按层原点重新基准化。因此本作改用数值钳制。

## 3. case-03 生成植物标本图版（程序化几何）
- 手法：对数螺线叶轴 + 按 `sin` 剖面递变的羽片（旋转条，末端加小圆）；叶序插图用
  **黄金角 137.507764°** 摆 150 个点，半径按 `√n` 分布；孢子囊用格点排布而非随机撒点。
- 依据：这是元素预算的实战案例——最初用 step 1.4 的光栅化羽片，直接撞上 1 MiB 与 4096 元素
  两道限制；改成旋转条后降到约 400 要素。
- 看图后的改动：v2 孢子囊插图的装饰环穿过孢子场 → 去掉；比例尺压在叶序图下 → 移位；
  v5 说明文字与免责声明重叠 → 收紧；v6 实体修正后重渲染。
- 价值：能生成「像真的」但明确标注为虚构的标本图版，适合做示例图鉴、教学版式。
- 边界：4096 元素上限直接决定可生成密度；`&` 必须裸写（见第 12 条）。

## 4. case-04 点阵发车板（自带 5×7 位图字体）
- 手法：手写 44 个 5×7 字形位图表，逐格发**方形 LED 单元**，因此所有排版都是几何而非字体；
  改一个 pitch 常量即可整体缩放。状态用琥珀/白/红三色键控。
- 依据：每格 2 个元素，因此「发车板」这类密集文字作品必须先做元素预算，
  否则会像 v1 一样到 7381 要素被拒。
- 看图后的改动：v2 列重叠 → v3 重算四列（30/280/880/1030）；v4 收紧面板高度。
- 价值：任何需要「像硬件」的界面示意都能自洽，且不依赖字体可用性。
- 边界：元素预算决定了板面能放多少行；本作最终只放 5 行。

## 5. case-05 滚筒地震记录（极坐标 + 螺旋线图）
- 手法：用同心圆环 + 放射刻度做「滚筒」隐喻；三条分量波纹沿极角展开，振幅随 P 波到时有
  真实增益（一个参数控制）；右侧长图（helicorder）用同一数组的另一种采样。
- 依据：极坐标由 `polar()` 计算后交给旋转条绘制；步长与线宽的配合决定连续性。
- 看图后的改动：v1 用 2.1° 步长导致波形断成短划 → 1.55° + 3px；STATUS 与 HELICORDER
  标题相撞 → 面板整体下移。
- 价值：把「时间序列 + 方位」的信息压成圆形，适合值班室的一屏总览。
- 边界：角度步长 × 半径 = 弧长，步长必须小于线宽才不会断线（这是可复用的定量规则）。

## 6. case-06 24 通道电平墙（真实 dB 刻度）
- 手法：把 dBFS 线性映射到像素，用**2.4 dB 一段**的分段条着色（绿/琥珀/红三区），
  峰值保持用白帽 + 数值；因此条长在不同通道间可直接比较，而不是装饰性抖动。
- 依据：真实刻度 + 由同一数组计算出的峰值与统计（最响、最轻、超阈通道数）。
- 看图后的改动：v1 图例印出 `&amp;`/`&lt;` → 改写措辞；v3 恢复真减号。
- 价值：混音师要的是「可比」，不是「好看」，这张图两者兼顾。
- 边界：分段条的段宽受列宽限制；通道数再翻倍需要缩短标签。

## 7. case-07 十字绣图样（旋转菱形针脚）
- 手法：把 case-04 的像素机制**旋转 45°**：每一针是一个圆角菱形，落在编织底纹上；
  图案用字符串矩阵描述（花、叶、隼），图例与针数台账与图案同源。
- 依据：旋转条的矩阵规则；底纹用整行半透明条做织物感。
- 看图后的改动：v1 布边压在色号栏下 → 拆成图/栏两列；v3 字母带两次压住角花 →
  缩成 KJ 首字母并上移花列；v5 加入重复花边填满版面。
- 价值：爱好者的图表需要「图案 + 色号 + 针数」同时可查。
- 边界：菱形在极小尺寸下会糊成噪点，本作最小针距 12px。

## 8. case-08 绘本跨页（剪纸拼贴）
- 手法：全部用纯色实心形状从后往前堆叠，靠**轮廓**而不是描边分层；海浪用重复圆点做扇贝边；
  太阳用两层圆 + 短放射条（放射条内径藏在圆盘之后）；山脊用 5px 扫描线多边形。
- 依据：多边形 step 越小越平滑但元素越多——这是预算与观感的直接权衡（v2 曾到 8810 要素被本地拦下）。
- 看图后的改动：v1 船体/鱼出现横向扫描线、放射条横穿日面、竖排书名是一列短划 →
  降 step、挪内径、书名改到天空区；v3 云压住书名 → 移云；v4 加上灯塔让画面与文案一致。
- 价值：儿童读者靠大形状与高对比识别；这张跨页在缩略图尺寸仍可读。
- 边界：竖排拉丁文在缺少旋转文字能力时只能做装饰性列，不能当作可读标题。

## 9. case-09 和纸食谱卡（竖排 CJK）
- 手法：**竖排**用「一字一个 Text + 计算字距」实现（不是旋转整段）；毛笔笔触用一个
  两端收窄的多边形一次性画出；材料表数量右对齐；时间轴用点 + 连线。
- 依据：CJK 宽度 1.00em 模型让竖排列宽可算；多边形取代圆头短条（后者会变成串珠）。
- 看图后的改动：v1 笔触成串珠、竖排标题撞材料区 → 重建笔触并把开本加到 1720px。
- 价值：日式排版的最小可用实现，可直接复用到菜单、标签、告示。
- 边界：竖排是「逐字摆放」，标点避头尾等排版规则需要自己实现，本次仅做基本处理。

## 10. case-10 小提琴把位指法表（乐谱排印）
- 手法：五线谱、符头、符干、升号、谱号全部用图元构造；音高映射到**真实 y 刻度**，
  因此谱面与上方指法网格天然一致；把位环用**描边圆**（`ring()` 拼圆要 ~190 个元素）。
- 依据：文档的 `borderRadius` + `border` 组合可以一次画出圆环；矩阵规则用于符头倾斜与符干。
- 看图后的改动：v1 谱面错乱、手型图越出画布；v2 重建谱表、重锚手型图；v3 放大比例、
  简化谱号、错开升号。
- 价值：教学讲义要「网格（找音）」与「谱面（读谱）」互相印证。
- 边界：符杠、连音线、多声部等进阶排印尚未实现；本作只做单声部音阶。

## 11. case-11 剧院节目单（装饰性排印）
- 手法：双线框 + 四角菱形装置；盾徽用多边形 + 十点星 + 两侧月桂枝（旋转条 + 圆点）；
  标题用 `letterSpacing` 作为**设计值**；演员表用悬挂缩进两栏。
- 依据：`letterSpacing` 是文档属性而非自造；盾徽与星都是多边形与旋转条的组合。
- 看图后的改动：v1 标题印成 `Kestrel &amp; the Long Tide`、场景两行压在一条基线上、
  月桂像散乱木棍 → 修实体、重写场景行、徽章改为盾 + 五角星。
- 价值：活动海报/节目单需要「一眼是印刷品」的仪式感。
- 边界：装饰必须用几何近似，无法做到真正的字体花饰。

## 12. case-12 潮汐与日照周计划（多编码矩阵）
- 手法：**一个调和生成器**同时产出 7 条潮汐曲线与表中 28 个高低潮时刻/潮高（扫极值得到），
  所以图表与表格不可能互相矛盾；日照窗用色条 + 晨昏阴影；月相用两圆相减。
- 依据：面积带用 5px 分箱 + 7px 折线（1350 要素），比 2px 折线（3900+）省 3 倍。
- 看图后的改动：v1 日照条越出右缘（bx 达 1850 > 1700）、七行填色连成幕布 →
  重算列位、隔行底色、每行加基线；v2 因 2px 步长撞预算 → 改 5px 分箱。
- 价值：赛艇/帆船俱乐部选窗口时，图表与数字必须一致，这张纸做到了同源。
- 边界：调和常数是演示值，明确标注「不得用于导航」；生成密度受元素预算约束。

## 13. 关于实体的最终结论（probe-15/16/17）
原文**不解码 XML 实体**：写 `&amp;` 画面就是五个字符 `&amp;`。
但**裸 `&` 与裸 `>` 被接受并原样输出**（probe-17 实测并看图确认），
只有裸 `<` 不能使用（会被当作标签起始）。
因此本题的 `esc()` 只把 `<` 换成 U+2039，`&`/`>` 直出——case-03 的
「R. Okonjo & T. Vasquez」与 case-11 的「Kestrel & the Long Tide」就是这样印对的。

## 14. 交付级结论
- 12 件作品的结构互不重复（时间-空间图 / 日曲线 / 标本版 / 字符矩阵 / 极坐标鼓 /
  刻度墙 / 针脚图 / 叙事跨页 / 竖排卡 / 乐谱排印 / 装饰节目单 / 周矩阵）。
- 共享代码只做图元（文字量算、旋转条、面积带、图例、刻度），不共享版式骨架。
- 所有数字（潮高、dB、频率、针数、元素数）都由脚本计算并落盘，未手编。
- 每件作品都至少记录过一次「看图 → 改 DSL → 重渲染 → 再看」的完整迭代；
  8 次服务拒绝的原始错误体全部保留。
