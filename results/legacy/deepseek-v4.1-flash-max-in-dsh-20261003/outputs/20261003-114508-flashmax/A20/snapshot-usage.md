## 4. 设计选择

1. **先解布局、再出图**：标签位置由 `solve_layout7.py` 求解（贪心 + 爬山），目标依次为
   “可行（不压点、不压标签、不穿标签）→ 交叉数 → 锚点到标签的距离”，避免手工摆放产生压字。
2. **圆点双层绘制**：白晕圈 + 深色填充 + 系统描边，保证圆点在任何引导线上都清晰。
3. **折线留 6px 间隙**：引导线从距圆心 `点半径+6` 处开始，既不与圆点连成一体，也不显得脱节。
4. **图例避让**：图例卡的位置由程序在候选位置中挑选第一个与所有标签盒、所有圆点都无冲突的位置。
5. **标签统一白卡 + 浅描边**：与全站设计语言一致（深色页头、浅底、白卡片），同时保证 20px 文本可读。
