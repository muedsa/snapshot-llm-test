## 3. 设计选择

1. **每格 34px，网格 884×612**，放在 (84,168)：给左侧 y 标尺、上侧 x 标尺、右侧说明栏和底部图例各留出独立空间。
2. **墙格与可走格用填充色区分**（灰 `#CBD5E1` vs 白 `#FFFFFF`），墙格比格子小 2px，避免相邻墙块连成一整片而看不出格界。
3. **线型 + 颜色双通道**：路线一实线红，路线二点划蓝（点划线是用 11px 实段 + 8px 间隔手工拼出的，因为不依赖任何虚线标签）。
4. **箭头用 3 条旋转细条拼三角形**，放在每一段 ≥5 格的长直段中点以及终点。
5. **重合段错开**：两条路线都以格心为基准，各向垂直于前进方向偏移 3px；这样即使完全重合也能看到两条独立线条。
6. **门洞**：位置与宽度完全来自 `floor.txt`，图中没有加宽任何门洞，也没有把墙格画成可走。
7. **说明栏**：只放路线信息与校验结论，图例与坐标/尺度说明放到网格下方的独立横带，避免说明栏与网格争高度。

## 5. 实际遇到的问题与修复

| 问题 | 现象 | 修复 |
|---|---|---|
| **段拼接写错** | `out.extend(leg if not out else leg[1:])` 把三段拼出一次多余折返，得到 37 格 | 改为显式逐段追加 + 断言首尾衔接 + 断言每步相邻，定为 36 步 |
| **绘制顺序错误（最关键）** | 墙格在路线**之后**绘制，穿过墙列的路线整段被墙格盖住，两条路线看起来是一段段孤立横杠 | 把「地板 + 墙格 + 站点方块」全部提前到路线之前；路线之后只画文字、标尺与图例 |
| 侧栏纵向溢出 | 侧栏内容按整幅 1080 排，但可用高度只有网格高度 612，文字一路压行 | 侧栏拆成固定高度的两块（224 + 388）并加断言；图例与坐标说明移到网格下方的独立横带 |
| 格号换行、压字 | `width=34` 的容器让 `10,10` 换行成两行，压住相邻格 | 只画宽度放得下的格号，并把范围限制为「不与路线格相邻」的格子，另加浅色底片 |
| 展区名压格号 | 「材料实验」「作品巡览」与格号重叠 | 展区名改到展区格正下方 3 格处 |
| 墙块连成一片 | 相邻墙格无缝，看不清格界 | 墙格缩小 2px |
| 侧栏/网格抢高度 | 网格高度与侧栏内容互相挤 | 用 `assert ROUTE_H + INFO_H <= GH` 把预算写死，超了就报错而不是悄悄压字 |
