## 3. 设计选择

1. **三图共用一套视觉单位**：①渠道率与③总体率都是 **0—40% 同一尺度、同一条零线**，所以「每根柱都变高」和「总体柱变矮」可以直接用高度对比；②构成带**每期等长 252px**，分段按真实份额 80/20 与 20/80，等长这一点本身就是信息。
2. **用颜色与位置建立关系**：绿=直接访问、橙=推广访问贯穿①②，③的后期柱换成玫红以强调「总量下降」。①下方直接写出「四条柱都变高」，③下方写出「总体变化 -9.40pp」与两项分解，避免结论先行——先看图、再看数、最后看结论。
3. **不使用平均**：总体率只用总成交 ÷ 总访问；图中唯一出现算术平均的地方是结论第三行，且明确标注「看起来在涨」以说明它与真实方向相反。
4. **可核对**：④表逐格给出访问数、成交数、转化率、精确分数与该期总体率，底部一行给出加权复核算式。

## 5. 实际遇到的问题与修复

| 问题 | 现象 | 修复 |
|---|---|---|
| 圆角元组写法 | 400 `Attr [borderRadius] value format error`，两次复发（v2、v5 各自回退） | `box()` 统一支持数字与 `("top", n)` 形式，改写为 `borderRadiusTopLeft` 等四角属性；此后封装进共享 `dslkit.py` |
| 图例压住轴标签 | ①的 x 轴标签被图例遮住 | 图例信息并入副标题，轴标签独占一行 |
| 构成带标签互相压字 | ②两条带之间的标签被带本身压住 | 改为「期名放在带外侧左侧 + 构成百分比合并到面板底部两行」，带内不再放任何文字 |
| 表格表头与列名错位 | 表头文字与第一行数据列名重叠 | 列几何改成一份「边界表」一次声明（左/右边缘 + 对齐），表头与单元格共用；再把表头单独占一行（`HY = TY + 62`） |
| 结论正文字数超框 | 首版两行文案在 106–1500px 宽度内换行成三行，压出框外 | 拆成三行独立文本，每行按实测字宽控制在单行内 |
| 脚注与加权复核相撞 | 表格高度增加后脚注位置写死 | 脚注改成跟随表格底边计算（`TH + TY + 12 / + 42`），并加断言 |
| 单元格文本过长被裁 | 「26.00% (2600 ÷ 10000)」超出 190px 列宽 | 该列只放总体率，精确分数留在前「精确分数」列 |
