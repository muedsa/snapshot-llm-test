## 使用场景

普通读者在手机竖屏上用 3 分钟读完一篇数据新闻：十年间这座城的单程通勤变长了多少、
变长在哪一种交通方式上、早高峰是不是被摊平了。长图（1200 宽、按内容自然生长的高度）
是移动端深度阅读的真实载体，不需要缩放即可自上而下读完；每个板块自带一句话结论，
只滑不看图也能得到完整叙事。

## 完成事项

1. 八个板块全部由 Snapshot DSL 构造，无外部图片、无字体素材：
   00 刊头（88px 主标题 + 锈红副标题 + 导语 + 署名行）、01 四张 KPI 卡、
   02 十年折线（含面积、网格、刻度、三个焦点标注）、03 七宫小倍数（占比 S 形曲线 +
   Δpp）、04 两幅 10×10 waffle 结构对照 + 图例、05 两只 arc 环 + 长尾时段成对条、
   06 七行成对时长条、07 距离/时长/速度反算表 + 校验行、08 三条结论 + 方法论 + 页脚。
2. **全部数字反算自同一张方式表**（7 种方式的 2015/2025 占比与时长）：
   逐年占比按各方式 S 形（logistic）路径内插并把舍入残差归一到 100%；
   加权平均 = Σ 占比×时长 ÷ 100；年通勤小时 = 均值×2×250÷60；
   门到门速度 = 距离 ÷ 时长；waffle 格数 = round(占比) 且 `assert acc == 100`；
   分时段占比与峰时占比 `assert` 闭合到 100%。改任一输入数字，趋势、小倍数、
   waffle、环图、成对条与反算表同步重算。
3. 文案里的结论句同样由程序生成，不手写常量：02 的「最大一跳 +0.7 分钟出现在
   2021→2022 年」由逐差取 max；03 的 ±pp 取占比变化的极值方式；06 的
   「小汽车 +7 分钟最多」由 `max(Δ)` 得出。

## 虚构声明

城市名、样本量（12 000 人）、七种方式的占比与时长、轨交里程 460→1104 公里、

图内已用三处标注：署名行「数据为虚构演示口径」、方法论面板整段声明、页脚「虚构演示数据」。

## 视觉与技术选择

- 浅色编辑部配色（米白底 + 墨蓝正文 + 锈红强调），七种方式各配一色并在 waffle、
  小倍数、成对条三处保持一致，读者只需记一次色。
- 折线与小倍数的面积用**逐列矩形**逼近（Snapshot 无 path 图元），并预先把半透明色
  合成实色：`K.hexa` 输出 8 位 alpha，相邻列 1.2px 重叠会叠成 0.19 的深色竖带，
  读起来像栅栏；改成本地 `mix()` 预合成实色后重叠无害。
- 成对条的 2015 条用**浅灰填充 + 描边空心**而非另一种颜色：七种方式里「其他」本身
  是灰色，任何纯色第二色都会与它撞车，用「空心 vs 实心」编码年份对所有方式都成立。
- 峰时长尾条与左侧环图共用同一满格尺度（41.5%），注释直接写明，避免读者误以为满格 = 100%。
- 文本全部走 TextFit 预算（177 项检查，0 溢出）；右对齐一律用 `x = 右边界 − w`，
  多行段落显式传 `maxlines`。

### 与计划的偏差

PLAN v6 原定画布 1200×2200；实际内容（八个板块）在 1200 宽下自然生长到 **1200×3645**。
未压缩板块数量或字号来凑原定高度，因为长图的可用性判据是「手机竖屏自上而下读完」，
高度不是约束、可读性才是。此偏差在 PLAN v7 记录。
