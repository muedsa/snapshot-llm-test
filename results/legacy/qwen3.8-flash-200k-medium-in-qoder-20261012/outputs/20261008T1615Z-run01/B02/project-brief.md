# 扳手屋 · 项目简报（B02 触点 01 前置）

> 虚构演示品牌。机构名、馆址、电话、费率、全部数字均为演示数据，由
> `tmp/20261008T1615Z-run01/B02/data.json` 一张表生成，十个触点共用；运营规则的骨架参考了
> 真实存在的工具图书馆公开做法（见 `research/notes-tool-library.md`）。

## 1. 一句话定义
社区工具图书馆：会员按年付费后**借走**工具而不是购买，馆方负责维修与保养，
用一次的使用权替代一整套所有权。

## 2. 用户与场景
- 主要用户：白鹤岭一带 1860 名会员中的「临时需求型」住户——一年用两次电钻，
  买一台 ¥420 的角磨机只为挂一次置物架。
- 次要用户：社区木作/园艺兴趣小组、来馆参加 Safety 101 的新会员、把家里坏掉的
  吸尘器拿来问能不能修的老人。
- 关键场景：进店找工具 → 前台借出 → 用一周 → 归还 → 逾期或被借坏时的沟通。

## 3. 要解决的问题
1. 工具贵、用得少、放家里吃灰；买错型号更浪费（避免重复购买合计
   1,344 件 / 约 10589.8 吨钢材，见年报口径）。
2. 「借工具」这件事在中文社区里没有现成心智，门头和海报必须一眼讲清规则。
3. 馆内 412 件工具分 9 类 9 个库区，找不到的问题比借不到的问题更常见。
4. 逾期、损坏、保养状态这些容易起冲突的信息，需要在小票、推送、档案卡上一致、
   可核对、不含糊。

## 4. 运营规则（十个触点必须说同一套）
| 项 | 规则 |
| --- | --- |
| 会费 | 个人 ¥180/年，家庭 ¥260/年，志愿者免会费 |
| 押金 | 无押金，借出不另收费 |
| 借期 | 7 天，可续借 1 次 5 天 |
| 限额 | 同时在借最多 3 件 |
| 逾期 | ¥5/件·天；逾期满 15 天暂停借阅 |
| 维修 | 正常使用损耗由馆方负责维修与保养；会员保养课免费 |
| 馆址 | 白鹤岭馆（主馆 + 公共工坊）／望江驿（社区服务站取还柜） |

## 5. 品牌与视觉立场
- 名：扳手屋 · WRENCH HOUSE TOOL LIBRARY；母题＝六角螺母 + 斜穿的扳手柄。
- 气质：五金店货架 + 图书馆目录卡，不要互联网产品的圆角玻璃感。
- 底色牛皮纸 #F2EBDD，墨黑 #1B1E22，主色朱橙 #C8552B，辅以钢青/计量黄/状态三色。
- 结构语言：**刻度尺**（所有比例数据统一用它）、六角芯片（所有状态统一用它）、
  编号小标题、可压缩页脚（full/short/micro/receipt 四档）。
- 深底只用于触摸屏与夜间门头；同一令牌在深底上必须提亮后才允许使用。

## 6. 十个触点（详见 touchpoint-map.json）
门头橱窗 / 会员卡 / 馆内触摸屏 / 借出小票 / 手机推送 / 招募海报 / 安全须知 /
年度统计年报 / 工具档案卡 / 库区分区导视。

## 7. 完成标准
1. 任一触点上的数字都能在 `data.json` 里对上，触点之间互不矛盾。
2. 十件作品各自独立成立：不看其他件也能读懂规则与数据。
3. 品牌识别在 2400px 门头与 720px 小票上都能被认出（同一母题、同一页脚退化）。
4. 每张最终图有同名完整 DSL，且为服务真实响应字节。
