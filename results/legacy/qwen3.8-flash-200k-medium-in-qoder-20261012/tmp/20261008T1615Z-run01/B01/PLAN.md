生成时间：2026-10-09T10:31Z（run 20261008T1615Z-run01）
依据：TASK.md（≥10 件独立完整作品）、AGENTS.md（自主选题、真实使用场景、逐件看图迭代）、
`tmp/<run>/B01/capability-findings.json`（20 格能力探针的实测结论）。

## 选题原则

10 件必须解决**不同的使用任务**、面向**不同受众**、在**不同观看环境**里被消费，
因此尺寸、媒介语言、信息密度各不相同；不允许只换配色或换文案。
每件都优先用探针新验证的能力（SWEEP/RADIAL 比例半径、BackdropFilter 毛玻璃、
ColorFiltered 双色调、textShadow 色散霓虹、foregroundColor 镂空描边、
WidgetSpan/Emoji 行内件、Container clipBehavior、Image dataUri 局部素材、
overflow=ELLIPSIS 兜底），而不是重复 A01–A24 已经用惯的纯色卡片。

## 完成标准（每件自检）

- 真实受众能在目标观看距离/时间内完成其使用任务（自己写清谁、何时、何地、怎么用）。
- 所有数字来自同一份脚本内数据源，比例/倒计时/占比可互相核对，不出现自相矛盾。
- 逐 Positioned 文本盒高 ≥ 1.15×字号；无遮挡、无切字、无空标签。
- 至少一处探针级视觉能力被真正用于服务场景（不是装饰堆砌）。
- final.png 为服务原始响应字节，同名 final.snapshot 完整自包含。

  ① 任何"标注压在图形线上"的问题优先改成不透明/半透明贴片 + 引导线，而不是继续挪坐标；
  ② 去碰撞的占位框必须按**可见墨迹**登记（文字按字宽、符号按圆体），粗占位会让候选全灭、

  ③ 时间类看板定稿前必须把"时刻 A"与"由 A 推出的 B"互相反查一次（本案 `clock()`

- v4（02:02Z）：case-06 手游赛季长图定稿（v05，5 版 / 5 次请求全部 200）。
  两处计划变更：① 画布由 1080×2340 改为 **1080×3292**——六个板块在可读字号下放不进
  一屏比例，长图按内容定高、宽度保持 1080；② 新增一条通用标准：**流式排版**
  （每段返回游标、画布高度取末段结束位置）比手工绝对坐标更适合多板块竖图，
  可以从结构上消除"卡片内容溢出压住下一段标题"这类 case-04/05 都出现过的缺陷。
  另记：`L(x, …, align="END")` 的 x 是**左边界**，右对齐数值必须自己减宽度（本案 v01/v02
  连续两版栽在同一处）。
- v5（02:29Z）：case-07 杂志封面定稿（v07，7 版 / 13 次真实请求 = 7×200 + 6 次
  `curl (56)` 连接重置，其中 v02 一个 DSL 连吃 4 次传输失败后第 5 次成功）。
  三条新的通用标准，case-08~10 直接沿用：
  ① **汉字不要用 `foregroundMode="STROKE"` 做描边标题**——描边与填充同色时，
     ≥96px 汉字的内部留白会被笔画吞掉，整块糊成一团（case-06 的拉丁字母可以，
     汉字不行）。大刊名用实心字 + 字距 + 一条细线。
  ② **`align="END"` 的 x 仍然是左边界**（v4 已记，本案再次踩到且形式不同）：
     传 `x = 右边界` 会让文本框整体跑到画布外，表现为"这行字根本没渲染"，
     而不是"没对齐"。右对齐一律写 `x = 右边界 - 宽`。
  ③ **纯 DSL 风景要防"像 UI 元素"**：圆角胶囊状的高不透明度横条会被读成进度条/分割线，
     方角 + 降透明度 + 长短错落才像云带；同理，装饰性暗带必须压到 6px 以下并留亮边，
     否则像画面裂缝。
  另记：封面类作品的"信息自洽"要落到可反查的物件上——本案条码按 EAN-13 标准表
  逐位编码（95 位条空 + 校验位 3），字数/中位数/通读分钟全部由同一张目录表算出。
- v6（03:17Z）：case-08 集换式卡牌（Boss 卡）定稿（v16，16 版 / 21 次真实请求 =
  13×200 + 3×400 语法 + 5 次链路失败：curl (28) SSL 超时 ×3、curl (52) Empty reply ×1、
  响应体截断 213,792/332,564 字节 ×1）。两处计划变更 + 三条新标准：
  ① 画布由 1000×1400 改为 **1100×1540**（同 5:7 比例）——卡牌比例不能破坏，
     内容放不下时改等比放大而不是压缩字号或拉长卡身；
  ② 新增**贪心排程模型**：循环伤害、击破回合、破盾窗口、对手存活回合、掉落期望
     全部由 `SKILLS/COUNTERS/DROPS` 三张表在生成期算出（本案 7 回合
     `[24,17,17,20,17,17,20]`，总伤 132、均伤 18.86、峰值 24）。
  ③ **分栏面板的默认宽度是陷阱**：`panel()` 默认 `w=IW` 会让后画的面板整幅盖掉
     先画面板的文字，表现为"格子没渲染"而不是"被遮住"。子栏必须显式传 `x/w`，
     并在 helper 里加越界 `assert` 从结构上禁止复发（本案 v04 即此缺陷）。
  ④ **`RADIAL` 渐变不接受 `gradientBegin/gradientEnd`**，只吃 `gradientColors` +
     `gradientRadius`（0~1 比例）；`K.T` 会把 `fontStyle=None` 原样序列化成
     `fontStyle="None"` 触发 400，可选属性必须整段省略而不是传 None。
  ⑤ **v5 的"风景别像 UI"在程序化地形上会升级为"别像图表"**：本案为盐壳连做 7 版
     （三段堆叠→金字塔、16 片线性收尖→倒挂钟乳石、多根晶簇→子弹头天际线、
     尖峰包络脊线→音频均衡器、暗剪影细列→虚线三角轮廓），全部失败，最后**换构图
     而不是换参数**：改画平静卤水滩（低对比横向条带 + 半沉圆角丘 + 暗剪影盐柱），
     一次成功。结论：当装饰性几何在缩略尺寸下反复读成 UI 时，应改用"面/带/丘"等
     低对比体块，放弃高对比细结构；亮色顶缘逐列描边必然拼成虚线。
- v7（03:52Z）：case-09 数据新闻长图《通勤十年》定稿（v04，4 版 / 4 次真实请求，
  全部 http 200，零语法错、零链路失败——沿用 v6 ③④ 两条规则的直接收益）。
  一处计划偏差 + 三条新标准：
  ① 画布由原定 1200×2200 变为 **1200×3645**。长图的可用判据是"手机竖屏自上而下读完"，
     高度不是约束、可读性才是；放不下时增加高度，不砍板块、不缩字号。
  ② **逐列矩形面积图必须预合成实色**：Snapshot 无 path 图元，面积只能一列列拼，
     而 `K.hexa` 的 8 位 alpha 会让相邻列的 1px 重叠叠成两倍透明度（0.10→0.19），
     肉眼读成竖条纹/栅栏。改用本地 `mix(hex6, a, over)` 先合成到实际底色，
     重叠只用来消抗锯齿缝。本案 02 折线面积与 03 七宫小倍数同时受益。
  ③ **成对条的年份编码别用第二种颜色**：七种方式里已有灰色系，任何"2015 用灰、
     2025 用色"的方案都会在灰色列上失效。改用**空心描边 vs 实心填充**，
     对所有色相都成立（本案 v03 即"其他"行撞色）。
  ④ **文案结论句也要程序生成**：v03 发现手写句"除步行外每种方式都在增加"与数据矛盾
     （步行 15→16 同样在增加）。凡"除 X 外""全部""最大"这类量化措辞一律由
     `max()/all()` 生成，并把口径写进图内校验行；线性内插改成 S 形路径后，
     方法论段落与图注同步改述，避免图文口径漂移。
