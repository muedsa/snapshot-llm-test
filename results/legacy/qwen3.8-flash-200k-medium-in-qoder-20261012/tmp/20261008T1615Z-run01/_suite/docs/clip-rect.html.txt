## ClipRect

`ClipRect` 按矩形裁剪绘制结果。默认裁剪区域是当前 Widget 的完整布局边界。

## 函数签名
Section titled “函数签名”

`

fun ChildSlot.ClipRect(

clipper: ((Size) -> Rect)? = null,

clipBehavior: ClipBehavior = ClipBehavior.HARD_EDGE,

content: ClipRect.() -> Unit = {},

)

`

## 参数
Section titled “参数”

| 参数 | 默认值 | 说明

| `clipper` | `null` | 根据当前 Size 返回自定义 Rect

| `clipBehavior` | `HARD_EDGE` | 裁剪质量和图层策略

| `content` | 空 | 最多一个子 Widget

`

ClipRect(

clipper = { size -> Rect.makeWH(size.width / 2f, size.height) },

) {

Container(width = 240f, height = 120f, color = 0xFF38BDF8.toInt())

}

`

`NONE` 表示不裁剪；`HARD_EDGE` 快但无抗锯齿；`ANTI_ALIAS` 适合曲线边缘；`ANTI_ALIAS_WITH_SAVE_LAYER` 质量更高但成本更大。矩形边缘通常使用 HARD_EDGE 即可。
