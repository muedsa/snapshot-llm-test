# case-06 · 起降简报 · 只把背景糊掉

## 场景与受众

- **受众**：虚构机场「临川 LKC」起飞口的签派员，屏幕是值班台第二块 1400×1000 的屏。
- **使用场景**：签派员需要一眼同时看到「雷达上回波在哪」和「报文读数是什么」。
  回波是**上下文**，不需要读数级精度；风、能见度、云底、温度气压是**读数**，
  必须像素锐利。两者同屏，所以需要「只糊背景」而不是「整体加模糊」。
- **用户要完成的事**：确认 240°/08 m/s、6000 m、Few 1500 ft，判断放行没问题。
- **观看环境**：值班室，屏幕距离约 60 cm，需要眯眼看清数字的每个字符。

## 内容依据

机场、航班号、目的地、跑道号、报文各行全部为**自拟演示值**，明确不对应任何
真实航班或真实气象报文（页脚已注明）。雷达回波是四个二维高斯团块
（中心、宽度、强度四个参数）叠加一个固定种子的伪随机扰动后按 dBZ 分档着色，
距离环 10/20/30/40 km。

## 视觉选择与探索的能力

主打**高斯模糊**。先用 `tmp/20261004-182918/B03/probes/probe-c06-blur.png`
（8 格：黑白条纹底 + 一行测试文字，逐格只改滤镜结构）验证：

| 手法 | 用在哪 | 实测结论 |
|---|---|---|
| `ImageFiltered sigmaX/sigmaY` 包住整棵树 | 主卡的雷达层；对照卡①（文字也在里面 → 一起糊） | 糊自己的子树；并按 sigma 自动扩大输出边界，模糊会溢出子节点盒子 |
| `BackdropFilter sigmaX/sigmaY` | 主卡的玻璃板；对照卡②③ | 只糊「它之前已经画过」的像素；文字另画 → 保持锐利 |
| 两者叠加的正确顺序 | 主卡 | 背景先放进 `ImageFiltered`，再把 `BackdropFilter` 作为**后面的兄弟**盖上去 |
| `BackdropFilter blendMode` | 对照卡③ `DIFFERENCE` | 参与合成，结果反相，肉眼明显 |
| `BackdropFilter` 外面套 `ClipRRect` | 主卡玻璃板、卡片②③ | 官方建议：配合 Clip* 限定区域，圆角才不会溢出 |
| `tileMode` | 探针里对比过 | 可写，但两个标签只构造高斯模糊，`tileMode` 对高斯的视觉影响很小 |

### 三条实测边界（写进了页面底部「实测边界」栏）

1. **`BackdropFilter` 只采样绘制顺序里已经画过的像素。** 探针 D：先画
   `BackdropFilter` 再画条纹，条纹是**锐的**——过滤器对它无效。
2. **但它能采样「已经被 `ImageFiltered` 糊过」的像素。** 探针 E：先
   `ImageFiltered` 再 `BackdropFilter`，玻璃板采到的就是模糊结果。这正是本件
   作品的做法。
3. **这两个标签只构造高斯模糊**，没有 offset / tile / blur 之类参数
   （那些是 Kotlin DSL 的 `ImageFiltered`）。Parser 侧只有
   `sigmaX / sigmaY / tileMode`（+ `blendMode`，仅 BackdropFilter）。

## 迭代过程（实际看图记录）

1. **v1**：`RENDER_ERROR: Document contains more than 4096 elements`。
   定位到雷达的 12 条辐条：`W.seg` 用点链画斜线，每条约 200 个元素。
   → 换成两条轴对齐十字线 + 12 个边缘刻度（各 1 个元素）。
2. **v2**：对照卡①的文字原本画在 `ImageFiltered` **外面**，所以是锐的，
   和「字也糊」的标题矛盾 → 把文字挪进滤镜内部。
3. **v2**：对照卡③用 `SCREEN` + 很浅的染色，模糊几乎不可见 → 改 `DIFFERENCE`。
4. **v3**：方位标签用雷达区局部坐标调用了面板级的 `Frame.at`，整体少加了一个
   `(RX, RY)`，N 跑到面板外面 → 补上偏移，并从环外移到环内。
5. **v4**：放大核对主卡，确认「背景糊 / 读数不糊」成立。

## 遗留 / 不足

- 雷达回波是合成的示意团块，不是真实产品；没有做 dBZ→颜色的行业标准色标，
  也没有做距离衰减和地形遮挡。
- `BackdropFilter` 在长列表里逐个使用会有性能代价；本套交付的是静态帧，
  没有做滚动场景的性能实测（服务也不提供这个指标）。
- 「毛玻璃」常见的噪点/饱和度提升做不到：Parser 只有高斯模糊，没有饱和度滤镜。
