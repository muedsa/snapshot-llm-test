# case-01 · 潮汐与风 · 海岸观测站值班板

## 场景与受众

- **受众**：澄澳灯桩（虚构）自动观测站的值班员，值班台是一台常开的 1600×1000 横屏，
  距离约 70 cm，每 10 分钟刷新一次；以及每天早上交接班时看这块屏的海洋观测组长。
- **使用场景**：值班员要在一屏之内回答三个问题——现在风多大、接下来潮水怎么走、
  天上还看得见月亮吗。潮位曲线要能直接读出高潮/低潮时刻，因为交接时要复述给
  船长听。
- **用户要完成的事**：30 秒内说出「213 度风、6.8 米，浪高 1.6 米；15:00 高潮
  3.84 米，09:00 低潮 0.39 米；今天白昼 11 小时 46 分」。
- **观看环境**：暗值班室（所以用深色底），文字全部 ≥9 px @100% 可读。

## 内容依据（全部为演示用虚构值，位置与标注自洽）

- 站位、风、海况、日出日落：自拟的合理数值。
- **月相不是自拟的**：按本页时间戳 2026-10-05 09:45 +08:00（＝01:45 UTC，
  JD 2461318.57292）算月球平距角
  `D = 297.8501921 + 445267.1114034·T − 0.0018819·T²`（T 以世纪计，Meeus
  《Astronomical Algorithms》第 47 章低精度级数），得
  `D = 285.0°`，于是

  ```
  月龄 age = D/360 × 29.530588 = 23.38 d      → 满月后 5.9 d，亏凸已过，下弦未到
  照亮比例 k = (1 − cos D) / 2   = 37.0 %     → 残月（ waning crescent ）
  ```

  亮面在**左**（北半球亏月规律）。图上的标签、月龄、图形三者由同一个 `k` 生成。
- **潮位不是随手编的**：用六个真实分潮调和数合成
  `h(t) = MSL + Σ A·cos(2π(t − g)/T)`
  - M2 A=1.15 T=12.4206h g=32°、S2 A=0.42 T=12.0000h g=58°、
    N2 A=0.24 T=19.3413h g=12°、K1 A=0.28 T=23.9345h g=210°、
    O1 A=0.19 T=18.7693h g=195°、MS4 A=0.10 T=6.1033h g=88°，
  - 平均海平面 2.05 m，量程 0–4.4 m。
  - 曲线的每一点、柱高、0.0/1.0/2.0/3.0/4.0 刻度、高低潮标注的时间与数值、
    「大潮差 3.46 m」全部由同一个函数算出，图和字不可能对不上。
- 海面剖面 η(x) 是三个正弦叠加，Hs=1.6 m、n=72。

## 视觉选择与探索的能力

主打**渐变全家族**，全部经 `tmp/20261004-182918/B03/probes/probe-c01-gradient-idioms.png`
逐格验证后才用：

| 手法 | 用在哪 | 实测结论 |
|---|---|---|
| 垂直 LINEAR 渐变 + 8 位 alpha | 25 根潮位柱（顶透明→底实）、72 根波高柱 | 起止点必须写成 `(0.5,0)`/`(0.5,1)`；写 `BOTTOM`/`TOP` 是 400 |
| `gradientStops` | 探针 B | 位置真的生效 |
| `gradientTileMode="REPEAT"` + **短向量** | 水面横条带、alpha 阶梯的底纹 | 只有当 begin→end 的向量短于绘制盒时才重复；默认 begin/end 铺满盒子时与 CLAMP 无异 |
| `gradientFocal` / `gradientFocalRadius` | 月面径向渐变的球面高光 | 焦点偏移真的产生明暗不对称 |
| `gradientStartAngle` / `EndAngle` | 探针 F（扇形） | 可当扇形用 |
| `gradientRotation` | 探针 I | 弧度制生效 |
| `backgroundBlendMode="MULTIPLY"` | 探针 L | 渐变与底色相乘生效 |
| `shape="CIRCLE"` | 罗盘外环、月面、当前潮位标记点 | **只有 CIRCLE 和默认 RECTANGLE**，`OVAL` 是 400 |
| `ClipOval` + 逐行 `Positioned` 细条 | 月面晨昏线 | 球面晨昏线投影是半椭圆，半轴 = `R(1−2k)`；用 1 px 一行从边缘铺到 `x(y) = 88 ∓ (1−2k)·88·√(1−(y/88)²)`，被 ClipOval 切圆，亮面面积就等于 k。不需要路径图元 |
| 每行自带的 LINEAR 渐变 | 月面明暗 | 一行一个 `Container`，`gradientColors` 由 `b = s·n` 算出两端亮度，`gradientBegin="(0,0.5)" → gradientEnd="(1,0.5)"` |
| 8 位 `#RRGGBBAA` | 水深 8 级分级，压在 REPEAT 底纹上 | 半透明确实参与合成，不是替换 |
| `Transform` 4×4 旋转 | 风向箭头指向 212° | 画面正确（见 `crops/` 与最终图） |

## 迭代过程（实际看图记录）

1. **v1**：每个面板的内容整体偏移了面板原点——这是我脚本的 bug（把画布绝对坐标
   当成了面板内局部坐标）。用 `probe-07/08` 定位，不是服务问题。
2. **v2**：改用 `wlib.Frame` 后仍然偏移，因为 `Frame` 又把面板原点加了一遍
   （子节点已经嵌在面板自己的 `Stack` 里）。修 `Frame` 后几何正确。
3. **v3**：看图发现 5 处排版问题——表头 kicker 压住状态 chip、罗盘说明文字压住
   读数行、潮位面板 x 轴末端「时」与刻度打架、潮位面板底部 4 行信息溢出面板、
   底部波高条幅度太小。逐条改。
4. **v4**：状态 chip 文字被裁（`dsllib.est_width` 用 0.55em 拉丁估算，
   DejaVu Sans Mono 实际 0.605em）→ `chip(mono=True)`；低潮标签压住曲线 →
   移到点位的右上空白处。
5. **v5**：复查 `crops/final-c01-tidezoom.png` 确认高低潮标签与刻度清晰。
6. **v6（收尾复审）**：把十张 `final.png` 逐张重新打开时，3.4× 放大月面
   （`crops/final-review-c01-moon.png`）发现标签写着「亏凸月 · 照亮 72%」，
   而画面是一弯约 20% 的**右侧**蛾眉 —— 图与字互相打脸。追到
   `MOON_ILLUM = 0.72` 是硬编码常数，晨昏线是一个偏移的 `CIRCLE`。
   → 改成按本页时间戳真算（k=37.0%，残月，左亮），并用
   `ClipOval` + 176 行 1 px 细条按 `R(1−2k)` 半椭圆填充晨昏线；
   月面明暗逐行用 LINEAR 渐变给。3.0× 复验
   （`crops/final-review2-c01-moon.png`）通过。

## 遗留 / 不足

- 月面的明暗是 Lambert 近似（`b = s·n` 后取 0.55 次幂），不是光度学渲染；
  三块「月海」是半透明圆片，边界是硬边，不是真实的海/月纹理。
- 潮位用六个分潮的固定调和常数合成，没有做气压订正与风致增水。
- 低潮标签在图上位于点位右上方约 66 px 处，严格说离点稍远；因为下方
  「理论高低潮」一行明确写了 `低潮 0.39 m @09:00`，不会误读，故保留。
- 海面剖面是三个正弦的示意叠加，不是真实海浪谱（`Hs` 与 `Tp` 是自拟值）。
