# case-08 · 淹没深度分级 · 断面与图例

## 场景与受众

- **受众**：虚构「青屿街道」防汛办的值班调度（看断面），以及每周例会拿到这张纸的
  社区网格员（看分级 → 处置动作对照）。
- **使用场景**：一张贴在会议室墙上的断面图。橙色预警当天，调度要指着断面说
  「左岸 0.3 m 以下不用管，河道中心超过 4 m 立即撤离 214 人」。
- **用户要完成的事**：把「水深 → 分级 → 处置动作」三段对起来，并看清
  历史积水区与管井渗漏区相交处风险叠加。
- **观看环境**：A3 打印 + 屏幕投影，最远看 2 m，所以关键数字 ≥11 px。

## 内容依据

- 河段名、断面桩号、警戒水位、预警等级、转移人数、处置阈值：**自拟演示值**。
- **地形不是随手画的**，是一条解析曲线：
  `h(t) = 8.8·exp(−((t−0.30)/0.09)²) − 1.65·exp(−((t−0.52)/0.105)²)
  + 7.9·exp(−((t−0.76)/0.10)²) + 0.22·sin(21t)`
- 120 根柱子、每根 16.7 m，所以**分级色带、最大水深 5.42 m、淹没河宽 1333 m、
  断面面积 4142 m²** 四组数字全部由同一个函数算出，不可能对不上。

## 视觉选择与探索的能力

主打**子树透明与 8 位 hex alpha**。先用
`tmp/20261004-182918/B03/probes/probe-c08-opacity.png`（9 格，底下都垫了条纹）
逐项验证：

| 写法 | 实测结论 | 证据格 |
|---|---|---|
| `<Opacity opacity="0..1">` 包子树 | 整组一起淡，组内重叠仍然叠深 | C / F |
| `Container opacity="0.5"` | **属性不存在，被静默忽略**——渲染结果与不写完全一样 | B |
| `opacity="1.5"` | `400 PARSE_ERROR: opacity must be between 0 and 1` | 第二次探针 |
| 两块 `#FB718580` 叠在一起 | 明显比一块深 = 0.5+0.5−0.25 = **0.75** | D |
| 两个 `<Opacity 0.5>` 嵌套 | 比 C 更深但不到一半 = **0.25（逐层相乘）** | E |
| `<Opacity 0.75>` 里再放 alpha 0.5 | = 0.375 | G |
| `opacity="0"` / `"1"` | 0 完全不可见；1 等于不写 | I |

作品里怎么用的：

- **深度分级**用同一色相 `#2563EB` 的八级 alpha（`1A 33 4D 66 80 99 C7 FF`）。
  颜色越深 alpha 越高，两条编码同向——压在本页条纹底上时深水区会遮住纹理，
  这正是分级图例该有的样子；图例右列专门把同一 alpha 压在近黑底上做对照。
- **风险叠加**用两个 `<Opacity>` 组：历史积水区 0.55（玫红）、管井渗漏区 0.45
  （琥珀）。两组相交处自然加深，和真实 GIS 的复合风险渲染一致。
- 条纹底用 `gradientTileMode="REPEAT"` + 短向量生成（复用 case-01 验证过的写法）。

## 迭代过程（实际看图记录）

1. **v1**：`ROSE + "80"` 拼出 11 位 hex → 400；`a.r(x, y, w, 1, color=…)` 与
   `Frame.r` 的位置参数冲突 → TypeError。改为 `ROSE[:7] + "80"` 与
   `a.r(x, y, w, color=…, h=1)`。
2. **v2**：探针里把 `Positioned` 塞进 `<Opacity>` →
   `RENDER_ERROR: renderBox.parentData must be StackParentData`。
   `Opacity` 不是 `Stack`，所以它不接受定位子节点。新增 `plate()`（不带
   Positioned 的纯 Container）供 Opacity 内部使用。
3. **v3**：看图发现叠加实验里的条纹画在色块**上面**，把两个 Opacity 组糊成一片；
   → 把条纹移到最底层。边界四条也溢出面板 → 收到面板 D 的第二行。
4. **v4**：图例行高 40 px 让底部四条实测结论被裁 → 行高改 36，并把结论移出。

## 遗留 / 不足

- 断面是**横向**断面（垂直河道的横剖面），不是沿程水面线；真实防汛会两张都要。
- 淹没范围按「静水位」计算，没有做流速、水动力或建筑物阻水。
- 两个风险区用矩形区间近似，没有真实矢量边界。
- 印刷上没有做深浅网的网点补偿；`C7` 这一级是我选的，不是任何标准色阶。
