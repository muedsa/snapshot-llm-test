# case-03 · 拣选层级 · 仓储手持终端

## 场景与受众

- **受众**： fulfilment centre（虚构「华东三仓 E3」）的拣货员，手持一台
  1440×1024 横屏的加固终端，站在货架前，单手操作、戴手套、屏幕常年强光。
- **使用场景**：拣货员按波次作业，必须在 2 秒内知道「我现在在哪一层、
  下一个该拿哪个 SKU、还剩多少单」。
- **用户要完成的事**：扫一个码、按 `+`，直到「已拣」等于「需」，然后按扫描确认。
- **观看环境**：50–70 cm 距离、强光、无鼠标；触控目标必须 ≥76 px 高。

## 视觉选择与探索的能力

主打**投影**。先用 `tmp/20261004-182918/B03/probes/probe-c03-shadow.png`
（10 格）逐项验证，再把「影子深度 = 嵌套层数」做成真正的信息编码：

| 手法 | 用在哪 | 实测结论 |
|---|---|---|
| `ELEVATION_1 / 4 / 8` | L1/L2/L3 三层货位卡 | 内置层级名可用，可读出递进关系 |
| `ELEVATION_2` | 候选货位行、波次状态卡 | 同上 |
| 自定义 `x y blur spread color` | 作业卡 `0 18 42 -8 #0F172A2E,0 4 10 -2 #EA580C44` | 一次给两条阴影（远投影 + 主色近投影）；`ELEVATION_16` **不能**和自定义阴影写在同一个属性里，会 400 |
| 负 spread | 主按钮 `0 6 14 -2 #EA580C66` | 收紧投影，不外扩 |
| 彩色阴影 | 主按钮、作业卡的橙边 | 状态色投影生效（探针第 2 行第 3 格） |
| `blurStyle=INNER / OUTER / SOLID` | 探针第 3 行第 1 格 | 三种都渲染；SOLID 需要 `0 1 3 0` 而不是 `0 0 0 n` |
| `ClipRect` 视口 | 候选货位可滚动列表 | 视口 176 px，第 3 行之后连同投影一起被切掉 |
| 对照：`Stack clipBehavior="HARD_EDGE"` | 探针第 3 行第 2 格 | 同样的卡片，投影直接穿出视口糊在格子上 |

### 两个必须写下来的边界

1. **`boxShadow` 的 `blurRadius` 必须大于 0。** 写 `0 0 0 4 …` 或
   `0 0 8 3 … INNER` 会让**整次渲染返回 500 INTERNAL_ERROR**，不是只坏那一个控件。
   `0 0 0.01 4 …` 正常。这条在 `probe_06_shadow.py` 里用 17 个独立小画布逐个
   试出来（见 `tmp/20261004-182918/B03/responses/`）。
2. **只有 `ClipRect` / `ClipRRect` / `ClipOval` 会裁掉子节点的投影；
   `Stack clipBehavior="HARD_EDGE"` 不会。** 所以滚动列表要用 `ClipRect` 包，
   不能靠 Stack 自己的裁剪。

## 迭代过程（实际看图记录）

1. **v1**：`ELEVATION_16,0 3 8 -2 #EA580C33` → 400
   `elevation only allow use ^ELEVATION_(\d+)$`，即层级名不能与自定义阴影混写
   → 作业卡改成纯自定义双阴影。
2. **v2**：探针第 3 行整体 500，原因是我把 `INNER` 写成 `0 0 8 3 …`、
   `SOLID` 写成 `0 0 0 4 …`，两条的 `blurRadius` 都是 0 → 触发上面第 1 条边界。
3. **v2**：探针里 Stack 与 ClipRRect 两个视口看起来一样，因为卡片离视口边缘
   还有 100 多像素，投影根本没越界 → 把视口改成 254×96、卡片 226×70，
   差 14/13 px，两者的差别立刻可见。
4. **v3**：作业卡右上「需 6 箱」「已拣 2」被卡片右边缘切掉。用 `probe_09` 排除了
   服务端的 `textAlign="RIGHT"` 语义（8 组对照：写 `width` 时右对齐精确落在框右
   边界；不写 `width` 时退化成左对齐；写 `right=` 也精确），最后定位是**我的坐标
   层级错了**——这两条标签在卡片自己的 `Stack` 里，却用了面板局部坐标，
   于是右边界正好压在卡片边上。改为卡片局部坐标后正常。
5. **v4**：候选列表的标题与触控按钮底边差 2 px 打架 → 按钮上移 8 px、标题下移 2 px。
