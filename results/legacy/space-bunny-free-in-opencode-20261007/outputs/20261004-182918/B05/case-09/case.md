# case-09 · 冰箱上的维修速查卡

- **载体**：打印 A5 横向卡片 1050×760（148×105mm），左侧四个装订孔，贴在冰箱门上
- **受众**：任何一个住在这套房里的人（**不假设会用 App**）
- **时刻**：2026-10-01 打印；使用场景是某个半年后的水管又漏了的下午
- **用户意图**：3 秒找到「该找谁」，30 秒知道「上次这个位置换了什么」，
  并在打电话时把话说清楚
- **状态**：2026-10-01 更新 · K-02 / B-02 已修 · E-02 至今未确认

## 场景与内容

**背景**是拉丝不锈钢冰箱门：竖向渐变基底 + 170 条确定性条纹 + 两处径向高光
（顶部主光 + 左下环境反射）。**卡片**居中，圆角 14，白底 + 投影 + 印刷细边。

卡面六层：

1. **报头**：`房` 黄色标记块 + 「这套房 · 维修速查卡」+ 地址与打印日期；
   右上角一块**紧急联系区**：「水管 / 地漏 → 老周 138****6621」/
   「其他问题 → 房东 陆文君 139****3308」（号码已打码）。下方一条黄黑危险条纹
2. **「这三个位置修过，最容易再坏」** + 提示「再坏时先报同样的件，
   别让它第三次进同一个门」
3. **六列表格**（锚点 / 位置 / 报修单号 / 上次维修日 / 换了什么 / 备注）三行：
   - `K-02` 厨房 · 龙头阀根 / `R-2403-118` / `2024-03-09` / 陶瓷阀芯 + 垫片 / 老周 · 质保至 2026-03
   - `B-02` 卫生间 · 台盆下 U 型弯 / `R-2506-042` / `2025-06-21` / U 型弯 + 密封圈 / 老周 · 质保至 2027-06
   - `E-02` 阳台 · 洗衣机进水口 / 无记录 / — / 未修过 · 首次记录 2023-07 / 未修过 · 渗水请开新单
4. **琥珀色 E-02 条**：「E-02 阳台排水地漏盖：这一项还没确认过」+
   「退租时拍了 4 张都没拍到标记牌，判「暂挂」。这一块到底有没有问题目前没人能回答——
   不是没问题，是还不知道。」右侧分隔竖线后是处置指引：
   「如果这里渗水或返味，请直接开新单，不要按「已修过」处理。」
5. **两块「这张卡为什么贴在冰箱上」**：
   - 「先自己看这三样」：标记牌还在不在 / 具体是哪个编号（报 K-02，别只说「厨房」）/
     上次换了什么件
   - 「打电话时说这四句」：我住云栖里 1602，房东陆文君 / 位置是 K-02，厨房龙头阀根那个标记牌 /
     上次 2024-03 换过陶瓷阀芯和垫片 / 我拍了标记牌，照片在房谱里能看到
6. **页脚**：履历口径（12 个锚点 · 2023-07-01 → 2026-09-30 · 累计维修 ¥440）+
   「看到这张卡上有你不认识的修法，说明有人绕过房谱直接找人修了——拍一张那个位置的标记牌，
   履历里就有了。」+ 二维码示意块

## 视觉选择

- **卡片逻辑，不是界面逻辑**：字号大、颜色少、一张表对齐。
  这张纸的阅读距离是一米，不是三十厘米。
- 整张卡只有一个强调色（锚点牌黄）+ 三个真实联系方式，
  其余全是「上次换了什么」——因为半年后最重要的问题是「这个位置已经被修过」。
- 左上角的黄黑标记牌图案让它和现场那些牌属于同一套东西：
  住户看到冰箱上的这张卡，就知道要找的是柜底那块小黄牌。
- **E-02 的处理是这张卡的诚实性所在**：它没有把 E-02 藏在表格里，
  而是单独给了半个版面的位置说「没人能回答」。

**本轮实际发现并修掉的缺陷（4 处，每处均重渲染并复验通过）**：

1. **表格第 7 列「备注」宽度算错，整列溢出卡片右缘并被裁掉**：
   列宽是按 `COLW = [84, 232, 92, 130, 144, 100, 180]` 分配的，
   但累计 `84+232+92+130+144+100+180 = 962` 已超过 `IWD = 838`。
   定位：首次看图即可见——「质保至 2026-03」和「如果渗水，新开单」都被切在右缘。
   修复：**取消「维修方」列**（老周已在右上角联系方式里，不必重复），
   改 6 列并按 `est_width` 重新分配为 `[64, 190, 104, 104, 164, 190]`。
2. **琥珀条的正文与右侧指引同样溢出**：左段 560px + 竖线 + 右段 170px 超出 `IX1 = 944`。
   修复：左段 560 → 496，竖线移到 `IX0+600`，右段起点 `IX0+616`、宽 222。
3. **表格底（`ry = 444`）与页脚线（602）之间有约 180px 空洞**：
   这不是留白，是缺内容。修复：填入两块真实内容——
   「先自己看这三样」与「打电话时说这四句」，
   这正是这张卡被贴在冰箱上的理由，之前只是没写出来。
4. **二维码说明落在卡片下缘之外**：二维码 72px 在 `FY+8`，说明在 `FY+86`，
   而 `FY = cardBottom - 92`，因此说明文字压在卡片边框上。
   修复：页脚带 92 → 104px，二维码 72 → 60px，说明移到 `FY+74`。

- [x] 未使用任何外部素材：冰箱表面是渐变 + 170 条确定性条纹 + 两处径向高光；
  二维码是确定性伪随机图块，卡上注明「图块为示意」
