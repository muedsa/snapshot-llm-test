# case-03 · 工具墙抽屉标签条（Tool-wall drawer labels）

- 画布：**1800 × 360 px**（服务真实响应 PNG 的 IHDR 读出，非设计稿标称）
- 交付物：`case-03/final.png`（服务原始响应字节）、`case-03/final.snapshot`（与该图逐字节一致的完整自包含 DSL）
- 素材情况：无。本件 100% 为 Snapshot DSL 绘制，未使用任何 <Image> 或外部素材。

## 场景

| 项 | 内容 |
|---|---|
| 受众 | 站在工具墙前、单手扶着抽屉拉手的找工具的人 |
| 媒介与观看环境 | 距柜子 40 cm，站着扫视，要在两秒内定位一把工具并知道它是否在架 |
| 使用者要完成的事 | 定位 + 可用性（绿=可借 / 铜=校准中或待校验 / 铁红=已借出） |

## 内容依据

自拟：5 个登记条目 + 8 个极简条目，编号 T-0001…T-1240 段内自洽。

> 以下全部机构、人名、地址、电话、编号与统计均为本次设计任务自拟的演示内容，未引用或主张任何真实机构、真实人物、真实统计或第三方背书。

## 视觉选择

这一件专门用来证明同一标签组件能在三种信息密度下都成立：A 登记标签给全部台账信息，B 标准标签给日常检索，C 极简标签只留编号与状态点

实际用到的 DSL 能力：同一 status dot 组件三种尺寸、同一字阶三档、线稿工具图标 illus_tool、chip 状态标签、按密度切换的列数。

## 实际自检

自定完成标准：

- (1) 三种密度的标签并排时状态色语义一致
- (2) 类别文字不压图标
- (3) C 档只保留能在 40 cm 读到的字段

实际查看与修改过程：v01 四张 B 标签的类别文字右对齐压住线稿图标 → v02 改列位后复看消除；交付前再次打开最终 PNG 核对。
