# case-09 · 谁在盯着一片海 · NOAA 观测状态板

## 场景与受众

- **定位**：状态板 / 幻灯片整页 / 打印参考
- **受众**：关心「这事到底有没有人在测」的公众；区域渔业与养殖从业者。
- **观看环境**：1700×1210 横版。
- **使用者要完成的事**：知道 NOAA 用哪三个指标、每个符号怎么读、七个海洋生态区的当前分类，以及这套表层观测看不到什么。

## 内容依据

全部内容来自 NOAA OA Program「OA Indicators Explained」（真实抓取，HTTP 200）。符号规则与七个区域分类的英文措辞均为原文。只有阿留申群岛与阿拉斯加湾两行填入了逐项百分位与趋势——因为只有这两区的逐项描述确实出现在取得的页面文本里。其余五行标注「未取」，没有依据文字描述反推符号。

## 视觉意图与手法

- **主要视觉主张**：既展示一套在真实运行的观测体系，也展示它的边界和本任务的记录缺口。
- **画面构成**：顶部一块符号规则面板（+ / − / ● / 箭头各带一句解释）；中部矩阵七行 × 三列指标 + 分类列（中英双行）；底部一块「这张板看不到什么」，照抄页面自述的局限。
- **实际用到的 DSL 能力**：矩阵表格 + 色条行标记 + pill 判定标签；`textAlign` 右对齐用于分类列。
- **素材**：无外部素材、无 `<Image>`，主体全部由 DSL 构造（`run-config.json` 的 asset_policy 为 `dsl_primary_with_supporting_assets`，本件未使用任何辅助素材）。
