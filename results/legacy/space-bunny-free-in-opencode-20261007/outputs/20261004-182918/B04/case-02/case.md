# case-02 · 基林曲线 · 一条被引用最多的实测曲线

## 场景与受众

- **定位**：编辑部参考页 / 可直接引用的数据页
- **受众**：新闻编辑、科学记者、任何要在稿子里放一条 CO2 曲线的人。
- **观看环境**：1600×1050 横版，编辑部内部参考页或印成 A4 横向附页。
- **使用者要完成的事**：找到可直接引用的端点数值、确认曲线连续性与量纲、知道记录里有真实缺口。

## 内容依据

主图 67 个点全部由下载的 NOAA GML 年均文件解析；增量条是同一文件逐年相减；400 ppm 交点为本图在相邻两年年均值之间线性插值的估计，已在图上标注「插值」。

## 视觉意图与手法

- **主要视觉主张**：让「引用」这件事变得可核查：数字、量纲、缺口、方法四件事都在同一屏。
- **画面构成**：左侧主图（真实曲线 + 20 ppm 网格）；2022–2023 的火山停测缺口用珊瑚色竖带标出；右侧不透明读数板给端点值；下方逐年增量条形图，2020 年后转色。
- **实际用到的 DSL 能力**：同 case-01，另加虚线由分段 `seg()` 生成而非 CSS dash；不透明面板用于避免曲线透过。
- **素材**：无外部素材、无 `<Image>`，主体全部由 DSL 构造（`run-config.json` 的 asset_policy 为 `dsl_primary_with_supporting_assets`，本件未使用任何辅助素材）。
