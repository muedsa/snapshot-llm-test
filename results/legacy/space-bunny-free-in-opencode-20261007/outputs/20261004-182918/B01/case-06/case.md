# case-06 · INFUSION · 儿童医院输液室的取号与叫号屏

- **尺寸**：1600 × 1200 横屏叫号屏
- **交付**：`final.png`（服务原始响应字节，未后处理）+ `final.snapshot`（产生该 PNG 的完整 DSL）
- **场景**：自拟「市儿童医院 · 输液中心」3 号输液厅二楼墙上那块屏。输液厅里坐着孩子和家长，屏幕挂在等候区正对面。
- **受众**：坐在椅子上抬头看的 4–10 岁孩子，以及站在旁边的家长。
- **希望用户完成的事**：孩子要能**一眼找到自己那个巨大的号码**；家长要能知道「前面还有几个、还要等多久、去哪个位子」。
- **媒介选择**：这个场景决定了几乎所有选择：屏幕远、明亮环境、观众是孩子且会不耐烦。所以**号是唯一的大字**（150px，全屏最大），配色走奶油纸 + 柔和糖果色，圆角全部 ≥24px，没有任何细线和小字——那些都是给成人办公场景的。
- **最有辨识度的视觉选择**：底部那四张「输液时可以做什么」的卡片，把「等待」变成一件可以一起做的事。每张配一个纯几何插画（书、鼓手、门、苹果），都用 DSL 基本形画出来——**这是全portfolio 里唯一一件把「装饰」当作功能使用的作品**：它不传达数据，它让屏幕在被等的时候也有用。
- **主要手法**：巨型叫号卡 + 剩余时长圆点进度环 + 输液位号队列 + 候诊区四块余量卡 + 儿童插画几何。全部圆角、大字号、低信息密度。

- **素材情况**：全部主体、排版、图形与图表均由完整 DSL 构造，服务真实渲染；未使用任何 `<Image>`、未引入外部图片素材，未做任何后处理补字或修图。品牌与示例数据均为本次设计演示自拟，不宣称是实际部署的客户作品。
- **数据说明**：本件内所有数值（时间、负荷、分数、计数、坐标、容量）均为本次设计演示自拟的示例数据，用于说明这套视觉语言能承载什么，不代表任何真实电网、书店、港口、烘焙场、观鸟记录、医院排班、车次编组、民宿经营、考古发现或场馆线路的真实记录，也不指向任何真实机构。
