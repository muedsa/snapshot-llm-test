# case-09 · ABYSSLOG · 深海考古打捞现场记录卡

- **尺寸**：1600 × 1000 横版记录卡
- **交付**：`final.png`（服务原始响应字节，未后处理）+ `final.snapshot`（产生该 PNG 的完整 DSL）
- **场景**：自拟深海考古项目「南海北部陆坡 遗址 B-7」第 3 潜次作业当天，潜水作业指挥在甲板上填的现场记录卡。
- **受众**：现场作业员当天填，之后由**一年后回来看这张卡的文物保护修复师**阅读。所以它必须用一年后还认得的语言写：深度剖面、地层柱、编目号——不是「刚才那个青碗」。
- **媒介选择**：现场记录单。甲板环境有低角度光、深色海水、戴手套填写，所以深底 + 黄铜金 + 珊瑚红，等宽字体承载全部编号和深度。
- **最有辨识度的视觉选择**：左边那根**地层柱**。五个色带自上而下按真实厚度成比例绘制，粗颗粒层用斜线阴影表示，两件文物用红线钉在各自的出水深度上，标签压在柱体内部而不是柱外——**柱子本身就是这件文物的「出土位置证据」**，谁接手都能复核。
- **主要手法**：深度剖面柱（按 cm 成比例）+ 地层斜线阴影 + 采样格平面图 + 探照灯扫掠扇形（叠在网格之上，说明这次作业照的是哪几格）+ 出水文物编目表 + 脱盐进度条。

- **素材情况**：全部主体、排版、图形与图表均由完整 DSL 构造，服务真实渲染；未使用任何 `<Image>`、未引入外部图片素材，未做任何后处理补字或修图。品牌与示例数据均为本次设计演示自拟，不宣称是实际部署的客户作品。
- **数据说明**：本件内所有数值（时间、负荷、分数、计数、坐标、容量）均为本次设计演示自拟的示例数据，用于说明这套视觉语言能承载什么，不代表任何真实电网、书店、港口、烘焙场、观鸟记录、医院排班、车次编组、民宿经营、考古发现或场馆线路的真实记录，也不指向任何真实机构。

## 实际自检
- 画布 1600 × 1000 横版记录卡，服务返回 HTTP 200，PNG 即响应体原始字节。
- `dsllib.warnings()` 输出 0 条（无文字溢出 / 框过小告警）。
- 元素数与全部渲染请求见根目录 `task-metrics.json`；DSL 与 PNG 一一配对。
- 已用图像查看工具打开最终图逐处核对：文字全部完整渲染、无重叠、无裁切、无溢出画布；曲线/色带/柱形的几何比例与脚本中的数值一致。
