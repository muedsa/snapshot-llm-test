# case-08 · INNSEASONS · 古镇民宿的节气与入住率月历

- **尺寸**：1400 × 1600 竖版月历
- **交付**：`final.png`（服务原始响应字节，未后处理）+ `final.snapshot`（产生该 PNG 的完整 DSL）
- **场景**：自拟民宿「汀步客栈」（浙江乌镇西栅，12 间客房）前台墙上那张 2026 年历。今天是 7 月 23 日大暑。
- **受众**：来住店的客人（抬头看）和前台自己（每天早上更新）。
- **希望用户完成的事**：客人判断「11 月来会不会太冷清」；前台判断「8 月上旬连续满房，5 月起就该收预订」。
- **媒介选择**：墙上手绘感的宣纸米色竖版挂历。**一年 365 天要用 12 个格子表达**，所以每格下方那条短墨条是「当日入住率」，不是装饰。
- **最有辨识度的视觉选择**：把二十四节气做成一个**真正的圆环刻度盘**，嵌在年历正上方的山形淡墨里。今天所在的「大暑」用朱红点出，其余 23 个按冷暖分竹青 / 朱红两色。**圆环不是图表，是钟面**——它回答「现在是什么时候」，和下面的月历回答「这一年过得怎么样」形成两个时间尺度。
- **主要手法**：月历格子 + 入住率墨条（绿=墨绿旺季 / 红=朱色旺季）+ 二十四节气刻度环 + 淡墨山形三叠 + 底部经营结论一行。

- **素材情况**：全部主体、排版、图形与图表均由完整 DSL 构造，服务真实渲染；未使用任何 `<Image>`、未引入外部图片素材，未做任何后处理补字或修图。品牌与示例数据均为本次设计演示自拟，不宣称是实际部署的客户作品。
- **数据说明**：本件内所有数值（时间、负荷、分数、计数、坐标、容量）均为本次设计演示自拟的示例数据，用于说明这套视觉语言能承载什么，不代表任何真实电网、书店、港口、烘焙场、观鸟记录、医院排班、车次编组、民宿经营、考古发现或场馆线路的真实记录，也不指向任何真实机构。
