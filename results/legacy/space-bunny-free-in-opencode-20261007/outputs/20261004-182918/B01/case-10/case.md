# case-10 · CRAGMAP · 攀岩馆的线路难度分布墙

- **尺寸**：1750 × 1150 横版场馆墙板
- **交付**：`final.png`（服务原始响应字节，未后处理）+ `final.snapshot`（产生该 PNG 的完整 DSL）
- **场景**：自拟攀岩馆「城西岩馆 西场」入口处的墙板。上午 10 点，馆里 38 个人。
- **受众**：同一块板前的两类人——刚进门的 V4 新手，和今天的值班设线员。
- **希望用户完成的事**：新手要找到「哪条 V3 现在没人上」；设线员要看出「V5 只有 3 条，V5 太薄了」。
- **媒介选择**：入口墙板，人站着看 3–5 秒。所以**一个面板只能回答一个问题**，四个面板各自独立成立。
- **最有辨识度的视觉选择**：难度梯本身就是直方图——**色带高度 = 线路条数**，于是「读分布」和「读难度轴」是同一个动作，不需要图例。七个色带（VB / V0–V5）各自就是一个柱，柱顶亮条是该等级的色标，柱内大数字是条数；每条难度同时带颜色**和**字母，色盲也能用。
- **第二选择**：右下角的场馆平面，每面墙里的堆叠色块是**这面墙自己的等级构成**，加上斜线阴影表示墙面，人拿着这张板就能走过去。左下的教学区故意不计入难度统计。
- **主要手法**：难度色带直方图 + 空闲/占用双态线路列表（颜色 + 圆点 + 文字三重编码）+ 场馆平面与墙体等级构成 + 教练手记 + 容量条。

- **素材情况**：全部主体、排版、图形与图表均由完整 DSL 构造，服务真实渲染；未使用任何 `<Image>`、未引入外部图片素材，未做任何后处理补字或修图。品牌与示例数据均为本次设计演示自拟，不宣称是实际部署的客户作品。
- **数据说明**：本件内所有数值（时间、负荷、分数、计数、坐标、容量）均为本次设计演示自拟的示例数据，用于说明这套视觉语言能承载什么，不代表任何真实电网、书店、港口、烘焙场、观鸟记录、医院排班、车次编组、民宿经营、考古发现或场馆线路的真实记录，也不指向任何真实机构。
