# case-04 · 一个 ↑ 箭头，撑不起三个决定

- **成品**：`final.png`（1240 × 1754，服务返回的原始响应字节，未做后处理）
- **DSL**：`final.snapshot`（与上面这张 PNG 同一次渲染的完整 DSL，可直接复现）
- **媒介与观看环境**：餐桌或床头打印一张 A4 贴冰箱上。纵向按指标横向分行，便于对照自己的化验单逐行找。

## 1. 用户原本卡在哪里

体检报告只有「实测值 + 参考范围 + ↑↓」。参考范围是 95% 的人群区间，所以 100 个健康人里必有 5 个带箭头；而真正决定「要不要治病」的医学决定水平（如 ALT 的 60 IU/L）和决定「要不要抢救」的危急值根本不印在报告上。

- **受众**：拿到年度体检报告、看到 1–3 个 ↑↓ 箭头就想上网查病的普通人及其家属。
- **希望他完成的事**：分清「参考范围」「医学决定水平」「危急值」三条线，知道哪个箭头可以观察、哪个应该 1–3 个月复查、哪个要马上找医生。

## 2. 原来的信息问题，和这张图怎么解决它

每个指标一行，行内从左到右是同一根数轴的三段：灰绿段是参考范围，琥珀段是医学决定水平，深红段是危急值/诊断阈值；本人实测值用一个带引线的深色牌插在轴上，落在哪一段、离哪条线还有多远，一眼可判。行右侧另给一张『化验单上真正印的（全部）』——只有关键项与箭头，用来说明报告其实只给了第一段。行下方给一句人话动作。底部是一张『看到箭头之后，按这张表做事』的三列表。

## 3. 视觉选择解决了什么

三条线用三种固定的颜色语言（灰绿=参考、琥珀=决定水平、深红=危急），四行完全复用同一套颜色，所以读第二行时不用重新学图例；本页整体用冷白底与克制的红，只有最右的『该做什么』一列允许出现红色文字。

## 4. 实际自检（逐条对照最终图核对过）

- 参考范围 = 95% 人群区间，5% 健康人天然落在外面——写在页眉
- ALT：参考 5–40，医学决定水平 20 / 60 / 300 IU/L，实测 47 落在 40–60 之间
- AFP：参考 <25，肝癌诊断阈值 400 µg/L（参考上限的 16 倍），实测 12 完全正常
- 空腹血糖：参考 3.9–6.1，诊断阈值 7.0 与任一次 11.1，危急值 ≤2.2 或 ≥22.2；实测 7.4
- 血小板：本院参考 125–350，另一实验室可能写 100–300——两段都画出来
- 四行各给一条可执行动作（观察 / 1–3 个月复查 / 立即就医）
- 「小安，34 岁」与三项实测值为自拟演示并声明

## 5. 取舍与不足

四个指标挤在一张 A4 里，数轴长度被压缩到约 860px；这意味着 47 与 40 的 15% 差距在纸上只有很短的视觉距离。我选择保留精确刻度而不是拉长轴，代价是『很接近参考上限』这件事需要读数字才能确认——所以每行都补了一句人话判断。

**真实来源（本次运行中引用）**
