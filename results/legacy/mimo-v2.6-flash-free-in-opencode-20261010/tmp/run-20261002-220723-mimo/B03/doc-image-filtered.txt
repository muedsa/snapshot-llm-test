与 ColorFiltered 嵌套
Section titled “与 ColorFiltered 嵌套” 
Skiko 的通用 ImageFilter
不提供可查询的输出边界。将 ImageFiltered 放在 ColorFiltered 内时，可通过 outputBounds
提供滤镜的完整输出范围，避免外层颜色滤镜影响边界之外的背景。高斯模糊可使用 com.muedsa.snapshot.widget.blurImageFilterBounds
：
ColorFiltered (colorFilter = ColorFilter. makeBlend (Color.RED, BlendMode.MULTIPLY)) { 
ImageFiltered ( 
imageFilter = ImageFilter. makeBlur ( 2f , 2f , FilterTileMode.CLAMP), 
outputBounds = blurImageFilterBounds ( 2f , 2f ), 
) { 
Container (width = 20f , height = 20f , color = Color.BLUE) 
} 
} 
blurImageFilterBounds(sigmaX, sigmaY)
要求两个 sigma 有限且非负，并分别按 ceil(3 × sigma)
向两侧扩张输入矩形。这里的 Rect
是 org.jetbrains.skia.Rect
，坐标相对于 ImageFiltered 本地坐标系。
其他滤镜可使用 outputBounds = { input -> /* 返回完整输出矩形 */ }
。回调应无副作用，并返回覆盖滤镜全部输出的有限矩形；范围过小会截断效果，过大则可能让更多透明区域被外层颜色滤镜着色。未提供或无法确定有效边界时会保留不裁剪回退；需要固定作用区域时，可在外层添加 ClipRect 等裁剪组件。
outputBounds
只用于外层颜色滤镜计算边界，不改变 ImageFiltered 单独使用时的裁剪行为。Parser 的 <ImageFiltered>
固定为高斯模糊，会根据 sigmaX
、 sigmaY
自动提供该边界，无需额外设置属性。
