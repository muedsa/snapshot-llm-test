## 一套参数化规则（无逐条硬改）

生成器 `tmp/.../A14/gen.ps1` 读取 `cards.json`，对每条记录走完全相同的流水线，
输出 8 份 DSL 与 `layout-vN.json`；任何一条不满足约束就直接 `throw`，因此"生成成功"
本身已经是一次几何自检。

**1. 画布与安全区** — 1200×630，安全边距 40，内容区 `40..1160 × 40..590`。
四边实测内容包围盒 `(40,40)-(1158,589)`（独立 QA 从像素测得）。

**2. 页眉** — 两个 20×20 圆角方块（青 + 琥珀）+ `Structure / Vision`（x=96, fs=24），
右端对齐 1160 的状态胶囊（y=40, h=40, fs=26, padding=22）。
**四种状态胶囊宽度统一 135px**，实底 + `#0B1220` 墨色文字，标签 = 符号 + 空格 + 状态文字。

**3. 标题区（共享盒）** — `y 104..396`（高 292），宽 1120，`START` 对齐，
**整块在区内垂直居中**，行高 = `round(size × 1.16)`。
字号阶梯 `112,104,96,88,80,72,64,56,48,40,36`（下限 36 由阶梯末端保证）。
守卫：块高超过区高、或块底 > 396、或与分隔线间距 < 8，一律抛错。

**4. 换行算法** — 两处关键设计：

- **分词** `Get-Atoms`：拉丁词连同尾随空格作为一个原子（可断点），每个全宽汉字独立原子，`——` 合并。
- **断行** `Find-Split`：穷举所有切成 n 行的方案，拒绝超宽行与以 `$NOSTART`（`，。：？！、）」》` 等）起头的续行，
  排序规则 = 优先断点（`$PREFBREAK` 或行尾空格，且首行 ≥ 0.70×可用宽）> 均衡度 > 更小的 k1。
  **`n=1` 时 `pref` 恒为 0**，因此"小字号排成一行"永远赢不过"大字号在标点处断成两行"。
- **取值** `Resolve-Text`：按阶梯从大到小走，对每个字号找能容纳的最小行数；
  有"≤2 行且自然断点"的结果立即返回，否则保留第一个 ≤2 行的结果。
- **宽度估算**：按字符类分档 `Get-Em`（全宽 1.0、大写 .74、小写 .58、数字 .58、空格 .30、其他 .40、非 ASCII .55、mono .62），
  再**按类乘像素系数**：全宽 1.05（Noto Sans CJK 全宽步进恰为 1em）、拉丁 1.10。
  系数记录在 `layout-vN.json` 的 `shared.measurement`。

**5. 分隔线** `y=404` — 状态色 240px 头（`40..280`）+ 中性尾 `#23324C`（`280..1160`），
把状态色从徽标一直带进版面中段。

**6. 页脚（底部锚定）** — 讲者块**底边正好落在安全线 590**：

两行讲者高 69px 同样落在 590，因此规则不可能溢出。

## 实际遇到的问题与修复

1. **PowerShell 把 U+2018/2019/201C/201D 当作引号定界符** → 标点集合改用 `[char]` 码位构造。
2. **`ConvertFrom-Json` 把 JSON 数组作为单个管道对象返回** → 先赋值再用 `-is [array]` 归一。
3. **数组字面量里逗号比 `+`/`-` 优先级高** → 先把运算数算进临时变量。
4. **`$line` 覆盖 `$LINE`（变量不区分大小写）** → 8×400 的根因，改名后全绿。
5. **断行规则先后迭代 4 次**：单一平坦宽度系数 → 按字符类分档；无自然断点偏好 → 加标点偏好；
   单行结果压过更大的断行解 → `n=1` 的 `pref` 置 0。
6. **校验器自身两个 bug**（矩形相交判据写反、徽标检查比错边）→ 改成与生成器一致的重叠宽高法，
   **只改校验器，不动作品**。
7. **看图通道旧帧** → 见上；交付文件经字节与独立 QA 双重确认，问题属运行环境而非作品。
