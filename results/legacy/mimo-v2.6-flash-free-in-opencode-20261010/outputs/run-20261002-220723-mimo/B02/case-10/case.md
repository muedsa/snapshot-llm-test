# case-10 · 认养滩涂捐赠页

- 作品名：你的 30 元，够半亩滩涂吃一个月 / ADOPT A MUDFLAT 月捐页
- 尺寸：1080 x 1526（长图，公众号/小程序详情页）
- 主图：`final.png`（191282 字节）｜ DSL：`final.snapshot`（12356 字符 / 12986 字节）

## 受众与使用场景
被前面任一触点打动、准备掏钱的本地居民与企业。手机竖屏长图，从上往下滑，
在第三屏（价格卡）做出「选哪一档」的决定。

## 使用者要完成的事
理解钱花在哪（清互花米草 / 校潮位计）→ 比较三档的月费与实际权益 →
确认「随时能停」→ 扫码完成首月认养。

## 内容依据
自拟演示数据：三档 ¥30 护滩人 / ¥68 潮汐伙伴 / ¥128 守望者，
对应已有认养 **214 / 96 / 31 人**（合计 341 人，与 case-09「新认养 341 人」一致，
且 214×30 + 96×68 + 31×128 = 16,916 元/月 ≈ case-09 的「每月约 1.7 万元」）；
权益面积递增 **0.5 / 1.2 / 2.5 亩**（与主标题「够半亩滩涂吃一个月」一致）；
标题下两行说明写明互花米草清理与潮位计校准；三条说明交代「不用于人员开支 /
季度公示 / 回复改档」；页脚标 `演示数据 DEMO`。

## 主要视觉主张
纸面浅底 + 顶部 10/4px 双压边立住「正式文书」感；46px 双行主张配橙色短杠；
三张 950×200 的白卡纵向排列，卡内用「价格列 ｜ 竖分隔 ｜ 权益列」的固定结构，
横线与竖线在 (385, y+128) 交成一个完整 L 角，把价格与权益锁在同一格里；
唯一一张橙色 CTA 横贯整幅，是全页第二强的色块。

## 实际使用能力
`ShadowBox` 投影卡、`Box` 竖/横分隔线构成的 L 角、`Chip` 自适应胶囊（含「推荐」贴角）、
`Eyebrow`、`RuleBand`、`TLines` 手动断行、`FooterLine`、`Mark` 人字鸟阵。

## 完成标准（自定）
1. 三档价格、人数、面积严格递增且互不矛盾；
2. 价格列与权益列之间必须有可见的分隔结构，L 角闭合；
3. 三张卡结构一致，「推荐」只出现在第一档；
4. CTA 与三条说明不出血，`演示数据 DEMO` 可见。

## 实际自检与修改
- `B02-c10-r1`（200，4476.1 ms）→ 看图：三档价格卡、CTA、免责声明、页脚均成立；
  但价格列（x≈100..300）与权益列（x=430）之间 130px 空档没有任何分隔，
  卡片读起来左右脱节 → 在 x=385 加一条竖分隔（y+30..y+128）。
- `B02-c10-r1-retry`（200，2788.5 ms）→ 看图：竖线把两列分开、结构清楚；
  但竖线终点 y+128 与横线起点 x=430 之间空 45px，两笔画悬空不相接 →
  横线起点 430 → 385、长度 555 → 600，与竖线构成完整 L 角。
- `B02-c10-r3`（200，2862.8 ms）→ 看图：竖线与横线在 (385, y+128) 正确相交；
  三张卡结构一致；CTA 与页脚无裁切 → 通过。
- `B02-c10-r6`（200，3628.2 ms，PNG 191282 B）→ 跨件一致性
  （`ite-B02-consistency-audit`）三处：主标题「够一亩滩涂吃一周」→ **「够半亩滩涂吃一个月」**
  （与 ¥30 档「每月清理 0.5 亩」对齐）、eyebrow「认养一亩滩涂」→ **「认养滩涂」**、
  守望者权益「包一亩滩涂全年维护」→ **「每月清理 2.5 亩与全年巡护」**
  （使三档 0.5 / 1.2 / 2.5 亩严格递增，此前 128 档反而比 30 档少）→
  看图确认标题与档位一致、三档面积递增、L 角闭合、CTA 与三条说明不出血 → 4 条标准全部通过。
