# case-09 · 东港站到发信息看板

- 作品名：东港站 EAST HARBOR STATION 到发信息看板（屏号 HGT-02）
- 尺寸：1920 x 480（车站候车区超宽条屏，16:4）
- 主图：`final.png`（124832 字节）｜ DSL：`final.snapshot`（9365 字符）
- 主导手法：**等宽数字 `fontFeatures="+tnum"`**（`车次 / 计划 / 预计 / 站台 / 时钟` 五类数值全部开启）
- 最终轮次：round 1（1 张基线 + 1 条"经读图直接通过"的判定）

## 受众与使用场景
候车区与检票口前抬头找车次的旅客，3–10 米、站着扫一眼；
屏幕本身嵌在高挑高大厅里，环境比屏幕亮。条屏只有 480px 高，
所以信息只能是**一行一条、横向排开**的表格，不能有需要滚动的内容。

## 使用者要完成的事
在 5 行里找到自己的车次（G7312 / D2244 / K1180 / G7596 / Z204）→
横着读过去拿到 计划时间 → 预计时间 → 站台 → 状态 → 备注；
一眼分辨出**哪一行需要改主意**（K1180 预计 14:45、晚点 4 分，红色）。

## 内容依据
自拟演示数据：虚构「东港站」5 趟列车（始发/终到站名、计划与预计时刻、
站台号、状态、席位备注），页脚 `数据每 30 秒刷新 . 站台信息以车站广播为准 . DEMO 演示数据`
与 `屏号 HGT-02 / 版本 3.1.7`。站名、车次、时刻、站台均为虚构，
不对应任何真实车站或时刻表；看板本身也自标 `DEMO`。

## 主要视觉主张
**一张表，颜色即状态**：顶栏深一档把站名、信息类型、秒级时钟分成三段；
表头用 `letterSpacing=4` 拉开的极小字（16px）压在分隔线上方，把宽度让给数据；
正文五行只有两种字体语言——`车次/站台/时钟` 用等宽字体 + `tnum`，
`始发终到/备注` 用无衬线。**数值列全部开 `+tnum`**，使 `14:12 / 14:26 / 14:41 / 14:50`
四列的时间上下严格对齐成竖线，`06 / 03 / 11 / 02 / 08` 三个字符宽一致，
远看时列边界不会因为字宽抖动而锯齿。状态是唯一的高饱和元素：五种状态五种颜色，
既做药丸底色也做描边，`晚点 4 分` 用红、`检票中` 用青、`到站` 用琥珀。

## 实际使用能力
`fontFeatures="+tnum"`（探针 p08 实测：同一串数字右边界 294px → 325px，**确实生效**）、
`fontFamily` 等宽字、药丸 `border + borderRadius + alignment`、
`TXW` 分栏网格（72 / 300 / 840 / 1000 / 1160 / 1320 / 1660）、
`letterSpacing` 表头、行分隔线（矩形）、右对齐列。

## 完成标准（自定）
1. 五列数值的左 x 严格一致（72 / 840 / 1000 / 1160），行间不漂移；
2. 数值列开 `+tnum` 后同行各行的数字宽度一致（可由 p08 的实测宽度佐证）；
3. 五行 + 表头 + 上下分隔线全部落在 `y=78..432` 之内，页脚不出血；
4. 状态颜色与其文字语义一致（红=晚点、青=检票中、灰=正点、琥珀=到站、蓝=候车）；
5. 画面可见 `DEMO 演示数据`。

## 实际自检与修改
- `B03-case-09-r1`（200，3367.6 ms，PNG 124832 B）→ 读图：**车次行距与到发分区成立**；
  逐项核对七列 x 坐标、行距 58、分隔线 `y=108 / 176 / 234 / 292 / 350 / 408 / 432`、
  页脚 `y=444..470` 均在画布内；字节与日志一致、尺寸 1920x480 == DSL。
- 复核 `+tnum` 的前提：探针 p08 已实测该特性在所选字体上**确实改变字宽**（294 → 325），
  所以本作对它的依赖不是空谈。
- 判定：**未发现需修正的缺陷，保持 round 1 为最终稿**（记入
  `ite-B03-c09-v1`，明确标注「无改版」而不虚构一次不存在的渲染）。
- 尺寸核对：PNG 1920x480 == DSL 首个 Container 宽高。

## 素材情况
纯 DSL，无外部素材；分隔线、药丸、表头全部由矩形与文字构造。

## 虚构信息声明
站名、车次、时刻、站台、席位、屏号、版本号均为虚构演示数据；
不构成任何真实乘车信息。

## 独立性说明
十件中唯一的**公共信息条屏**（3–10 米、超宽 16:4、每行一条记录）；
它检验的是「多行多列在远距离下能否对齐」，与 case-04 的单值大字屏刻意相反。
