# case-07 · 夜航登机牌

- 作品名：潮汐航空 TIDE AIR TA 216 —— 深圳 SZX → 大阪 KIX 登机牌
- 尺寸：1748 x 760（航空标准比例的横向凭证）
- 主图：`final.png`（140684 字节）｜ DSL：`final.snapshot`（13058 字符）
- 主导手法：**渐变平铺纹样**（`gradientType=REPEAT` + `gradientRotation` 斜向条纹）
- 最终轮次：round 4（1 张基线 + 3 次视觉迭代）

## 受众与使用场景
值机后拿到纸质登机牌、或在手机上出示给安检口的旅客与地勤，0.3 米手持、
强光/夜航灯光下。凭证必须让人在**一次低头**里读完出发到达、时间、登机口、座位。

## 使用者要完成的事
确认航班 TA 216 与航线 SZX → KIX → 记住起飞 22:40 / 到达 02:15（次日 +1）→
找到登机口 B12、座位 14A、登机时间 22:05 → 过检时把右侧存根交给地勤。

## 内容依据
自拟演示数据：虚构「潮汐航空 TIDE AIR」航班 TA 216，深圳宝安 SZX 22:40 起飞、
大阪关西 KIX 02:15 到达（次日 +1）、航程 03:35、机型 AIRBUS A320、日期 2026-11-19、
登机口 B12、座位 14A、登机 22:05、乘客 CHEN/YI-HAN、常旅客 TIDE-8842170、
存根编号 0481 2216 0119；主区与存根各一处 `DEMO`、页脚
`DEMO . 演示数据 . FICTIONAL BOARDING PASS`。航司、航班、姓名、票号全为虚构。

## 主要视觉主张
**条纹出现两次、各司其职**：底页是深蓝底上的暗色斜纹（`REPEAT` 平铺，斜向重复到整页），
压住空白又不抢内容；卡内顶部一条橙黄斜纹带是同一套条纹的高饱和版本，作为整张牌的
「航司色带」。主体用四列网格（96 / 364 / 632 / 900）严格对齐：左两列是 SZX→KIX
的起降对，第三列是日期/登机口/座位，第四列是航程/机型/登机/常旅客。
虚线打孔线在 x1176 把牌切成正票与存根；存根里「旅客姓名」被放在**右上角右对齐**、
日期也右对齐，与左边的 `14A` 大字形成左右平衡，条码拉满存根整宽 440px。

## 实际使用能力
`Grad gradientType="REPEAT"` 平铺斜纹、`gradientRotation` 旋转条纹、
虚线（短矩形序列）、四列 `TXW` 标签值网格、药丸胶囊（`Container borderRadius`）、
条码（不等宽矩形序列）、`TXW textAlign=RIGHT` 右对齐列。

## 完成标准（自定）
1. 斜纹在底页与色带上都是**重复**的（不是拉伸一次的渐变）；
2. 四列 x 坐标（96 / 364 / 632 / 900）在相邻行之间严格对齐，无 20px 级错位；
3. 存根内容左右平衡，不留出大片空白；条码右端不超过存根右界 1656；
4. 正票与存根信息（航班号、日期、座位、票号）两处一致；画面可见 `DEMO`。
