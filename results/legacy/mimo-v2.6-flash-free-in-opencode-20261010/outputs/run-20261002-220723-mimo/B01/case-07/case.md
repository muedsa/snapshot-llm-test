# case-07 · 围棋棋谱解说图

- 作品名：围棋序盘 20 手棋谱解说图
- 尺寸：1200 x 1200（正方形）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
围棋教室学员与讲义读者。用于教室投影讲解与 A4 方形讲义印刷，观看距离 0.5–3 米。

## 使用者要完成的事
按序号读出序盘 20 手的落点坐标，理解三段解说（序盘构思 / 定式选择 / 关键手），
并从结果栏核对最终目数。

## 内容依据
自拟演示棋谱（虚构棋手「沈砚 七段 vs 顾青 五段」、虚构对局），画面标 `演示数据 DEMO`。
坐标按 19 路标准记谱法计算：列用字母 `ABCDEFGHJKLMNOPQRST`（跳过 I），行号 = 19 − 行索引，
因此星位 D16 / Q16 / D4 / Q4 与天元 K10 均落在标准位置；目数与贴目自洽
（黑 71 + 白 66 + 贴 6.5 = 白 72.5，白胜 1.5 目）。

## 主要视觉主张
木色棋盘 + 精确坐标系统：20 手全部带序号，坐标与解说文字互相对应；
解说区用「彩色竖条 + 标题 + 手动分行的三行正文」保持中文排版整洁（避免行首标点）；
结果区用黑白两段条形图把目数对比可视化。

## 实际使用能力
Container/Stack/Positioned；木纹用 LINEAR 渐变；19 路网格由等距 HLine/VLine 序列；
shape=CIRCLE 棋子与星位；棋子序号 Text 居中；重点手用圆环（border CIRCLE）；
TLines 手动控制中文断行；两段条形对比。

## 完成标准（自定）
1. 棋盘 19x19 格距均匀，边距对称；
2. 20 手序号与坐标、解说一致；
3. 解说正文每行不以标点开头，且不超出文本框；
4. 结果数字自洽（目数 + 贴目 = 分差）。

## 实际自检与修改
- `B01-c07-r1`（200，3925 ms）→ 看图发现内容层面的问题：
  解说提到「三三侵角」但盘面上第 6 手是小飞挂；「黑先占右上与右下星位」与实际
  （黑占上边两角 D16/Q16、白占下边两角 Q4/D4）不符；结果栏「白胜 1.5 目」与
  「白中盘胜」互相矛盾，且 41/42.5 目与 1.5 目分差对不上。
- `B01-c07-r2`（200，4375 ms）→ 改写解说与结果：
  解说改为与盘面对应的 D16/Q16/Q4/D4、左上 6-8 手、右下 9-12 手、13 手天元、19 手拆边；
  结果改为黑 71 / 白 66 / 贴 6.5 → 白 72.5，白胜 1.5 目，条形图比例同步改 201:187 →
  复看：内容自洽，但中文自动换行出现「行首逗号」。
- `B01-c07-r3`（200，4832 ms）→ 改用 TLines 手动分行；生成时 `Fit` 报 2 处超宽
  （need 448 > 364、373 > 364），该版本标记为**未完成迭代**（渲染成功但文字超框）。
- `B01-c07-r4`（200，2802 ms，239177 B）→ 拆分超宽行（每块固定 3 行、每行 < 364px）
  → `problems = 0` → 局部放大核对（`zoom-07.png`，2x）：三段解说各 3 行、行首无标点、
  无溢出，结果栏数字自洽 → 通过。
