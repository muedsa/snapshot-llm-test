# case-05 · 独立乐队霓虹巡演海报

- 作品名：独立乐队「低保真花园」霓虹巡演海报
- 尺寸：800 x 1200（2:3 竖版海报）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
独立乐队乐迷、演出主办方与场地方。用于地铁灯箱、Livehouse 竖版屏、社交平台
竖图分享；观看距离 1–8 米，先看到「氛围」，再走近看场次与二维码。

## 使用者要完成的事
被海报吸引后，读到巡演主题与主视觉、确认城市/场地/日期，并扫码购票。

## 内容依据
自拟演示乐队名、巡演主题与 4 场城市场次，画面标 `演示数据 DEMO`；二维码为
「示意图形」（DSL 绘制的方块阵），不指向真实票务链接。

## 主要视觉主张
霓虹夜色：品红-青蓝双主色 + 多层发光叠字 + 扫描线栅格，营造地铁灯箱的
高饱和夜间质感；上半部用超大标题与发光描边承担远距离识别，下半部把「扫码购票」
与二维码合成一个独立的行动区，让 CTA 与图案互不侵占。

## 实际使用能力
Container/Stack/Positioned；多层 Text 叠印（同坐标多层营造描边/发光）；
Text `textShadow` 发光；shape=CIRCLE 光晕；LINEAR 渐变；SCANLINE 类栅格由
等距细矩形序列构成；二维码方块阵由 Positioned 矩形序列构成。

## 完成标准（自定）
1. 主标题在缩略图下仍可辨认；
2. 4 场场次时间/场地/票价三列对齐；
3. 二维码与「扫码购票」按钮不重叠、各自留白；
4. 底部版权与 DEMO 标识不裁切。
