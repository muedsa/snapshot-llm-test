# case-09 · 潮汐与海泳安全牌

- 作品名：今日潮汐与海泳安全牌
- 尺寸：1080 x 1350（4:5 竖版）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
海滨浴场游客与救生员。用于浴场入口立牌 / 闸机旁竖屏，户外强光下、3–6 米距离
扫视，需要先给结论（能否下水）再给依据（潮汐曲线与安全提示）。

## 使用者要完成的事
判断现在能不能下水、今天的高潮/低潮时刻与潮位、浪高水温风力等海况，以及
3 条必须遵守的安全约束与救生员值班时间。

## 内容依据
自拟演示潮汐数据（虚构「蓝湾海滨浴场」），画面标 `演示数据 DEMO`。
潮位曲线由 4 段余弦插值生成：每段 `v = vm + amp*cos(π·u)`，过高潮/低潮极值点，
按 0.25 h 采样 96 段；像素换算 `y = 566 − (v/4.5)×236`、`x = 140 + (t/24)×830`，
与网格刻度共用同一套比例。当前时刻 15:20 对应潮位 1.9 m（与页眉一致）。

## 主要视觉主张
深海青绿底 + 结论前置：顶部渐变条直接给出「当前 · 可下水」的判断卡；
主面板是 24 小时潮位面积图——填充块 + 顶部亮点序列构成曲线（DSL 无 line 元素，
故用密集圆点近似曲线），高/低潮用橙点 + 深色标签牌标注，当前时刻用红色竖线 + 红点
贯穿画面；下方潮时表/海况/安全提示三块面板并列，编号方块带不同颜色强调优先级。

## 实际使用能力
Container/Stack/Positioned；LINEAR 渐变页眉；shape=CIRCLE 点阵曲线与极值点；
VLine/HLine 网格；borderRadius 面板与标签牌 + border；Text 多级与右对齐。

## 完成标准（自定）
1. 曲线极值点与标签牌的时刻/潮位一致；
2. 曲线填充无可见接缝（相邻填充块重叠 1.4px 抵消抗锯齿缝隙）；
3. 红色当前线与红点落在曲线上；
4. 首末 x 轴标签不与 y 轴标签相撞；
5. 所有面板底边不超出画布。

## 实际自检与修改
- `B01-c09-r1`（200，4392 ms）→ 看图发现：面积填充由 96 个独立矩形拼接，
  抗锯齿在相邻矩形间留下可见竖向接缝。
- `B01-c09-r2`（200，3175 ms，191533 B）→ 填充块宽度加 `+1.4px` 相互重叠 →
  复看：填充成为连续色块、曲线圆点连续、极值标签与当前时刻线位置正确，通过。

## 素材情况
纯 DSL，无外部素材。

## 虚构信息声明
浴场名、电话、海况与潮汐数据均为虚构演示；不作为真实航行/游泳依据。
