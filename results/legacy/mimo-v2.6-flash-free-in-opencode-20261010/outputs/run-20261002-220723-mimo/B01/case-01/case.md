# case-01 · 末班地铁到站屏

- 作品名：末班地铁 · 末班车到站信息屏
- 尺寸：900 x 1600（竖屏，约 9:16）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
深夜通勤乘客与站台值班员。用于地铁站台竖屏 LCD 到站信息屏（或乘客手机端查询页），
观看环境是灯光较暗的地下站台，站位约 2–5 米，需要在几秒内读到关键信息。

## 使用者要完成的事
判断「末班车几点到、往哪个方向、我这一侧站台对不对、还赶不赶得上」，并在发车前
走到正确的候车位置。

## 内容依据
自拟演示数据（虚构线路「8 号线」、虚构站点、虚构时刻表），画面内已标 `演示数据 DEMO`。
不引用任何真实运营方的实时数据。

## 主要视觉主张
深色荧光站台屏：黑底 + 线路荧光色带 + 超大方向字，用色带的粗细和亮度差建立
「线路 > 方向 > 时刻 > 备注」的四级信息层级；两侧用对称的箭头区块把「本次列车 /
下一班」的对比做实，让远距离扫视时先命中最大的那块。

## 实际使用能力
Container/Stack/Positioned 栅格；纯色 Box 与 borderRadius；shape=CIRCLE 徽标；
多级 Text（含 bold）；LINEAR 渐变分隔带；Border（width style color）；点阵连线。

## 完成标准（自定）
1. 末班时刻、方向、站台号三要素在缩略图尺寸下仍可辨认；
2. 无文字溢出容器、无元素遮挡、无空洞留白；
3. 数据自洽（到站时间 < 发车时间，前后班次间隔合理）；
4. 演示数据标识可见。
