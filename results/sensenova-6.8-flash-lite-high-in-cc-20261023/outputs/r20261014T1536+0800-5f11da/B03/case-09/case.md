# B03 case-09: 等高线地图（Contour Map）

## 基本信息

| 项目 | 内容 |
|------|------|
| 中文标题 | 等高线地图 |
| 英文标题 | Contour Map |
| 尺寸 | 1600 × 1200 px |
| 技术主题 | 地形数据可视化 |
| 核心技法 | 网格高度场生成、等值线追踪、颜色编码海拔 |

## 场景与受众

- **受众**：地理信息系统分析师、城市规划师
- **场景**：GIS地图展示、地形分析、城市规划
- **内容范围**：40×30网格高度场，10级等高线，3个山峰标记

## 视觉选择

- **高度场**：4个高斯中心模拟山峰（0.3,0.4 / 0.7,0.6 / 0.5,0.2 / 0.2,0.8）
- **10级等高线**：从10%到100%，蓝色渐变（深蓝→浅蓝）
- **3个山峰**：山峰A(1200m)、山峰B(1500m)、山峰C(800m)，金色/橙色标记
- **透明度**：0.6，营造地形层次感

## 实际看图记录

- **渲染结果**：HTTP 200，100295 bytes，1689 parts
- **视觉检查**：地形层次分明，山峰位置准确，颜色梯度清晰，图例完整，整体呈现GIS地图质感
