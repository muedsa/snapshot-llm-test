# B04 · Snapshot DSL 使用说明

## 概述

B04题使用Snapshot DSL创建太阳系八大行星视觉特辑，共10件独立作品。所有DSL均通过`b04_kit.py`工具包构建，使用统一的`Doc`类封装DSL生成逻辑。

## 技术栈

- **DSL构建**: Python脚本，通过`b04_kit.py`封装
- **渲染服务**: open-snapshot (snapshot.muedsa.com)
- **输出格式**: PNG + .snapshot (完整DSL)
- **尺寸**: 1600×900 (6件) / 1400×1400 (4件)

## DSL设计模式

### 1. 色彩系统

```python
# 行星固定配色
planet_colors = {
    "水星": "#B8860B", "金星": "#FF8C00",
    "地球": "#4169E1", "火星": "#CD5C5C",
    "木星": "#DEB887", "土星": "#F4A460",
    "天王星": "#87CEEB", "海王星": "#4169E1"
}
```

### 2. 布局类型

- **柱状图** (case-03, 05, 07, 09): 网格线 + 数据柱 + 标签
- **气泡图** (case-04, 06): 对数尺度，气泡大小表示数值
- **圆形比例图** (case-01): 按直径比例绘制行星
- **螺旋布局** (case-02): 行星沿螺旋线分布
- **堆叠条图** (case-08): 大气成分百分比堆叠
- **时间线** (case-10): 水平时间线 + 卡片分区

### 3. 标签放置策略

- **柱状图标签**: 数值在柱顶上方，名称在x轴下方
- **气泡图标签**: 数值在气泡中心，名称在气泡下方
- **螺旋图标签**: 行星右侧固定偏移（避免重叠）
- **堆叠条标签**: 仅在条段宽度>40px时显示

### 4. 质量门禁

```python
gates = K.dry_run(doc, "case-XX", 12, [], max_parts=9000)
# 最小字体12px，最大部件数9000
```

## 数据源

所有数据来自 [NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) (2025-03-18)，包含：
- 直径、质量、密度、距离
- 自转周期、公转周期、卫星数量
- 表面温度、大气成分、引力
- 发现历史

## 已知问题与修复

1. **case-02 内行星标签重叠**: 原始螺旋布局导致水星、金星标签重叠
   - 修复: 改为螺旋布局，标签在行星右侧固定偏移
   
2. **case-05 地球参考线标签重叠**: "地球自转24小时"与海王星柱标签重叠
   - 修复: 标签移至线下方，简化为"地球 24h"

3. **case-06 气泡标签重叠**: 数量"X"和单位"颗"分开显示导致重叠
   - 修复: 合并为单个标签"X颗"

4. **字体过小**: 多件作品中note/atype/pct标签为11px
   - 修复: 统一提升至12px
