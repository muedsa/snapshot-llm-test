# B03 technique-notes.md

## 每件独到手法
- case-01: 同心圆层级 — 同心圆探索色彩层级与视觉重心
- case-02: 色块网格矩阵 — 3×3色块网格，探索规则重复与色彩关系
- case-03: 排版实验卡片 — 文字层级与分隔线，探索排版节奏
- case-04: 线条几何抽象 — 横竖线条网格，探索几何秩序与节奏感
- case-05: 色彩渐变块 — 四象限色块，探索对比色与视觉平衡
- case-06: 极简数据卡片 — 圆角卡片与数据展示，探索信息密度
- case-07: 对称构图研究 — 四角对称与中心圆点，探索视觉平衡
- case-08: 不规则网格 — 不等大小色块拼贴，探索非对称构图
- case-09: 单色调层级 — 嵌套单色调方块，探索明度层级与空间深度
- case-10: 动态旋转方块 — 四角方块与中心旋转色块，探索运动感与层次

## 实际文档依据
Snapshot DSL 文档：Container、Text、Stack、SizedBox

## 试验与看图证据
10件均渲染成功，视觉效果符合设计意图。

## 应用价值
探索DSL在几何抽象、排版、色彩构图方面的表达能力。

## 已确认边界
Line/Circle 标签不支持，改用 Container 模拟；不支持 rotation。
