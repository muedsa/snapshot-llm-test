# 项目说明 — 绿叶社区图书馆

## 项目问题
社区图书馆缺乏统一的视觉识别系统，用户在不同接触点（外墙、会员卡、收据、海报等）上难以快速识别图书馆品牌。

## 解决方案
为绿叶社区图书馆设计一套10件作品的视觉生态，涵盖线下和线上所有主要触点。

## 视觉系统
- 主色: #16653A (森林绿)
- 强调色: #D97706 (麦穗橙)
- 背景: #F0FDF4 (浅绿)
- 字体: Noto Sans CJK SC,Inter

## 触点清单
- 外墙招牌 (1000×400)
- 会员卡 (850×540)
- 借阅收据 (300×500)
- 活动海报 (600×800)
- 图书书签 (150×550)
- 还书提醒卡片 (400×250)
- 志愿者胸卡 (350×220)
- 捐赠箱贴纸 (300×300)
- 社区公告板模板 (700×500)
- 手机小程序界面 (375×812)

## 假设与边界
- 纯DSL构造，无外部图片
- 未进行真实用户测试
