# 叠光 / Layerlight 品牌方向选择说明

两个预览方向：方向A为“对角线双层叠加”（外框深色圆角正方形，向左上与向右下各叠一层圆角正方形，中心以橙点收束）；方向B为“放射菱形叠加”（外框外，中心一个45°旋转正方形菱形，内嵌小圆角正方形与点）。

方向A与方向B差异：A以轴对齐正方形错位叠层，负空间形成清晰的L形轮廓，强调“信息叠加后仍然清晰”的层次关系；B以旋转菱形与同心正方形，视觉更柔和但边缘为斜线。

实际预览选择方向A：在32x32缩略检查中，A的轴对齐边缘与L形负空间保持较高辨识度，橙色中心点在缩小后仍作为聚焦点可见；B的45°旋转菱形在32x32下边缘抗锯齿明显，轮廓容易模糊成一点，层次关系弱于A。因此以A为最终方案。

小尺寸改进：将中心圆点半径从20px放大至适合32x32的可见比例（约占画布6%），外框与内层的色阶对比保持充分（深蓝/中蓝/白/橙），确保在32x32时轮廓与关键负空间仍可辨认；各应用（横幅、海报）中的图标均按同一DSL几何重绘，未嵌入渲染PNG。
