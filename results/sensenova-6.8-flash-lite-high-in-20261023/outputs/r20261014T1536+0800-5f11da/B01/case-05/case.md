## 内容范围与数据声明

12×8 街区网格、6 个声源（工地 88、地铁 86、物流 85、夜市 84、学校 82、餐厅 80 dB(A) @10 m）
及两时段活跃集合，**全部为自拟演示数据，非真实监测值，不宣称实际部署**。页脚同样声明。

声场不由人填写，由脚本算出：

```
逐源衰减  Li(x) = L0i − 20·log10(max(d_i, 10) ÷ 10)
多源叠加  L(x) = 10·log10( Σ_active 10^(Li ÷ 10) )
         ——— 非相干声能相加，不是 dB 线性相加
分级      <55 / 55-59 / 60-64 / ≥65 dB → CL0 / CL1 / CL2 / CL3
影响半径  reach65(L0) = 10^((L0−65)÷20)·10 m
户数      确定性伪随机逐格求和，超标户数与格数同向变化
```

门禁 `case-05-c02` 用「等强度源每多一个多 3 dB」的解析性质做独立校验：
3 个 80 dB 源 = 80 + 10·log10(3) = 84.77 dB，线性相加 240 dB 被拒绝，差 155.2 dB。

## 视觉选择与理由

1. **同一张街区图画两次，左早右晚。** 声场用反距离衰减的等值圈叠加出，
   差异一眼可读：哪片街区从绿变红就是施工时段挪走能救的。
2. **65 dB 环线用衬底 + 芯两层。** 单一颜色无法满足「对 CL3 底 ≥3.0 且对白字 ≥3.0」
   （需要亮度既 ≥0.343 又 ≤0.300，物理上不可能），所以衬底 `#FFF6E8` 铺满整圈
   保证超标格可见（7.50:1），芯 `#5C3D18` 保证低档位可见（3.17:1）。
3. **环线画整圈 + 数字遮罩，而不是打断。** 打断的环在 R < 36.4 px（声源在格子角落，
   相邻 4 格中心距声源 0.5×CELL×√2）时只剩 4 段短括弧，读不出是影响半径。
   第六版改为画整圈 0→2π，数字底下压一块与格子底色同色的遮罩（外扩 MASK_PAD=2.75 px），
   环是连续圆，遮罩只是把数字底下的环盖住。
4. **遮罩坐标取整到像素边界。** 浮点坐标会让渲染器抗锯齿遮罩边缘，
   产生遮罩色与环色的混合像素（50% 衬底 + 50% CL3 = `#C6947C`，对白字只有 2.6:1），
   框外 1-2 px 就落在这些混合像素上。取整后遮罩是全实心矩形，边缘与像素对齐。
5. **四档色为同色相单色渐变。** 亮度单调 0.876 → 0.596 → 0.288 → 0.081，
   格内文字对比 14.08 / 9.83 / 5.14 / 8.03，全部 ≥ 4.5。
6. **颜色从来不是唯一的判定通道。** 192 个整数 dB 全部印出；
   超标格有描边；声源有单字标记 + 名称 + 级别数；分级图例印出四档色块与 dB 区间。
7. **图例限值文案按法规校正。** 65 dB 是 GB 3096-2008 中 3 类声环境区的昼间限值，
   不是任何区的夜间限值；图例改为「示例阈值统一取 ≥65 dB，非实际限值」。

## 已知限制

- 声源位于格子角落（路口），相邻 4 格中心距声源 0.5×CELL×√2 = 36.4 px；
  R < 36.4 px 时环线落在 4 个数字框内部。第六版用遮罩解决，但遮罩必然在
  数字位置遮挡环的一部分，读者看到的是带小凹口的圆而不是完整圆。
  这是「环可见」与「数字可读」之间的几何约束，不是设计缺陷。
- 65 dB 阈值是示例值，非任何功能区的实际限值。实际噪声标准按 GB 3096-2008
  分区（0-4 类）分昼夜，本件为了简化讨论只取一个阈值。
- 声场模型用反距离衰减（点源、自由场、无遮挡），没有考虑建筑遮挡、
  地面吸收、气象条件等真实因素。议事会讨论用此模型识别「哪条街区最响」
  是合理的，但不能据此做精确的噪声合规判定。
- 户数为确定性伪随机生成，不是真实人口普查数据。超标户数变化趋势
  （搬走工地减少 565 户）与格数变化同向，但绝对值不代表真实社区。
- 遮罩坐标取整使遮罩比数学矩形略大（floor 左上、ceil 右下），
  这意味着遮罩可能覆盖略多于一圈衬底外沿。实际上多覆盖的像素数
  ≤ 1 px，不影响环线可读性。
