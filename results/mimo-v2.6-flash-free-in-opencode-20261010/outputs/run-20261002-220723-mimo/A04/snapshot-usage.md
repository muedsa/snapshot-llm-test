## 2. 数据与结论

源数据 `tasks/A04-conversion-paradox/inputs/conversion.csv`（4 行）：

| 期别 | 渠道 | 访问数 | 成交数 | 转化率 |
|---|---|---|---|---|
| 前期 | 直接访问 | 8,000 | 2,400 | 30.0% |
| 前期 | 推广访问 | 2,000 | 200 | 10.0% |
| 后期 | 直接访问 | 2,000 | 700 | 35.0% |
| 后期 | 推广访问 | 8,000 | 960 | 12.0% |

- **总体必须是 成交总数÷访问总数**：前期 `2600÷10000 = 26.0%`，后期 `1660÷10000 = 16.6%`。
- **分组与总体不同向**：直接 +5.0pp、推广 +2.0pp 均上升，总体 −9.4pp 下降（辛普森悖论）。
- **原因**：访问构成由 `直接 80% / 推广 20%` 反转为 `直接 20% / 推广 80%`，低转化渠道拿到 80% 权重。
- **禁止的错误算法已在图中显式否定**（图④ 表头右侧橙字）：
  - 对渠道率取简单平均 → `(30.0+10.0)/2 = 20.0%` → `(35.0+12.0)/2 = 23.5%`，算出 **+3.5pp 的相反方向**；
  - 把绝对成交量当转化率 → `2600 → 1660` 是成交量变化，不是率。
- **限制说明**（图右下红框）：汇总观测数据、无随机分流、未控制用户构成/渠道质量/季节，只显示加权算术关系，**不能由该数据证明因果**。

## 3. DSL 与文档的实际应用

真实查阅（suite 共享准备，已缓存，本题复用不重复计请求）：

- `https://open-snapshot.muedsa.com/ai-guide.md` —— 请求体编码、`Content-Type: text/plain; charset=utf-8`、错误 JSON 结构、`/fonts` 查询方式。
- `https://snapshot.muedsa.com/reference/parser-tags/` 与 `https://snapshot.muedsa.com/` —— `Snapshot`/`Container`/`Stack`/`Positioned`/`Text` 的属性与行为。
- `GET /fonts` → 27 个可用字族。

本题使用的标签能力：

- `<Snapshot type="png" background="#0B1220">` 根元素 + 单个 `<Container width height>` 定尺寸。
- `<Stack>` + 多个 `<Positioned left top>` 做绝对定位排版——四区版式（标题/图例 → 三面板 → 核对表 → 结论框）全部靠坐标落位。
- `<Text fontSize fontFamily color height>`：正文与表头用 `fontSize="22"`，表格单元格加 `height="1.0"` 收紧行盒使 6 行 28px 行高内垂直居中；最小字号 18（坐标轴、分段值、注释）。
- `<Container width height color borderRadius>` 直接画柱、堆叠分段、网格线（`height="1"`）、面板底、斑马行、结论框。
- 双字族回退 `fontFamily="Inter,Noto Sans CJK SC"`，拉丁数字走 Inter、中文走 Noto Sans CJK SC。
- 颜色统一用 `#RRGGBBAA` 不透明 6 位写法；同一渠道用明暗区分期别（直接 `#0EA5E9`/`#38BDF8`，推广 `#D97706`/`#F59E0B`），总体用紫色系（`#7C3AED`/`#A78BFA`），上升 `#34D399`、下降 `#F87171`。

未使用 `<Image>`、未嵌入任何外部素材；全部图形与文字由 DSL 构造。
