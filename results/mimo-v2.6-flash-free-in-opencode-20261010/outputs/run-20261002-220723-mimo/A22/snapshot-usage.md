## 4. 真实文档应用

* **`A22-doc-000`**（`requests.jsonl`）：用工具**实际重读**了 `https://open-snapshot.muedsa.com/ai-guide.md`，
  但**未发起新的 HTTP 请求** —— 该 URL 全套唯一一次真实 GET 是 `A21-doc-001`（200 / 846.4 ms / 3718 B），
  按总 AGENTS「缓存文件/原请求保留并引用，仅复用时不在后题重复计为新 HTTP 请求」归为 `shared-suite-cache`。
  因此本行**起止时间、耗时、HTTP 状态一律记 `null`，不伪造请求**；去重后全套仍只算一次文档访问。

  `Inter,Noto Sans CJK SC`，均在已取得的 `/fonts` 列表内）；不臆造标签/属性；非 2xx 是
  `code/message/requestId` 的 JSON，429 参考 `Retry-After`（A22 **未发生**任何 429 或服务故障）。
* 未新增 DSL 文档请求：A17/A11 的标签属性与字体缓存（`A17/tag-attrs.md`、`A11/fonts-0001.txt`）已真实取得过，
  直接复用，**不重复计为新请求**。

## 6. 设计选择

1. **五块固定绝对网格**（标题 / KPI 行 / 图 / 表 / 主结论）—— 这是本题最关键的选择：
   两轮数据更正与一轮加行都只动**内部**，主区域边界三轮 **0px 偏移**（题面要求 ±2px）。
2. **三轮共用一把尺子**：`-50,000…250,000` 单一比例尺贯穿 round-02/03，
   负值**不单独放大**——否则读者会同时看到两把尺子。
3. **负柱靠标注而不是靠改色**：利润柱始终是琥珀 `#FFB020`（柱色系统不随轮次变），
   `#DC2626` 只给文字（表格负值、零下标注），既交代了「负」也不破坏视觉系统。
4. **表格行高不随行数变化**：宁可底部余量从 48px 收到 4px，也保持三轮行距一致
   （题面明确「可重排内部刻度/行距」，但一致性优先），并用逐像素扫描证明没裁切。
5. **探针取离字形 6px**：左对齐取框左缘外 `x−6`，右对齐取框左缘内 `x+6`
   （右对齐字形结束于框右缘、左邻列右对齐字形恰好结束于本框左缘，`x+6` 两侧都够不到字形）。
6. **结论只写实际值**：结论里的每个数字与比较（最高/最低/唯一负值）都被写成断言并核对，
   没有外推、预测或「可能」这类数据之外的说法。
