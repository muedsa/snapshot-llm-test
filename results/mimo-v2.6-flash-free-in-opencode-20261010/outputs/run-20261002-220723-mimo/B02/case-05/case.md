# case-05 · 新手工作坊手册封面

- 作品名：第一次出门，带这四页就够 / 新手观鸟工作坊学员手册封面
- 尺寸：1000 x 1400（5:7 竖版，可印 A5）
- 主图：`final.png`（168065 字节）｜ DSL：`final.snapshot`（14276 字符 / 14897 字节）

## 受众与使用场景
报名 2 小时户外课的学员（亲子家庭与上班族新手）。手持印刷册封面，观看距离 0.3 米，
在开课前翻到，需要立刻知道自己要上哪几节、在哪个小组。

## 使用者要完成的事
看到四节课的标题与页码 → 找到自己的小组（A/B/C/D）→ 知道课后要交什么、
勾选哪四项才完成。

## 内容依据
自拟演示课纲：四个环节（认识望远镜 / 听 / 记录五要素 / 交数据）对应 P.2、P.4、P.6、P.8；
第 3 环节的「记录五要素」为 **时间 / 种类 / 数量 / 行为 / 备注**，与 case-06 野外记录表
的副标题及其表格五列逐项对应；交表时间「当天 17:30 前交给北门服务台」与 case-03 一致；
四个小组 A·芦苇荡 / B·栈道 / C·潮间带 / D·观测屋；页脚标 `演示数据 DEMO`。

## 主要视觉主张
纸面暖色 + 上下两条 14/4px 压边（深青 + 落日橙）立住封面感；52px 双行标题配橙色短杠；
中部 4 个模块行用「编号方块 + 标题 + 两行说明 + 右侧页码牌」形成可扫读的目录节拍；
底部两块功能区——小组选择胶囊组与「完成勾选」四格——把封面变成可操作的页面。

## 实际使用能力
`Box` 压边、`Eyebrow`、`TLines` 手动断行、`NumChip`、`Chip` 自适应胶囊、
`RuleBand`、双层矩形勾选框（深色描边 + 白色内格）、`FooterLine`。

## 完成标准（自定）
1. 四个模块的页码 2/4/6/8 与模块序号严格递增；
2. 四枚小组胶囊总宽 ≤ 756px，不越出内容区；
3. 四个勾选框尺寸、间距一致且不与文字相撞；
4. 页脚与底边留白 ≥ 80px，`演示数据 DEMO` 可见；
5. 第 3 条「记录五要素」的枚举与 case-06 野外记录表逐项一致。
