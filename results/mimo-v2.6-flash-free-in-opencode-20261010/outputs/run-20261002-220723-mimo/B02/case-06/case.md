# case-06 · 野外记录表

- 作品名：候鸟湾同步调查野外记录表 / FIELD RECORD SHEET
- 尺寸：830 x 1170（A4 可印）
- 主图：`final.png`（87951 字节）｜ DSL：`final.snapshot`（22711 字符 / 23050 字节）

## 受众与使用场景
持表夹在滩涂边现场填写的调查员与志愿者。观看距离 0.4 米，需在戴手套、有风的条件下
快速勾填，纸面留白与分隔线必须耐脏耐看。

## 使用者要完成的事
填好表头四格（日期 / 天气 / 观察者 / 样线·样点）→ 逐行记录五要素 → 看懂合计行 →
知道交表时间与地点。

## 内容依据
自拟演示数据：表头四格为「日期 / 天气 / 观察者 / 样线·样点」；表体 14 行（6 行示例 + 8 行空行），
列头为 **时间 / 物种 / 数量 / 行为 / 备注**，即副标题声明的「五要素缺一不可：时间 / 种类 /
数量 / 行为 / 备注」；6 行示例合计 24+2+8+5+3+4 = **46 只**、**6 种**（青足鹬、黑腹滨鹬、
环颈鸻、白鹭、苍鹭、普通翠鸟），与页内「合计 46 只 · 6 种」一致；交表「17:30 前交回北门
服务台」与 case-03/05 一致；页脚标 `演示数据 DEMO`。

## 主要视觉主张
纸面浅底 + 顶部深青表头条把「机构」与「表格」分开；14 行表格用交替底色 + 每 38px 一条
分隔线形成可耐读的行节奏，合计行用深青实底反白压住表尾；备注列留出虚线书写位；
整件作品把「品牌」降到最低，让数据行成为主角。

## 实际使用能力
`Box` / `Stack` 行构建、交替底色矩阵、`RuleBand`、`T` 分级字（列头小字 + 数值等宽感右对齐）、
`Chip`、`FooterLine`、`Mark` 小尺寸缩略。

## 完成标准（自定）
1. 14 行行高一致、分隔线连续不断；
2. 6 行示例的数量之和 = 合计行的 46 只，种数 = 6 种；
3. 五要素枚举与列头逐项一致，且与 case-05 第 3 条一致；
4. 合计行与页脚不出血，`演示数据 DEMO` 可见。

## 实际自检与修改
- `B02-c06-r1`（200，4446.9 ms）→ 看图：表头、6 行示例、合计 46 只 / 6 种、备注虚线
  均正确；但交替底色过浅、行分隔线过淡，14 行表格看起来像 4 个悬浮灰块 →
  改交替底色 `0x0A → 0x0D`、行分隔线 `0x22 → 0x4D`。
- `B02-c06-r1-retry`（200，2561.4 ms，PNG 87951 B）→ 看图 + `System.Drawing` 在 x=400
  采样 y=545..865 复核：14 条分隔线全部出现，位置 y=555/593/631/…/859（每 38px 一行，
  与 `rowH` 完全一致），线色 (175,187,180) 与 30% 不透明度叠纸面的理论值一致 → 通过。
- `B02-c06-r2`：一次 **DNS 解析失败的传输层错误**（无 HTTP 状态码、无响应字节、
  `duration_ms` 为 null，`type=render_transport_error`），请求体与 r1-retry 相同；
  因 DSL 未变、r1-retry 的 200 响应已在手，未重复渲染，交付仍是 r1-retry 的原始字节。
  这一行如实保留在 `requests.jsonl`，不计为成功的渲染。
- 跨作品元素核查（`ite-B02-crosswork-elements`）确认本表的「五要素」枚举为准，
  反向修正了 case-05 的文案（`B02-c05-r3`）。
