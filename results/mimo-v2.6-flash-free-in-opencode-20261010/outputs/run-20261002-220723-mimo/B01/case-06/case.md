# case-06 · 锂电 PACK 装配工艺指导

- 作品名：锂电 PACK 装配工艺指导（防错要点 + 扭矩窗口）
- 尺寸：1600 x 1000（16:10 横屏）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
新能源电池 PACK 线操作工与班组长。用于产线工位的 16:10 触控一体机，站立距离
约 0.6–1.2 米，戴手套操作，环境为冷白顶光的车间。

## 使用者要完成的事
按 5 个步骤完成电芯入壳与紧固，核对扭矩窗口是否在 6.2–6.8 N·m 合格带内，
记住 3 条防错要点，并按正确的星形顺序拧紧 5 颗螺栓。

## 内容依据
自拟演示工艺文件（虚构公司「启源新能源」、虚构工位与工序号），画面标 `演示数据 DEMO`。

## 主要视觉主张
工业蓝灰底 + 琥珀色强调：左侧 5 张步骤卡形成纵向阅读流；右上扭矩面板用一条
带公差带的水平条（绿=合格带、红=超差区、白游标指示当前 6.5）把「合格窗口」变成
可视区间而非抽象数字；右下拧紧顺序图用 5 个编号圆点 + 点线连线把星形拧紧次序
画出来，替代纯文字描述。

## 实际使用能力
Container/Stack/Positioned；SWEEP 渐变（环形徽标）与 LINEAR 渐变；
borderRadius 卡片与 badge；shape=CIRCLE 编号点；点线连线（虚线 border 序列）；
Text 多级 + 右对齐/居中。

## 完成标准（自定）
1. 5 张步骤卡行距一致、编号徽标垂直居中；
2. 扭矩条的绿带位置与 6.2–6.8 的数值刻度一致；
3. 拧紧顺序图 1→2→3→4→5 连线正确、编号可读；
4. 底部页脚不出血。
