# case-10 · 社区旧物集市导览横幅

- 作品名：第 6 届旧物集市 · 摊位导览横幅
- 尺寸：1920 x 640（3:1 超宽横幅）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
社区居民与来客。用于社区广场入口的横向 LED 横幅 / 易拉宝横版，观看距离 2–10 米，
经过时 5 秒内获取「几点、在哪、有什么摊位、什么规则」。

## 使用者要完成的事
确认活动时间与地点、找到自己想去的摊区（A 书籍文具 / B 厨房器物 / C 绿植多肉 /
D 玩具童书）及席位号、从哪个门进、需要遵守的 3 条规则。

## 内容依据
自拟演示数据（虚构「青禾社区」与集市），画面标 `演示数据 DEMO`。
席位数 12+14+10+12 = 48 与左侧统计「48 交换席位」一致；摊区编号范围与图例一致。

## 主要视觉主张
暖纸色 + 三栏信息架构：左栏是身份/时间/统计的「确认区」，中栏是白卡片里的
场地平面图（4 个色块摊区 + 4 个出入口 chip），右栏是规则与图例；
用「色块 + 字母徽标 + 色号」把摊区在平面图与图例之间建立双重编码，
远看按颜色找摊区，近看按字母找编号。

## 实际使用能力
Container/Stack/Positioned；LINEAR 渐变/纯色顶部与底部压边；
borderRadius 面板与 chip + border；2x2 网格定位（`x = 656 + (i%2)*368`、
`y = 168 + floor(i/2)*180`）；TPara 自动换行；Text 分级与右对齐/居中。

## 完成标准（自定）
1. 三栏边界清晰、不越界（中栏右边界 1400 与右栏左边界 1440 之间留白）；
2. 4 个摊区色块尺寸与间距一致（320x156、横纵间距 48/24）；
3. 席位数合计 = 48，与统计区一致；
4. 中栏右上角说明文字不被面板边缘裁切；
5. 所有文字不溢出卡片。

## 实际自检与修改
- `B01-c10-r1`（200，2952 ms）→ 看图发现：中栏右上角「北门在上 · 南门在下」
  的文本框右边界算到 1404，超出卡片右边界 1400，文字被边缘裁切。
- `B01-c10-r2`（200，3384 ms，189776 B）→ 文本框改为 `(1060, 66, 316, 28)`，
  右边界收到 1376（24px 内边距）→ 复看：文字完整、三栏比例与摊区网格无异常，通过。
