# case-04 · 精品咖啡烘焙曲线卡

- 作品名：精品咖啡 · 单锅烘焙曲线卡
- 尺寸：1200 x 900（4:3 横版）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
精品咖啡烘焙师与咖啡馆主理人。用于烘焙室张贴的批次卡，或导出为 A4 横版打印
夹进批次档案；在有蒸汽与强侧光的环境下近距离阅读。

## 使用者要完成的事
记录并复盘这一锅豆的入豆温、转黄、一爆、下豆时间与失重率，判断本锅是否需要
调整火力与风门，并与标准曲线对比。

## 内容依据
自拟演示烘焙曲线（虚构批次号与曲线数据），画面标 `演示数据 DEMO`。
温度轴与时间轴按比例换算，曲线关键节点坐标由同一套比例计算得出。

## 主要视觉主张
暖褐深底模拟烘焙室的暗环境，用一条折线（由等距点段连接构成）串起温度曲线，
三个关键节点用「引线 + 标签牌」标注在曲线上方的空白区，避免压住曲线本身；
右侧指标区用「标签 / 大数 / 注解」三行一列的节拍排布，形成稳定的纵向节奏。

## 实际使用能力
Container/Stack/Positioned；LINEAR/RADIAL 渐变背景；曲线用点阵 + 矩形段近似
（DSL 无 line 元素）；标签牌 borderRadius + border；大字号 Text 分级。

## 完成标准（自定）
1. 三个节点标签牌不重叠、不压曲线；
2. 指标区四行的基线节拍一致（行距 92px）；
3. 时间轴刻度可读，无裁切；
4. 曲线趋势与指标数字方向一致（升温段单调上升）。

## 实际自检与修改
- `B01-c04-r1`（200，3846 ms）→ 看图发现：曲线区过矮导致「6:00」刻度被压住、
  三个节点标签牌互相贴近/压曲线、右侧指标行距不足导致上下行粘连。
- `B01-c04-r3`（200，4901 ms，155756 B）→ 修改：曲线区 `$cy0=200, $chh=324` 加高；
  标签牌移到 (178,384)/(470,260)/(578,224)；指标区改为 `$y = 198 + i*92`
  （标签 16/24h、数值 34/44h、注解 14/20h），分隔线 y=574、结论行 y=580 → 复看：无重叠、
  「6:00」刻度可见，通过。
