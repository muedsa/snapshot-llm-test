# case-03 · 半程马拉松破风配速卡

- 作品名：半程马拉松 · 破风配速卡
- 尺寸：1080 x 1440（3:4 竖版）
- 主图：`final.png` ｜ DSL：`final.snapshot`

## 受众与使用场景
首次参加半程马拉松的业余跑者与配速员。用于赛前打印贴在补给桌 / 领物袋内页，
或赛前一晚在手机上查看；赛道环境下只在补给点短暂停留时扫一眼。

## 使用者要完成的事
按 21.0975 km 的分段目标配速控制节奏，知道每个补给点在几公里、几点经过、
补什么，避免前半程冲太快导致后半程崩掉。

## 内容依据
自拟演示赛事与配速方案（虚构赛事名、虚构选手与配速员），画面标 `演示数据 DEMO`。
分段里程之和严格等于 21.0975 km，累计比例按真实里程计算（0.2378 / 0.4755 /
0.7102 / 0.9460 / 1.0000）。

## 主要视觉主张
以「跑道」作视觉隐喻：深绿跑道底 + 亮色分段进度条，进度条长度严格按累计里程
比例换算，使 5 个分段在视觉上与真实里程一致；配速表用交替底色行与大号数字，
在补给点被汗水模糊的视角下也能快速对位。

## 实际使用能力
Container/Stack/Positioned；LINEAR 渐变；分段矩形 + borderRadius 胶囊；
交替行底色；Text 数字/单位分列与右对齐；水平点线分隔（点阵序列）。

## 完成标准（自定）
1. 进度条总长与轨道终点重合，5 段比例与里程比例一致（误差 < 1px）；
2. 配速、里程、累计时间三列数字互相对得上；
3. 无文字溢出或串行。

## 实际自检与修改
- `B01-c03-r1`（**400 PARSE_ERROR**，1785 ms）→ `Attr [matrix] value format error`：
  `<Transform matrix>` 缺少外层括号。失败响应体保留于
  `attempts/v1/failures/B01-c03-r1.body`，DSL 保留于 `attempts/v1/`。
- 修复矩阵格式（`matrix="(v,v,…)"`，16 有限浮点、无空格）后 → `B01-c03-r2`（200，6479 ms）
  → 看图发现分段比例按「等分」写死，导致第 5 段条尾与轨道终点不齐。
- `B01-c03-r3`（200，5570 ms，220595 B）→ 改为按真实累计比例 `0.2378/0.4755/0.7102/0.9460/1.0`
  与 `$barMax = 640` 计算，轨道色改 `#16241B` → 复看：5 段条尾精确落在轨道终点，通过。
