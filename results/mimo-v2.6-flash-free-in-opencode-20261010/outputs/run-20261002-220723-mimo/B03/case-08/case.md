# case-08 · ELEVATION 深度与材质规范

- 作品名：深度与材质规范 v2.4 / ELEVATION
- 尺寸：1200 x 1500（规范页，设计师在工位上对照阅读）
- 主图：`final.png`（209634 字节）｜ DSL：`final.snapshot`（8941 字符）
- 主导手法：**`boxShadow` 多层阴影**（内置 `ELEVATION_*` 阶梯 + 自定义 `x y blur spread color` 组合）
- 最终轮次：round 5（1 次语法修复 + 1 张基线 + 4 次视觉迭代）

## 受众与使用场景
要给自己的产品做深度系统的前端与 UI 设计师，0.4–0.6 米坐在工位上看，
不是"好看一页"而是"能照着实现"：阴影数值、层级命名、边界行为都要可复制。
所以这一页的任务是**解释规则并给出证据**，而不是装饰。

## 使用者要完成的事
按 A 段建立直觉（六级阴影逐级变重）→ 按 B 段拿到可直接抄的两层组合
（环境光层 + 接触阴影层及其 blur / spread / 色值）→ 按 C 段确认一个反直觉的
裁剪行为（`clipBehavior` 裁什么、不裁什么），避免实现时踩坑。

## 内容依据
自拟演示数据：虚构规范版本 `v2.4`，六级阴影名 `ELEVATION_1/2/4/8/16/24`
（服务端可用层级 0/1/2/3/4/6/8/9/12/16/24），B 段两层色值 `#0B3B3A2E` 与
`#1B2B4533`；页脚 `本页为虚构规范演示` 与 `DEMO . 演示数据`。
C 段的裁剪结论**不是虚构数据，而是本任务的实测结果**（探针 p19，见下）。

## 主要视觉主张
**从直觉到参数到反例的三段式**：A 段用 3×2 六张卡片把 `ELEVATION` 阶梯铺成
一条可扫读的阶梯（同一张卡只换 `boxShadow`，让差异只来自一个变量）；
B 段把镜头推近到一张卡的"解剖"——左边是卡本身，右边是两行可直接粘贴的参数，
中间不留装饰，让"看"和"抄"并排发生；C 段是全页唯一的一处**反例**：
两块同几何的灰框 + 橙卡，左边 `HARD_EDGE` 在框边被切断，右边 `NONE` 冲出框外，
橙色 `OVERFLOW` 标签只在右边出现——这一段是整页最硬的证据。

## 实际使用能力
`boxShadow="ELEVATION_n"` 内置阶梯、自定义 `boxShadow="x y blur spread color"`
（B 段两层叠加）、`clipBehavior="HARD_EDGE" / "NONE"`（`Stack` 裁剪对照）、
`Box`/`TXW` 规范版式、`HLine` 分隔线、右对齐段落与参数行。

## 完成标准（自定）
1. A 段六张卡**只**在阴影上不同（几何、内容、颜色一致），差异可肉眼排序；
2. B 段给出的数值与左边卡片实际使用的数值**完全一致**（不许文案与图形打架）；
3. C 段两块面板必须**客观可分**——以像素底边判定，不接受"看起来有点不同"；
4. 全页无指向不存在产物的引用；画面两处可见 `DEMO`。

  `clipBehavior="HARD_EDGE"`、标题改「clipBehavior=HARD_EDGE 被裁切」。

  新增脚注「实测 p19：Stack 裁的是子节点本身，boxShadow 不参与裁剪（四组阴影像素完全一致）」。
  像素复核：左卡底 `y=1223`（框边 1224）vs 右卡底 `y=1293`，**差 70px** → 客观成立。

  读图确认页脚两段完好、全图无 `B08` → 通过。
