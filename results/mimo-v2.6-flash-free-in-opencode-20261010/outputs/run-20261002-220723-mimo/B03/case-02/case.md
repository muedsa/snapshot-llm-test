# case-02 · 环贸中心大堂楼层导视

- 作品名：大堂导视 / LOBBY DIRECTORY（环贸中心 HUANMAO CENTER）
- 尺寸：1920 x 720（超宽横屏，大堂玻璃幕墙前的立式横屏）
- 主图：`final.png`（244341 字节）｜ DSL：`final.snapshot`（12594 字符）
- 主导手法：**`BackdropFilter` 毛玻璃卡片**（`ClipRRect` 直接包裹 + 全文档仅一次）
- 最终轮次：round 2（1 张基线 + 1 次结构性重做）

## 受众与使用场景
第一次来这栋楼、要在 10–30 秒内找到自己那层楼的人（访客、外卖、面试者）。
写字楼大堂横屏，站位 2–6 米，背后是彩色玻璃幕墙与中庭灯光——屏幕本身处在高亮环境里，
所以信息层必须**既能压住复杂背景、又不遮死背景**，这正是毛玻璃的任务。

## 使用者要完成的事
扫到自己楼层（28F/21F/17F/12F/01F）→ 顺带看到电梯 ETA（42 秒、B 区 3 号梯、运行中、
无障碍可用）→ 看到下一班接驳车 14:20 与当前时间 14:07:32 → 不用问人就能走到电梯厅
（页脚「电梯厅 LIFT LOBBY 直行 12m」）。

## 内容依据
自拟演示数据：虚构「环贸中心」五层租户（潮汐资本 / 海图设计 / 蓝盒影像 / 中庭花园 /
大堂·快递·咖啡）、电梯与接驳车时刻、天气与今日活动；右上角与右下角两处
`DEMO . 演示数据`。楼名、租户、时刻均为虚构，不指向任何真实楼宇。

## 主要视觉主张
把整屏分成**上半锐利、下半磨砂**两层：上半是纯 DSL 画的中庭场景（深浅不一的竖向
玻璃肋 + 暖黄圆形灯具 + 灯晕），故意画得足够零碎，才能让「被虚化」这件事一眼可见；
下半一整块 1848x384 的毛玻璃横跨全宽，承载三栏信息——左栏楼层导视（绿色楼层数 +
中英租户名）、中栏电梯 ETA 与接驳车（巨大 42s + 状态药丸 + 进度段）、右栏 NOW
（秒级时钟 + 天气 + 今日活动）。玻璃**只有一块**，栏与栏之间靠分隔线而不是靠玻璃边界
来划分，这样三栏读起来是一张连续的信息层，而不是三块贴片。

## 实际使用能力
`ClipRRect > BackdropFilter(sigmaX/sigmaY)` 毛玻璃、`Container borderRadius` 圆角、
`Grad` 灯晕渐变、`C` 圆形灯、`P` 绝对定位拼三栏、`TXW` 标签值对齐、
分段进度条（矩形序列）、药丸胶囊。

## 完成标准（自定）
1. 玻璃内确实能读到背景的模糊形状（非纯色）——用像素采样证明，不靠肉眼印象；
2. 玻璃外的背景保持锐利，与玻璃内形成对比；
3. 三栏在同一块玻璃上，栏间只有分隔线；
4. 秒级时钟、ETA、接驳车时刻互不矛盾；画面两处可见 `DEMO . 演示数据`。

## 实际自检与修改
- `B03-case-02-r1`（200，3729.2 ms，PNG 152753 B）→ 读图：**四块玻璃全部没有虚化**，
  玻璃面板内建筑边缘仍是硬边。主导技术失效，进入深度排查（不是「不好看」，是「没生效」）。
- 排查过程用探针 p14–p18（结构 / sigma / 裁剪 / 顺序四个变量各一次真实渲染）定出两条
  硬规则：
  1. **`BackdropFilter` 与被虚化的背景之间不能夹 `Container(color)`**，夹了就读不到背景；
  2. **整份 DSL 只能有第一个 `BackdropFilter` 生效**，所以「四块玻璃」在结构上就不成立。
- `B03-case-02-r2`（200，5088.7 ms，PNG 244341 B）→ 整体重做为**一整块玻璃**：
  上半保留锐利中庭场景，下半 `(36,300,1848,384)` 单块 `ClipRRect > BackdropFilter`
  承载全部导视信息。
- **像素证据**：玻璃面板 A 内 10px 天空缝 `x=694 → 697` 为硬切渐变，与卡外 `y=660`
  处的形状完全一致 → 背景确实被读到并被模糊；若未生效，该缝会保持硬边。

## 素材情况
纯 DSL，无外部素材；背景中庭场景也是用矩形/圆/渐变画出来的，不是图片。

## 虚构信息声明
楼名、租户、租户楼层、电梯与接驳车时刻、天气、活动时间均为虚构演示数据。

十件中唯一的**大屏实时导视**（1920x720 超宽、2–6 米、要在高亮背景前保住可读性）；
它的信息是「此刻的状态」，与 case-03 的一次性凭证、case-09 的时刻表看板结构不同。
