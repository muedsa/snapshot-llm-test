# A15 复刻差异说明（comparison.md）

参考图：`tasks/A15-reference-reconstruction/inputs/reference.png`（1440×900）。
重建图：`reconstructed.png`（1440×900，服务真实响应）。

参考图**只用于观察与像素测量**：没有嵌入 DSL、没有裁块、没有作为输出资产。
DSL 里没有任何 `<Image>`，全部结构由图元与文字构成。

## 1. 坐标怎么来的

题面不提供作者源码或标准坐标，所以参考坐标是**对公开参考图做像素测量**得到的，
原始测量值保留在临时目录：

- `tmp/run-20261011-01/A15/drafts/reference-probe.json`
- `tmp/run-20261011-01/A15/drafts/reference-geometry.json`
- `tmp/run-20261011-01/A15/drafts/reference-geometry-2.json`
- `tmp/run-20261011-01/A15/drafts/reference-geometry-3.json`
- `tmp/run-20261011-01/A15/drafts/reference-geometry-4.json`

关键结论：参考图与重建图用**同一套测量代码**（`verify_a15.py`）分别测量，
因此误差是同口径可比的，而不是拿设计参数去对答案。

坐标约定：原点在画布左上，x 向右、y 向下，单位 px；矩形记 `[left, top, right, bottom]` 外轮廓；
边界项只记 x 或 y，点项记 `(x, y)`；矩形四边分别比较，不做平均抵消。

## 3. 图表是按比例重建的，不是照数字摆的

零线 y = 549，最上一条刻度线 y = 405，刻度 [0, 30, 60, 90, 120]，
由此得到 **1.2 px / 数据单位**。柱高按 `height = value × 1.2；y_top = 549 − height` 算出，
柱宽 54px，柱左边界 [357, 458, 559, 660, 761, 862]。

## 5. 残余差异（实际看图后确认）

**1. 字体**  
参考图为几何无衬线（近似 Poppins），服务端 27 个字体族里没有该族，改用 Inter。字宽/字面率不同，因此长标题与长项目名的可见字形右缘会比参考图略短  
影响范围：全部文字的字形形状与宽度，不影响任何文字块的位置与字号

**2. 字重观感**  
Inter Semi Bold 的笔画粗细与参考图标题用字略有差异，在 2× 放大下可见  
影响范围：视觉重量，不影响几何

**3. 抗锯齿**  
服务端 Skia 渲染的边缘过渡与参考图的生成管线不同  
影响范围：1px 级别的边缘灰阶，锚点测量已把它计入

### 具体到看得见的地方

- 2× 放大 `zoom-header-2x.png`：主标题「Workspace Overview」的字形宽度比参考图窄，
  字重观感也略轻；**文字块的左上角位置误差 3px**，在 ±8px 之内。
- 2× 放大 `zoom-table-2x.png`：「Atlas / Visual system」这类长项目名在重建图里
  右缘略短，同样来自字宽差异，不影响列位与行距。
- 卡片 1px 描边：参考图把描边画在填充外沿（KPI 卡顶边落在 y=137），
  重建图由服务端的 `border` 画在填充内沿（y=138）。两者都是「1px 浅蓝灰」，
  视觉上不可分辨，卡片外轮廓锚点实测误差 0px。

### 不宣称的部分

- 不宣称逐像素完全复刻，也不宣称 DSL 树与参考来源一致；锚点合格不等于字形一致
- 本题**没有**验证像素级完全一致：渲染管线（Skia）与参考图的生成方式不同，
  抗锯齿灰阶必然存在差别，也没有定义可接受阈值。
- 24 个锚点合格只说明「关键锚点对齐了」，不代表每一块文字的每个字形都一致；
  字体替换带来的字形差异是系统性的，已在上一节列出。
