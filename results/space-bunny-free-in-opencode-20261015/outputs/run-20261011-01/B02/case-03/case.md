# case-03 · 借还规则

## 用户情境

- **触点**：前台立牌 A4
- **谁在什么时候用它**：站着翻阅的借阅者
- **他真正要解决的问题**：六条规则能不能一次看完，逾期怎么算

## 这件独有的视觉决定

六条规则各配一个独立色条，颜色与状态色系统同源；底部「逾期怎么算」用四段时间条，把最常被问的一条单独拎出来。

尺寸 1240×1754，正文最小字号 19px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
