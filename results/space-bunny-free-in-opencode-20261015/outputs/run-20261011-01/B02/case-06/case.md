# case-06 · 逾期提醒

## 用户情境

- **触点**：锁屏推送
- **谁在什么时候用它**：被推送打断的逾期会员
- **他真正要解决的问题**：哪件、迟了几天、再不还会怎样

## 这件独有的视觉决定

**整套最窄的一件**，用来检验字号层级在 560px 下是否还站得住；信用额度条把「3 / 6 次」画成进度条，损失是可见的。

尺寸 560×1200，正文最小字号 17px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
