# case-07 · 维修台挂签

## 用户情境

- **触点**：工作台上的标签
- **谁在什么时候用它**：值班维修员与回贴的志愿者
- **他真正要解决的问题**：哪件在修、谁接的、还要做什么

## 这件独有的视觉决定

四张可撕标签，每张带撕线；标签只在维修台出现，因此字号比面向顾客的页面更大。

尺寸 1200×800，正文最小字号 18px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
