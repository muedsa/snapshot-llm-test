# case-01 · 门头招牌

## 用户情境

- **触点**：街角门头
- **谁在什么时候用它**：路过的行人，5–8 米
- **他真正要解决的问题**：这是什么、能不能进、几点开

## 这件独有的视觉决定

标题放大到 96px——整套里唯一按「远观」设计的字号；品类色点与 App 内分类徽标同色，看过一次就认得。

尺寸 1600×600，正文最小字号 18px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
