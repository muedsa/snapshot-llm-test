# case-05 · App 物品详情

## 用户情境

- **触点**：手机单手握持
- **谁在什么时候用它**：在站里决定借哪一件的会员
- **他真正要解决的问题**：这台能不能借、什么时候还、怎么借

## 这件独有的视觉决定

三个动作按钮（借 / 看说明 / 问值班员）全部落在拇指可达区；顶部实物位用几何占位并明写「无实物照片」，不假装有图。

尺寸 720×1560，正文最小字号 17px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
