# case-08 · 开放日单张

## 用户情境

- **触点**：社区公告栏 A3
- **谁在什么时候用它**：还没听说过这个站的陌生人
- **他真正要解决的问题**：值不值得去看一眼

## 这件独有的视觉决定

受众是**路人不是会员**，所以标题（96px）比说明重要、开门时间比规则重要；全场免费写在最显眼处。

尺寸 900×1200，正文最小字号 19px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
