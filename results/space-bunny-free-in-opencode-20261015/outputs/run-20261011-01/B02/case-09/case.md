# case-09 · 归还检查单

## 用户情境

- **触点**：归还台
- **谁在什么时候用它**：逐项打勾的值班员
- **他真正要解决的问题**：这件能不能收、六项过没过

## 这件独有的视觉决定

合格/待清洁/缺件/待检 四种结果复用同一套状态色；结论行直接写「有 3 项不合格，当场拒收」，和表里的勾选一一对应。

尺寸 1400×900，正文最小字号 18px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
