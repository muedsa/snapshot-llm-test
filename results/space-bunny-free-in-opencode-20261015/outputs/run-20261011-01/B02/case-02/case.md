# case-02 · 借阅证

## 用户情境

- **触点**：口袋里的卡
- **谁在什么时候用它**：掏卡的会员与柜台店员
- **他真正要解决的问题**：我是谁、有效期到什么时候、店员怎么给我取件

## 这件独有的视觉决定

正反双面：正面给持卡人（姓名/等级/额度），背面给店员（取件与归还四条）；信息密度比门头高一档但字号下限不变。

尺寸 1050×600，正文最小字号 18px。

## 为什么它属于同一套生态

- 共用**标签条**（编号 + 分类徽标 + 状态点）；
- 共用**五种状态色**（可借 / 已借出 / 待修 / 逾期 / 缺件），颜色是唯一编码；
- 共用**页脚署名**「旧物仓 · 邻里共享」与一句示例数据说明；
- 图形语汇只用圆角矩形、细分割线与状态色块，不引入插画。

系统规则全文见输出根的 `design-system.json`。
