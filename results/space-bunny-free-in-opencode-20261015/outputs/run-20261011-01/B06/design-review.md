## 复核方法

两道关卡：**生成期**用 `check_layout.py` 解析 DSL 里每个 `Positioned` 与 `Text`，断言越界、字宽超盒、盒高不足 1.40 倍字号、字号层级比值；**渲染期**逐张打开 PNG 目视，核对遮挡、裁切、数据一致性与页脚声明。渲染返回 200 不作为通过依据。

## 逐件

### case-01 · 超市购物小票（热敏纸）

- **现状问题**：41 行等权信息，合计压在第 41 行；品类与促销混排在同一列，没有任何分组

- **结论**：三个数：总额、差���、可报销；以及「钱花在哪」

- **改版路径**：结论行 + 品类归因条 + 三个动作

- **目标环境**：收银台后 20 秒，正对 35–45cm，竖持

- **实测**：见下方「跨件实测」。

### case-02 · 居民燃气缴费通知

- **现状问题**：只给用量、金额、账期三个有效数字，阶梯价的那一行在原账单上根本不显示

- **结论**：把金额差额拆成可核对的价格效应与用量效应

- **改版路径**：差额归因一句话 + 3 期用量对照 + 阶梯明细

- **目标环境**：餐桌，横向细看

- **实测**：见下方「跨件实测」。

### case-03 · 健康体检报告

- **现状问题**：28 项按科室平铺，每项只有「标 ↑↓」，没有排序也没有动作

- **结论**：把二值标签换成「下一步做什么」，并说清参考区间不等于异常

- **改版路径**：三档分层 + 每项一步动作 + 为什么不能只标红箭头

- **目标环境**：手机与打印件，横竖皆可

- **实测**：见下方「跨件实测」。

### case-04 · 航空行程单 / 值机确认页

- **现状问题**：5 段行程等权平铺，没有当前时刻，没有倒计时

- **结论**：把「现在」钉在时间轴上，其余一切围绕这一段排

- **改版路径**：当前游标 + 距下一段倒计时 + 按截止时间排序的三件事

- **目标环境**：手机，走动中快速扫读

- **实测**：见下方「跨件实测」。

### case-05 · 门诊收费票据（一式多张）

- **现状问题**：5 张独立票据，金额不跨票相加，退费信息分散在各张的末尾

- **结论**：合成一笔账，并说清还能反悔哪一笔

- **改版路径**：三个总数 + 按发生时间排的 5 项 + 可退项与截止时限

- **目标环境**：诊室门口，站立扫读

- **实测**：见下方「跨件实测」。

### case-06 · 快递电子面单 / 隐私面单

- **现状问题**：22 个等权字段，收寄同屏，无隐私状态

- **结论**：寄件人核对「电话、门牌、隐藏」，收件人只看「谁的、什么时候到、带什么」

- **改版路径**：正反两面 + 隐私状态 + 已折叠的 18 项清单

- **目标环境**：手持，柜台光线，横向

- **实测**：见下方「跨件实测」。

### case-07 · 餐厅菜单（堂食单页）

- **现状问题**：40 道菜纵向平铺，无分类、无维度标注

- **结论**：先给条件，再看菜

- **改版路径**：4 个决策入口（人数/辣度/素食/上菜时限）+ 每道菜 4 个维度

- **目标环境**：桌面上斜放 45°，横向视线

- **实测**：见下方「跨件实测」。

### case-08 · 药品说明书 / 药盒侧面

- **现状问题**：23 个法定章节，术语密集，动作埋在末段

- **结论**：三个问题放到第一屏，并给出今天的服药时刻

- **改版路径**：能不能吃 / 一次几片 / 和别的药冲不冲 + 24h 时刻表 + 3 条警示

- **目标环境**：药盒旁，手边，夜里

- **实测**：见下方「跨件实测」。

### case-09 · 预包装食品包装（正标 + 标签）

- **现状问题**：一张 3 列小表 + 一行配料，字号最小、位置最边

- **结论**：法定标示一字不动，另加一层标准允许的补充说明

- **改版路径**：前三位配料大字 + 法定 1+6 原样 + 每包换算

- **目标环境**：货架上，1 米距离

- **实测**：见下方「跨件实测」。

### case-10 · 家用电器说明书（空气净化器）

- **现状问题**：9 章 34 节按功能组织，任务要自己找

- **结论**：把说明书首页改成「你现在能做的 6 件事」

- **改版路径**：6 张任务卡 + 滤芯寿命进度 + 保养周期日历

- **目标环境**：家电旁，手机或纸质卡

- **实测**：见下方「跨件实测」。

## 配色与排版

统一的报刊式双栏版式：左列为主版面（结论 → 证据 → 动作），
右列为辅助（分层表与折叠清单）。强调色按载体语义分配
（票据红、燃气金、体检蓝、行程蓝紫、菜单橙、药品绿、食品品红、电器蓝绿），
每张只用一个强调色，其余为纸白 / 墨 / 灰三级，正文最小 20px。

## 限制条件

- 原版结构一律用**中性抽象示意条**表示，不伪造具体品牌的版式。
- 所有数值为自拟示例；标准与行业阈值按公开常识量级给出，**未逐项核实**。
- case-09 的 NRV% 一列留空并写明原因——不填比填错好。
- 本专题只重排信息，不构成消费、计费、医疗或用药建议。
