## 策展命题

「删掉无用信息之后，日常信息载体长什么样。」

十件不是把原版做丑再修正，而是**重新定义这件物品要回答的问题**，
再让版式只服务那个问题。每件都必须能说清：
用户原本为什么需要它 → 物品信息和用户核心问题之间隔了什么 →
用户真正需要的是什么 → 新版把什么提到了第一层。

原版信息结构以**中性抽象示意**（不是伪造的劣质原图）出现在每张图的
「信息结构对照条」中，主版面全部是重设计版式。

## 各件专属标准（在通用标准之外追加）

- **C01**：分类金额之和 = 合计；合计 − 优惠 = 实付；与「上次」差额自洽。
- **C02**：阶梯价分段计算与图中金额一致；价格效应 + 用量效应 + 交互项 = 总差额。
- **C03**：10 项分档数量与列表一致；每项的「偏离度」与所画区间条位置一致；明示非医学建议。
- **C04**：所有时刻按同一时间线自洽；「现在」游标位置与倒计时数值一致。
- **C05**：各项目金额之和 = 合计；医保 + 自付 = 合计；可退项金额来自对应项目。
- **C06**：双面字段不重叠；折叠项数量与列出的类别数一致。
- **C07**：筛选入口计数与实际菜品数一致；每道菜的过敏原标记与文字一致。
- **C08**：服药时刻表 24 小时栅格上「已服/待服」位置与文字时刻一致；明示非用药建议。
- **C09**：法定 1+6 七项齐全；能量按 蛋白×17 + 脂肪×37 + 碳水×17 核对；盐量由钠×2.5 换算。
- **C10**：滤芯已用百分比 = 累计/总额；剩余小时数 = 总额 − 累计；任务卡步数编号连续。
