# case-09 · 为什么它排第一 · 联赛积分榜的净胜球规则

- **作品**：`final.png` · `final.snapshot`
- **尺寸**：1920 × 1080（大屏）
- **接受版本**：v3（B06-req-0020）
- **受众 / 环境**：看联赛积分榜却分不清同分球队排序依据的球迷；3–5 米外观看大屏，
  需要大字号与高对比。
- **观看目标**：知道两队同分时按什么规则排出先后。

## 用户原本卡在哪里

积分榜把三件事压成一列数字：积分、净胜球、进球。两队同为 24 分时，谁排前面由
**净胜球**决定；净胜球也相同时，由**进球**决定。这条逐级判定链在榜上完全不可见
——它只存在于规则文档里。球迷看到的只是"这两队同分，为什么这个在前"，于是只能
猜或者吵。

## 场景与受众

客厅大屏，3–5 米距离，可能是一家人在看。**这个距离直接决定了设计约束**：字号
必须大、对比必须强、任何在 30 英寸上"勉强能看出"的色差在这里都等于没有。信息
密度要低到一眼能读，但结论必须精确——因为球迷会逐队核对。

## 内容

- 虚构联赛 8 队，**全部 14 场**（56 场）自拟演示数据。
- 三档同分：云岭 24 分 / +10 / 进 22，沁水 24 分 / +10 / 进 19，苍梧 24 分 /
  +6；其后 白泽 22 / 青岚 19 / 长庚 16 / 赤壁 12 / 玄鸟 11。
- 顶部**同分排序规则链面板**：第 1 级积分 → 第 2 级净胜球 → 第 3 级进球，三级
  蓝框药丸 + 箭头。
- 11 列积分榜：排名 / 球队 / 积分 / 赛 / 胜 / 平 / 负 / 进球 / 失球 / 净胜球 /
  净胜球比例条。
- 净胜球比例条以 x=1560 为零轴：正净胜球蓝色向右，负净胜球橙色向左。
- 页脚两行说明逐级判定过程。
- 联赛级一致性：总胜 = 总负 = 40、总平 32（偶数）、总进球 = 总失球 = 120、
  56 场。

## 视觉选择

**视觉隐喻是"把三档规则变成一条看得见的判定链 + 一根零轴"**：规则链面板给出判
定顺序，比例条给出判定**用到的量**。零轴居中、双向延伸，于是"净胜球"不再是一个
要读的正负号，而是一根从中间往哪边长、长多远的条。

同分组用**一整条连续色带**而不是三个独立高亮块——因为规则说的是"这三队同分"，
三个分离的块会读成"三行各自被高亮"。云岭与沁水净胜球同为 +10 这一第 2 级关键
事实，则用一条贯穿两行的竖线 + 「+10」标注显式标出，**不依赖肉眼比对条长**。

## 实际自检

三个版本，全部逐张实看：

| 版本 | 观察到的问题 | 修改 |
|---|---|---|
| v1 | (1) 同分组用三个独立圆角色块，块间 6px 缝隙使其读作"三行各自高亮"而非"一个同分整体"；(2) 云岭与沁水净胜球同为 +10 这一第 2 级关键事实只能靠肉眼比对条长 | 同分组改为一整条连续色带（0–2 行 228px 高）；在相邻行条尾 x=1810 加贯穿两行的深蓝竖线与「+10」标注；零轴由 #A8BCCA 加深为 #94A9BA |
| v2 | 连续色带已读作一个同分整体、+10 标注已显式；**但同分色带 #E8F2FB 与页面底色 #EDF1F5 在蓝绿通道仅差 5/255、1/255，3–5 米观看对比过弱，且验证时两者不可靠区分** | 同分色带加深为 #D9E8F6（与底色差 20/255）；并列标注由 15px 升至 17px |
| v3 | 色带差值 5/255 → 20/255，前三名在 3–5 米下仍清晰可辨；+10 标注 17px | 接受为定版 |

`_verify09.py` 像素核验全部通过：

- **C4 几何**：八条比例条实测 249 / 249 / 150 / 75 / 25 / 125 / 275 / 300px 对应
  净胜球 +10 / +10 / +6 / +3 / −1 / −5 / −11 / −12，每条均为 |净胜球| × 25px/球
  （取整误差 ≤1px）；正条左端恒在零轴 x=1560、负条右端恒在零轴；条高均 34px；
  **并列两队条长像素级完全相等（249 = 249）**，苍梧条恰短 100px 即 4 球差；
- 零轴自 334 至 952 连续 478 行（被正条遮挡的 136 行除外）；
- 并列连接线在 x=1810 贯穿 355–479 共 125 行且不越出并列行上下边界；
- 同分色带自 342 至 569 共 228px 恰覆盖前三行，第 4 行起完全未着色；
- 九列对齐核验：球队列左对齐 x≈150，其余八列右对齐至各自边界（547 / 637 / 717 /
  797 / 877 / 977 / 1077 / 1207）；
- 同分三队积分墨迹尺寸完全一致（47×29）；积分数字字高 29px 明显大于统计列
  20px，满足大屏层级；
- 表格元素无一越过 1880 内容列；四周边距逐像素扫描零越界。

脚本断言 **C1–C3**：8 队胜 + 平 + 负 = 赛、积分 = 胜 × 3 + 平、净胜球 = 进 − 失；
排序由 (−积分, −净胜球, −进球) 从数据派生；**第 2 级生效**（云岭与沁水同 24 分
同 +10）与**第 3 级生效**（进球 22 对 19）均被断言；联赛级总胜 = 总负 = 40、总平
32 为偶数、总进球 = 总失球 = 120、共 56 场，数据自洽。

**C1–C5**：全部满足。

## 素材情况

纯 DSL，无外部素材。球队名称与战绩均为自拟演示数据（虚构联赛，已在图上标注）；
判定规则为通行的 积分 → 净胜球 → 进球。

## 边界与未验证项

几何比例与数据自洽经像素量测 + 断言；**3–5 米可读性为基于色差与字号的设计推断，
未经实际距离观看测试**。同分色带对比度问题在 v2 被识别为"验证时不可靠区分"，v3
以量化色差（20/255）修复，但仍属可观察改善而非用户实验结论。
