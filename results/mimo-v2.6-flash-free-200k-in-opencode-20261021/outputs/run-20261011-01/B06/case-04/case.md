# case-04 · 箭头之外 · 检验报告的参考区间定位

- **作品**：`final.png` · `final.snapshot`
- **尺寸**：1240 × 1754（A4 纸面）
- **接受版本**：v1（B06-req-0009）
- **受众 / 环境**：拿到化验单、只看到 ↑↓ 箭头而焦虑的患者；A4 打印或手机查看，
  近距离细读。
- **观看目标**：知道自己偏离参考区间多少、偏离方向，以及**这是否等于有病**。

## 用户原本卡在哪里

化验单把结论压缩成一个箭头。箭头给了方向，**没给幅度**——0.2 mmol/L 的轻微超出
和 58 μmol/L 的大幅超出拿到的是同一个 ↑。患者于是要么对所有箭头一律紧张，要么
对所有箭头一律无感。更关键的是，参考区间本身是一个**区间**，而箭头把它压成了
一个二值状态。

## 场景与受众

拿到报告的那一刻，可能是诊室外、可能是家里。A4 纸面意味着可以停下來細看，但
也意味着信息密度可以更高。需要在同一版面上同时给出：结果、单位、参考区间、偏离
幅度、以及"箭头 ≠ 诊断"的口径说明。

## 内容

- 7 个检验项目行，每项四要素齐全：项目名 + 缩写 / 结果 + 单位 / 参考区间 /
  偏离量，含正常项与异常项。
- 参考区间带：每项一条，带内 = 在区间内；偏离项的彩色段落在带的**左或右**，
  段长与偏离量成正比。
- 三档视觉层次：正常项绿带内深墨竖线 +「在参考区间内」；偏低项蓝段在带左；
  偏高项红段在带右。
- 界值数字分别落在各自带端下方；图例（带 / 竖线 / 带外彩段）。
- 演示数据红章 +「箭头不等于诊断」口径说明 + 页脚边界。

## 视觉选择

**视觉隐喻是"把点放回带子里"**：箭头之所以误导，是因为它把一个位置信息变成
了状态信息。所以作品的主体不是更大的箭头，而是一条**带**——每个结果是一个落在
带内或带外的**位置**，偏离量是**段长**。

由此 TC 仅 0.2 的超出表现为一段很短的红段，尿酸 58 的超出表现为一段很长的红段：
**偏离幅度在几何上直接可比**，无需读数字。这是纸面版式能承载的信息密度：一条
一行，逐行对齐，可以反复比对。

## 素材情况

纯 DSL，无外部素材。项目名与参考区间为常见检验项目的通用表述，**具体数值为自拟
演示数据**，不代表任何真实检验报告。

## 边界与未验证项

偏离量与落点比例经像素量测，**未经医务人员或患者实测**。口径说明是科普性表述，
不替代医生解读。
