# case- 03 · 避水路线规划

## 场景与受众

- **受众**：通勤族 · 林岚
- **内容范围**：3 条路线卡（最短12min 经禁止点 / 避水17min 推荐 / 地面辅路21min）、途经点位与风险、+5分钟收益说明、车型离地间隙切换提示。
- **观看环境**：出发前在手机上选路线。
- **用户目标**：比较最短路线与避水路线，选一条不涉禁止通行点的路，并理解为何绕行值得。
- **前后关系**：承接case-02 ｜ 去 case-04（同一决策换骑手阈值(5/10cm)）；去 case-07（同一决策换车机离地间隙判定）
- **尺寸**：780 × 1688（按实际 PNG 读取）

决策页：用户要理解的不是『哪条最快』，而是『最快那条为什么不能走』，三条路线并排比较。

## 内容与数据来源

本画面的数据全部由 `b05_data.py` 作为单一事实源生成并带断言
（点位/深度/路线/上报/泵站），跨画面一致；唯一真实锚点为暴雨橙色预警分级
（中国气象局 CMA 标准，见 `tmp/run-20261011-01/B05/SRC-01-cma-rainstorm-warning.txt`）。

真实锚点仅有暴雨橙色预警分级（中国气象局标准，SRC-01）；其余点位、水深、
传感器、车辆、上报、泵站、人物均为虚构演示数据，风险分级为产品自定演示规则，
非官方通行标准。未做真实用户验证。

## 视觉选择

三条路线卡横向并排，推荐卡以描边+徽标突出；每卡用迷你 DepthRuler 标出途经风险，让用户一眼看出最短路线为何被否。

招牌视觉为 **DepthRuler 水位刻度尺**：把抽象的 cm 变成可一眼判断的相对位置，
判定表现为『水位线越没越过那条线』的几何事实。风险色全系统一为
可通行 `#2FBF71` / 谨慎 `#2E86DE` / 建议绕行 `#F2A93B` / 禁止通行 `#4572E4`。
