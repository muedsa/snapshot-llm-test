# A20 · 24点指数示意地图（密集标注）— 快照 DSL 使用报告

## 任务与硬约束

在 1600×1100 画布上把 `inputs/markers.json` 的 24 个点画成示意地图，锚点严格按
`px = 280 + 10.4*lx`、`py = 920 − 7.6*ly`（逻辑原点在**左下**、y 向上；审计用画布
左上原点、x 向右、y 向下、像素单位、不预取整）。每个点 d12 圆盘落在映射锚点上，每个点
必须显示「编号 + name + value」。标签盒不得与**非本点**的实际圆盘（d12，必要时可缩到
d8，本图未用）相交，标签盒间距 ≥4px，正文 ≥20，锚心到盒 >24px 必须引导线，引导线只连
自身盒边、不穿过任何盒内、异线交叉 ≤3、无自交、无共线重叠（容差 1e-6）。标注坐标轴、
范围、单位「指数」与 value 前三（降序，并列按 ID 升序，**不按 y**）。交付
`label-layout.json`（未取整逻辑坐标、像素锚点、标签盒、折线）与 `layout-audit.json`
（标签相交、线穿标签、交叉数、边界检查）。必须放大查看中心 6 点
M06/M08/M09/M10/M11/M12 及引导线，再看整图。

## DSL 配方（本题新学/复用）

| 目标 | 配方 | 来源 |
|---|---|---|
| 文字 | `<Text fontSize color fontFamily textAlign text=…/>`，**width/height 只放 Positioned**；用元素内容 `<Text>…</Text>` 会静默出空 | A19 交付件比对（本题缺陷#1） |
| 行线段 | `Positioned(left=x1·…, width=length, height=3)` + `<Transform matrix="(c,s,0,0,−s,c,…)" origin="(0,0)" alignment="TOP_LEFT">` 包一个 `Container` | A18 line_el 复用 |
| **描边中线补偿** | Positioned 顶边对齐会让 3px 描边中线偏离折线 `1.5px` 法向；发射位置改 `(x1+1.5·sinθ, y1−1.5·cosθ)` 后描边中线 == 布局折线 | 本题新学（像素采样发现） |
| 面板/圆盘/高亮环 | `Container color` + `borderRadius`；环用 `border="2 SOLID #F59E0B"` 画在盒内（盒=外径，border=半径差） | A13/A18 复用 |

## 布局引擎（几何求解，非手摆）

`a20_layout.py` → `placement-raw.json`；`build_a20.py` 做路由+审计+发射
`annotated-map.snapshot`。

- **放置**：8 方向 × 近/远偏移 × 轴向位移生成候选，按「密度优先」（最近两邻距离均值）
  顺序放置；打分无线槽 `d`、有线槽 `400+d`、留白槽 `800+…`。
- **约束**：盒-盒最短欧氏距离 ≥5（要求≥4，留 1px 设计余量）；盒到任一圆盘（含 top3
  高亮环 d22）净距 ≥2；盒不压自身点与自身高亮环；盒与标注/画布留白。
- **引导线路由**：多入口点（最近点+四角+边点，就近优先）× 模板（直、L 拐、Z 拐、±绕行）。
  判据：Liang–Barsky 解析判定不进任何盒内；`seg_box_dist≥1.5`（描边半宽）保证不贴他盒；
  末段贴自身盒边长度 ≤8px（禁止沿边滑行）；首段必须径向离开自身圆（`(b−a)·(a−c)≥0`）。
  可路由性在打分排序后**惰性**校验，避免对不会被选中的候选付费。
- **放置结果**：24/24 全部落位，仅 M06、M11 需引导线（锚心距 62.2 / 106.8）；其余 22 个
  标签锚心距 ≤13.8（<24，无线）。最小圆心距 M10–M11 = 30.86px > 12px，**无需缩点**（已记录）。

## 迭代与缺陷（4 次视觉迭代 + 1 次语法修复，7 次渲染全 200）

1. **全图无字**（map-01）：Text 误用元素内容 → 改 `text=` 属性。
2. **标题被 CLIP**（map-02）：标题盒宽按 fs20 估、文字按 fs24 画 → `ann_text` 增 fs 参数。
3. **top3 环压自身标签板角 1.6px**（map-03）：环纳入自身放置约束，近偏移起点改 7。
4. **M11 末段沿盒边滑行 68px + 描边中线 1.5px 系统偏移**（map-05/06）：多入口路由 +
   贴边带宽测试 + 发射补偿；M11 改 `bend-hv` 落标签右上角（贴边 1.59px），M06 直线落角点
   （1.76px）。

无 429/503，无客户端超时，0 重试；文档/字体全部复用 run 本地缓存，无新增 HTTP。

## 可迁移经验

- **Text 必须用 `text=` 属性**；`width/height` 只属于 Positioned。
- **Transform 描边会偏移半个描边宽**：任何按中心折线声明的线，发射时都要做 `±(w/2)·法向`
  补偿，否则审计声明与像素不符。
- **标签绕线不要贴边**：给「末段贴自身盒边长度」设上限，比判「是否进盒」更能拦住难看的
  沿边滑行。
- **可路由性放进候选打分之后惰性校验**：既保证选到的槽真能走线，又不为落选候选付费。
