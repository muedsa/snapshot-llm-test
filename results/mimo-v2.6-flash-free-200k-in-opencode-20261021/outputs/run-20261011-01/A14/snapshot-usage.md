## 实际文档/DSL/工具应用

- `ai-guide.md`、`parser-tags.html`、`fonts.txt` 均复用套件缓存
  （`A14-doc-reuse-0001..0003`，未新增 HTTP）：请求体编码、`Text` 的
  `text` 属性/`textAlign`/`height`、`Positioned` 几何、`Container` 的
  `borderRadius`/`gradient`、字体族均按缓存文档执行。
- 关键标签能力（本题实证）：
  - `Text` 的 `text="..."` 属性通道原样传递 `< > &`（K04/K05 实证），
    元素内容形式遇到裸 `<` 会 PARSE_ERROR，故全部走属性形式。
  - `textAlign="CENTER"` 让胶囊文字在预估宽度盒内双边留白（v3 起）。
  - 未转义换行在 text 属性与元素内容两种形式中都真实换行；字面 `\n`
    不解码（整墙阶段 `probe-newline` 实证，见 drafts/）。
  - `Snapshot background` 默认透明；卡面渐变由整面 `Container` +
    `gradientType="LINEAR"` 承担。

## 设计与参数化规则（一套规则，无逐条硬改）

- 画布 1200×630、安全边距 40；主色 `#22D3EE`（品牌字/页眉细线）；
  统一页眉（品牌左 / 序号胶囊 / 日期右）→ 青色细线 y92 → 统一标题区
  `[104,422]`（标题块按行数垂直居中）→ 分隔线 y430 → 讲者行 y450 →
  底行 y540（时间胶囊左 / 状态徽标右）。
- 标题：字号分支 `[56,50,46,42,40,38,36]` 取首个换行 ≤3 行者（真实输入全部
  56px；2 行 5 张、1 行 3 张），换行算法为标点分段装箱 + 孤行回收；
  绝不下限以下缩字，不整图缩放。
- 状态体系（颜色+符号+文字）：开放 `#34D399 ●`、满额 `#FBBF24 ▲`、
  候补 `#60A5FA ◇`、取消 `#F87171 ✕`；未知状态走中性 `#94A3B8 ◆` + 告警。
- 取消卡 K06：数据驱动分支 `status=="取消"` 追加实心红「✕ 本场取消」注记胶囊，

## 实际问题、修复与验证

1. **误读任务方向（已纠正）**：早前会话按误记的任务描述做了 1440×1800 整墙
   （`drafts/wall-*`，req-0001–0006）。复读 `TASK.md`/`task.json` 权威文本后
   纠正为 8×1200×630 卡片交付；整墙草稿与探针全部保留在 tmp 作为过程证据，
   换行探针仍被引用为文本发射的辅助证据。详见 `iterations.jsonl`
   `A14-requirement-change`。
2. **标题区空洞（v1→v2）**：顶对齐标题使单行卡中部大面积留白 → 标题块在统一
   区域内垂直居中；同时 K06 注记改为实心胶囊与描边徽标拉开层级。8 张复看确认。
3. **胶囊文字贴边 + 日期不齐边（v2→v3，像素量测发现）**：时间文字墨迹
   41..98 贴左缘、序号离右缘 32px、日期右缘距页边 52px → 四个胶囊
   `textAlign="CENTER"`，日期盒移到 x=1041 使墨迹齐 1160。
4. **日期丢字缺陷（v3 量测拦截）**：日期盒宽 119 < 文本进宽 ~120，末字符
   "7" 被挤到不可见的第二行，v3 实际渲染为 "2026.11.0"（x7 裁剪目视确证）→
   盒宽 131（盒可越页边、墨迹不可），v4 渲染后墨迹 1042..1159 齐页边。
5. **量测工具自身两轮误报**：整墙量测 ±6px 窗口在 35px 行距下互相渗漏
   （8 起假溢出）→ 改行带分析；卡片量测首跑 22 起失败全为工具缺陷
   （行盒 leading 判定、r=22 边框弧、注记亮底圆角外暗底）→ 改包含判定 +
   x±12/y±6 内缩窗 + 注记反相检测，复跑 0 失败。渲染本体未因此返工。
6. **异常/压力探针（交付生成器本身）**：真实输入全干净，合成 K99（未知状态、
   类型错 time=900、长标题 56→38 缩字、长讲者两行）与 K98（极端标题触发
   36px 下限 + 省略号截断 + 告警）均渲染 200 且目视通过，记录在
   `batch-audit.json.generation.auxiliary_tests`。
