## 真实文档与工具应用

- 请求前阅读 `https://open-snapshot.muedsa.com/ai-guide.md`（缓存于 `tmp/run-20261011-01/_suite/docs/ai-guide.md`）确认请求体为 `{"snapshot": "<dsl>"}`、返回字节即图片本体；Cloudflare 对无浏览器 UA 的 Python 请求返回 403（错误 1010），共享脚本 `snap_render.py` 已加浏览器 UA 并自动重试。
- 使用 `SizedBox` + `Stack` + `Positioned` 做根布局（根节点尺寸必须有限），`Container` 画色块/网格/泳道底，`Text` + `textAlign`（START/CENTER/END）配合固定宽度做对齐；`gradientType="LINEAR"` + `gradientColors` + `gradientBegin/End` 画头部渐变条。
- 字体使用服务已确认可用的 `Inter,Noto Sans CJK SC`（字体列表见 `_suite/docs/fonts.txt`）。
- 程序化生成：`scripts/gen_a02.py` 从 `inputs/agenda.csv` / `venues.json` 读取全部输入，计算时间轴坐标、自动换行、窄块降级排版，并同时产出审计 JSON，保证图与审计同源同值。

## 设计与几何

- 时间轴：09:00–16:00 共 420 分钟映射 x∈[310, 1880]，**1 分钟 = 3.738095 px**；每 30 分钟一条网格线，整点加时间标签（20px）。色块宽度 = 时长 × 3.738095，未做任何“塞字式”拉伸：40 分钟 = 149.52 px、60 分钟 = 224.29 px，比例严格一致。
- 泳道 A/B/C 纵向排列，各带会场卡片（名称、容量 320/80/160 座、场次与分钟数、类别构成）。空档即为空白，不做填充。
- 公共午休 12:00–13:00 画成跨三泳道的琥珀色竖带 + 顶端独立标签条，与 15 场会议完全分离；审计中按 `public_lunch` 独立记录，会场空档在 12:00/13:00 处拆分，分钟数不重复计入。
- 窄活动（S15 仅 30 分钟，宽 112 px）自动降级：编号行缩到 18px、起止时间拆成两行 `15:30` / `至 16:00`，并保留在色块内，同时下方索引表给出完整单行信息，满足“短活动通过索引解决文字空间”的要求。
- 手机图为重排的分时段列表（不是缩小/裁切大图），保留编号、起止时间、会场色点、标题，并写明“讲者详见完整日程（1920×1200）”。
