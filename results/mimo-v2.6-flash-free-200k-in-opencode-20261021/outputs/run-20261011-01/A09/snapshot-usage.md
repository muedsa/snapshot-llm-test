## 踩坑

- 亚像素核验三轮才收敛：固定 dist 阈值在 30° 斜边上系统性 -2px（反走样边缘被"半像素推入"）；半距阈值被红黄仅 107px 的调色板间距击穿；覆盖率法又被两类伪命中污染——底色整数取整在背景→圆点连线投影 f≤0.042、十字准线 50% AA 像素 (28,40,69) 经 BG→圆点线拟合 f=0.263。
- 定稿规则：**背景→主体色连线优先**（残差≤8 即判定覆盖/底色），不可解释时先排除七种家具色与底色的混合线，再取调色板间连线最小残差；实心段(≥65%)定带、行/列取含最大覆盖率的连续段定界（隔离孤立杂散）；圆点独立阈值 0.05。
- Python 列表解包坑：`sum(y*f for y,_,f in fs)` 实际取到 x，造成圆点质心 dcy=dcx——解包顺序必须与元组 `(x,y,f)` 一致。
- PowerShell 无 heredoc（`<<'EOF'` 报 ParserError），批量替换改用 edit 工具 replaceAll。

- 生成器"计算→断言→一次写出 DSL+JSON"模式延续 A04–A08；本题新增：列主序矩阵合成的枢轴等价性（线性部分 + alignment=CENTER 盒心=枢轴）、审计预测值与实测值同文件对照。
