## 图形结构与几何

- **共用真实时间横轴**：08:00–12:30 = 270 分钟，x = 150 + minute_offset × 4.62963 px，
  三图完全同一映射；12 条纵向参考线在三面板同列（像素探针：09:15 参考线在三图均为 x=497）。
- **断线规则**：只有相邻两侧都有实测值才连线（温度 7 段、湿度 9 段、压差 11 段），
  缺测两侧一律断开，**没有用直线或虚线补值**；缺测列用白色虚线 + “缺测”文字标记。
- **独立采样标记**：每个真实读数一个 10px 圆点，上方药丸底衬标注该点数值（数值标签防重叠，
  相邻标签强制 ≥52px 间隔），负值读数用红色标记与标签。
- **压差零线**：白色 3px 通栏零线（探针 y=702，与计算值 702.4 相符），刻度 −1.0…1.5 kPa。
- **每图独立纵轴单位**：面板标题“温度 · 纵轴单位 °C / 相对湿度 · 纵轴单位 % / 压差 · 纵轴单位 kPa”，
  且最高刻度带单位（24 °C、45 %、1.5 kPa）；量程分别为 19–24、30–45、−1.0–1.5，均覆盖观察极值。
- **上方统计卡**：三卡各列指标、单位、有效采样数、观察最小/最大值。
- **下方明细表**：全部 12 时点 × 3 指标，缺测显示“—”，行标签用对应指标色与图中线条同色建立关系。
- **图例**：真实采样点、缺测处断线（不补值）、缺测（非 0）、负区段，四项均在页眉。
- **字号**：标题 40、面板/卡片标题 22、正文与表格数值 20、轴刻度/标记数值/图例/表头 18（正文≥20、轴/表≥18）。

## 实际问题、修复与验证

1. **语法（服务端 400）**：首版 `border="1" borderColor="#..."` 被服务拒绝
   （`PARSE_ERROR: Attr [border] value is invalid`，requestId ea6bffee-…），按 ai-guide 的
   组合语法改为 `border="1 SOLID #color"` 后通过。错误 JSON 原文保留在 drafts 中，未计入最终图。
2. **标签粘连**：相邻点数值标签互相压盖 → 加底衬药丸并强制 52px 最小间隔，复查后 19.2/19.6、
   41/40、0.2/0.4 均已分开。
3. **负值标签压零线**：负值点标签移到药丸内并遮住零线，零线在其余区域保持连续清晰。
4. **注释越界**：负区段注释原为一行 860px，右端压住面板右上角说明 → 拆为两行、宽 640px。
5. **表格裁字**：“相对湿度 %”因行标签宽 100px 被裁 → 列起点 144→160、标签宽 116。
6. **虚线穿字**：缺测虚线从面板顶起画会穿过“缺测”二字 → 虚线从文字下方 30px 起画。
7. **几何核验**（probe_a05.py，均通过）：三面板参考线 x=497 对齐；压差零线 y=702；
   温度 09:00 标记 y≈302（计算 302.4）；压差 10:10 标记 y≈745（计算 745.3）；
   09:40 标记 x≈613、10:50 标记 x≈937（计算 613.0 / 937.0）；湿度 12:10 标记 y≈493（计算 493.5）。
8. 最终 PNG 与已查看的 v3 草稿 **md5 字节一致**，交付图即所见图。
