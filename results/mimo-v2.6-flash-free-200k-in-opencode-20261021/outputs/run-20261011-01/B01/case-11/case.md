# case-11 · 夜巡观星 · 今晚观测条件卡

- 受众：城市天文爱好者（傍晚出发前手机扫一眼，亦可发小组帖）
- 使用场景：出发决策，1200×1200 方形
- 用户目标：选出今晚最佳观星时段，并对比市内/近郊两观测点
- 内容来源：自拟虚构观测数据：残月 18%（月出 03:12）、云量 12%、视宁度 3/5、透明度 4/5、Bortle 6/8 两站点
- 视觉主张：深空夜色：星野底 + 残月几何 + 四项条件点阵 + 时段评分 + 两站点对比
- 尺寸：1200×1200（final.png 实际 IHDR 读取一致）
- 最终版本：v4（B01-c11-v4，4 次渲染）

## 素材情况
纯 DSL 构建，无外部素材；全部色块/文字/图形由 .snapshot 自包含生成（asset_policy 允许素材但本题选择纯 DSL）。

## 虚构声明
“夜巡观星”与全部气象/月相/评分虚构；Bortle 等级含义为通用天文常识。品牌、人物、机构与全部数据均为虚构演示；不指向任何真实客户或实际部署。
