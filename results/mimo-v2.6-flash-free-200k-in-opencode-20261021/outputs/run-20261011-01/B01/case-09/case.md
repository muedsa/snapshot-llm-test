# case-09 · 赶海历 · 东岙湾潮汐窗口

- 受众：周末赶海爱好者（出发前手机 + 渔市张贴）
- 使用场景：出发决策，1500×1000 横版
- 用户目标：按当日潮位曲线决定去哪片滩涂、采什么、几点必须撤
- 内容来源：自拟虚构潮汐：四极值（05:20 高 4.2m / 11:40 低 0.6m / 17:50 高 4.0m / 23:55 低 0.8m）余弦拟合
- 视觉主张：潮位曲线主角：真实双峰正弦 + 赶海窗口带 + 挖点三卡 + 安全线
- 尺寸：1500×1000（final.png 实际 IHDR 读取一致）
- 最终版本：v2（B01-c09-v2，2 次渲染）

## 素材情况
纯 DSL 构建，无外部素材；全部色块/文字/图形由 .snapshot 自包含生成（asset_policy 允许素材但本题选择纯 DSL）。

“赶海历·东岙湾”与潮汐/滩涂数据虚构；潮型为通用半日潮模型。品牌、人物、机构与全部数据均为虚构演示；不指向任何真实客户或实际部署。

## 迭代记录
