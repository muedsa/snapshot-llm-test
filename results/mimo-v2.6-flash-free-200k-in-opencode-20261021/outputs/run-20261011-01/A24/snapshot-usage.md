## 真实文档与标签能力应用

- 服务指南与 DSL 文档复用本 run 已缓存的 `_suite/docs/`（此前任务真实取得，
  本次无新增 HTTP 请求）；服务地址以 run-config 为准。
- **本题新学并实测的 DSL 事实**：
  1. `DecoratedBox` 边框是**单一属性** `border="宽度 SOLID 颜色"`（round-01 三图 400
     实测：写成 `border` + `borderWidth` 两属性即报错）；
  2. `Text` 超出宽度会折行，**固定高度框裁掉第二行尾字**（无省略号）——五轮中 7 处
     文本踩中，最终按字宽预算逐行核对；
  3. 绘制顺序即层叠：不透明面（泳道白底）会盖住先绘细线（网格线/竖线），必须放在
     其后、任务块之前；
  4. 圆角矩形相接处底色透出（蝴蝶结通道），需实色接缝补条（像素级发现与验证）。

## 设计选择

- 同一 `a24_common.SCHEDULE` 生成三图 DSL 与三份 JSON；
- board 用奇偶行错开图注避免碰撞、依赖只用块下编号索引（不画跨线）；
- brief 的 DAG 用显式 polyline（含 skip 层左侧走廊）保证零穿节点；
- card 每行两层信息（行 1 时间/ID/标签/团队，行 2 依赖或风险），风险徽标上移一行
  换取行 2 全宽。
