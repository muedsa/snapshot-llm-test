## 能力判定（依据真实文档/接口，不编造）
- 接口/格式：ai-guide.md——`POST /snapshot` 单次单图，`type` 仅 `png`/`jpg`/`webp`
  → 无 SVG 输出、无 CMYK 参数、无 GIF/多帧/时间轴。
- 透明背景：DSL 文档 `background` **默认 transparent**、颜色支持 `transparent`/
  `#RRGGBBAA`；**探针 `A23-probe-01` 实测**：返回 PNG 为 RGBA、四角 alpha=0 → 透明真实。
- 旋转：`Transform matrix` 列主序 16 元组 + `alignment="CENTER"`（绕自身中心）；探针实测
  **正角=顺时针**（+45° 使端点标记落到右下），与题目"顺时针度数"约定一致。
- 全套文档为本 run 早前真实取得的本地缓存（`tmp/run-20261011-01/_suite/docs/`），本题复用、
  无新增文档 HTTP（requests.jsonl 中 other_service_requests=0 如实反映）。
