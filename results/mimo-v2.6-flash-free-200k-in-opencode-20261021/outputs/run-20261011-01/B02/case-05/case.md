# case-05 · 志愿者排班表

- 受众：志愿者与管理员（出门前手机查看/工具房打印）
- 使用场景：1400×1000 横版网格
- 用户目标：看清本周各时段岗位缺口并认领
- 旅程阶段：参与
- 内容来源：自拟虚构演示数据（见虚构声明）：7 天×4 时段网格、四岗位需求与缺口高亮、容量条、认领方式与联系人
- 视觉主张：排班网格：叶绿表头语义 + 土陶缺口高亮 + 容量条三色
- 尺寸：1400×1000（final.png 实际 IHDR 读取与计划一致）
