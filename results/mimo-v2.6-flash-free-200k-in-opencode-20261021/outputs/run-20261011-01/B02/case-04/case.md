# case-04 · 菜篮订阅卡

- 受众：家庭用户（微信群/朋友圈转发，手机竖屏睡前点开）
- 使用场景：1080×1920 手机长图
- 用户目标：选好规格并知道配送日与退订规则
- 旅程阶段：复购
- 内容来源：自拟虚构演示数据（见虚构声明）：三规格价格与适用人数、每周菜色示例、配送自提、订阅流程、退订规则
- 视觉主张：手机长图：三层规格卡 + 菜色 chips + 流程条 + 规则脚注
- 尺寸：1080×1920（final.png 实际 IHDR 读取与计划一致）
- 最终版本：v2（B02-c04-v2，2 次请求 / 2 次看图）

## 素材情况
纯 DSL 构建，无外部素材；全部色块/文字/图形/图表由 .snapshot 自包含生成（asset_policy 允许素材，本题选择纯 DSL）。

## 虚构声明
品牌、价格、菜色为虚构演示；菜色随采收微调已注明。品牌、人物、机构与全部数据均为虚构演示；不指向任何真实客户或实际部署。
