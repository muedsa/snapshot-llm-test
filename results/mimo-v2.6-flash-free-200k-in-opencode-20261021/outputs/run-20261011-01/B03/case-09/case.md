# case-09 · 夏夜观星星图

- 受众：观星活动参与者（楼顶活动现场手持 A4 图板，0.5m + 头灯弱光）
- 使用场景/观看环境：夜间户外弱光 A4 图板 0.4–0.6m
- 用户目标：找到 3 个目标天体：方位、仰角、最佳观测时段对得上
- 内容范围（计划记录）：星场（星等→星径）、3 组星座连线与名称、银河带、方位圈（东南西北）、观测时刻表与月相提示
- 视觉主张：220颗星场 + 银河带 + 两真实星座与一虚构星座 + 方位圈 + 时刻表
- DSL 手法（计划记录）：程序化星场：确定性 PRNG 播种、星等 1–5 级映射星径；亮星辉光=ImageFiltered 模糊层；连线=旋转段
- 尺寸：1600×1000（final.png 实际 IHDR 与计划一致）
- 最终版本：v2（B03-c09-v2，2 次请求 / 2 次看图 / 3 条迭代日志）
