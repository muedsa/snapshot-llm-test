### case-01 · 青禾岭登山等高线路线图（1200×1600，final=v3）

- **手法**：程序化等高线——同一山形母题按高程递减半径生成同心椭圆环带
  （`ring_rx()`：10 条 @40m 等高距，峰顶 782m），计曲线（每 200m）加粗 + 高程注记；
  两条路线为折线段首尾相接，穿过等高线处画"过线"刻记；补给点圆点 + 名称；比例尺条由
  段长=实际图上距离推算（1px 换算断言）；用时表 = 距离/平速 + 爬升/爬速 逐行计算。
- **文档依据**：`seg/box/circle/text` 基础图元；`stroke_w` 分层（计曲线 3px/首曲线 1.5px）；
  `letter_space` 微调注记；`alpha` 8 位十六进制尾缀控制环带透明度。
- **试验与看图证据**：v1 首渲 400（XML 声明）→ v1b 修复后看图（200，baseline）；
  v2/v3 视觉迭代（过线刻记可读性、表内数值复核）。终版 v3 复看：两条路线各自沟槽内读得清，
  表内 4.2/4.5h 与 402/400m 对应爬升/平速自洽；`requests.jsonl` B03-c01-*，观察在 `iterations.jsonl`。
- **应用价值**：证明 DSL 可做"数据驱动的地形图"——环半径函数 + 表格同源计算，
  适合路线图/楼层平面/海图类信息图。
- **已确认边界**：BorderStyle 仅 NONE/SOLID（`enums.txt`），无原生虚线；本件未用虚线。
  环半径单调性由生成期断言保证，服务端不做几何校验。

### case-02 · 江城地铁换乘图（1800×1000，final=v2）

- **手法**：强制直角几何——所有对角段 |dx|=|dy| 恰 45°（生成期逐段断言）；
  线路色带 = 粗 `seg` 沿 0/45/90° 折线；换乘枢纽 = 双环白心（大圆描边 + 白色内圆）；
  站点 = 均匀参数 t 在折线上取点钉圆；末班车表行色 = 线路色一致（断言 hex 相等）。
- **文档依据**：`Transform` matrix 列主序（45° 段 = dx=dy 构造，避免矩阵法误差）；
  `circle` 的 `border_w` 环；表格用 `box` 分行底 + `text` 对齐。
- **试验与看图证据**：v1 200（baseline 看图），v2 视觉迭代（换乘站注记与步行分钟
  引线避让）。终版 v2 复看：3 线 12 站 2 枢纽齐备，末班车表与线路色对应。
- **应用价值**：线性拓扑图（地铁/公交/流程）可完全参数化；"折线段 + 均匀取点钉站"
  是可复用组件。
- **已确认边界**：同上——虚线需手造；文本不自动避让几何，重叠须生成期预算 + 看图。

### case-03 · 昼夜节律钟盘（1200×1200，final=v2）

- **手法**：SWEEP 扫描渐变做昼夜环带（`grad gtype="SWEEP"` 1 圈，probe-01 验证可渲染）；
  24h 双色整点刻度（白色外基 + 墨色内芯，两种底色上都可读）；睡眠弧 = 沿弧等距旋转
  短矩形拟合（`arc()` 切线长度 = 间距×1.8 的经验系数）；缺口段用高亮色 + 分钟数标注；
  理想/实际两组弧不同半径并列。
- **文档依据**：`grad` 的 SWEEP/RADIAL 模式（probe-01 实测）；trig 定位极坐标
  （15°/h 断言 = 360/24）；`arc()` 参数（角度制，起止角）。
- **试验与看图证据**：v1 200（baseline 看图，星等/弧段检查），v1 生成期 syntax_fix
  （弧段拟合系数），v2 视觉迭代后定稿。终版 v2 复看：缺口 1h20m 高亮醒目，
  24 刻度在昼夜两种底色上均可读。
- **应用价值**：任何"角度=数值"的图（钟盘/仪表/雷达/饼图替代）都可用 SWEEP+trig 复刻。
- **已确认边界**：probe-02 确认 `fontFeatures smcp` 对 Noto Sans CJK SC 无效果
  （小型大写不生效，CJK 无对应字形）；本件未依赖 smcp。

### case-04 · 摩尔纹科普展板（1000×1400，final=v2）

- **手法**：摩尔纹——两层细线栅（线距 6px 一致，`d=6/sinθ` 推导条纹间距）
  以 0.5°/10° 错角叠放；`ClipRect`（`clip()` helper）把叠加限定在演示窗；
  主窗 0.5° 错角呈粗大条纹、对照窗 10° 错角条纹细密，形成对比；
  条纹走向用引线文字如实标注"几何后果"。
- **文档依据**：`clipBehavior`/`ClipRect`（`clip()` helper 生成）；
  线层用不同 `alpha` 区分前后；`Transform` 旋转 0.5°（列主序矩阵）。
- **试验与看图证据**：v1 400（XML 声明）→ v1b 200（baseline），v2 视觉迭代
  （条纹对比度、窗边框）。终版 v2 复看：两窗条纹差异肉眼明显，参数标注 6px/0.5°/10° 与
  推导一致（d_main=687.5px、d_ctrl=34.56px 断言）。
- **应用价值**：证明 DSL 能构造"物理光学现象级"视觉（干涉/衍射类），
  双层线栅 + ClipRect 是可复用图案组件。
- **已确认边界**：`letter_space`（`letterSpacing`）在 `tw()`/`fit()` 宽度预算中必须计入，
  否则 CJK+tracking 文本会估窄而溢出（本件标注文字踩过，已修入 common）。

### case-05 · 工坊轴测导览图（1400×1000，final=v4，含 plan-v1a 修订）

- **手法**：等距投影——`Transform` 斜切矩阵（x'=x−y·cos30 系数）逐面构造挤出体块；
  顶面亮/左面中/右面暗三阶明度（三组颜色互异断言）；5 个 zones 事实表单一来源驱动
  三面体块与底部尺寸表（逐行一致断言）；动线 = 琥珀虚线（手造短划阵列）+ 编号 [1..5]。
- **文档依据**：`Transform` matrix 列主序 + `alignment` 锚点（probe-04 A/B/C 对照确认
  面语义：锚点在角点 + 线性矩阵 + 零平移才能正确出面）；`filter` 模糊可给体块投影柔化。
- **试验与看图证据**：probe04 专测 Transform 面构造（3 变体渲染对照）；
  v1/v2/v3 视觉迭代（v3 修复"体块不渲染"——AABB 尺寸失真问题）；
  v4 为交付版。终版复看：5 体块三面明暗分明，动线 5 站连贯，尺寸表与体块逐行对得上。
- **plan-v1a**：原计划"长宽高 2:1:1"条件改为"各区实际尺寸与表逐行一致"（真实工坊各区
  尺寸不同），修订于 case-05 首渲前，依据 `plan-v1a-case05-amendment.json`。
- **应用价值**：轴测/等距建筑图、爆炸图、流程立体图的可复用范式；
  单一事实表驱动多视图（体块+表）是数据一致性的关键手法。
- **已确认边界**：`Transform` 不裁剪（无 clipBehavior）——超出画布的 paint 会外溢，
  需靠 Positioned 锚点控制；用 AABB 而非逻辑矩形做尺寸会失真（v3 实证）。

### case-09 · 夏夜观星星图（1600×1000，final=v2，收口到 plan-v1）

- **手法**：程序化星场——确定性 PRNG（LCG）播种 220 颗（计数断言），
  星等 0–1 映射星径 0.9–2.4（带宽 + 离散度断言）；亮星辉光 = 两级（`blur()` 模糊层 +

- **文档依据**：`blur()` 辉光；`prng()`（`C.prng` = LCG，DSL 无原生随机，用脚本侧 PRNG
  生成坐标后内联进 DSL——**边界**：最终 .snapshot 仍是确定性静态文本）；
  `seg` 星座连线；`circle` 双层星点。
- **试验与看图证据**：v1 生成期 syntax_fix（星等半径断言过严：LCG 不保证恰有 m=0/1 样本，
  改为上下界+离散度>1.0，未发请求）→ v1 200（baseline）→ 收口 v2（requirement-change：

  无碰撞可读，时刻表与图面位置对得上。
- **收口记录**：原版 2 组星座缺时刻表/方位圈/月相，user_goal（找到 3 个目标的方位/仰角/
  时段）不可达 → 收口。
- **应用价值**：星空图/散点图/星链拓扑的程序化范式；"显示值 = 几何推算值 + 断言"
  是图表数据一致性的强保证。
- **已确认边界**：星径映射带宽断言（0.9–2.4px）在渲染端受抗锯齿影响，极小圆点
  <1px 不保证可辨——故下限 0.9 已考虑渲染余量。
