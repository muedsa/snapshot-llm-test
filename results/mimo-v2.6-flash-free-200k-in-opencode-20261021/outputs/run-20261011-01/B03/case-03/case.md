# case-03 · 昼夜节律钟盘

- 受众：中学生家长（家长群/打印贴冰箱，手持 0.4m）
- 使用场景/观看环境：手机/打印 0.4–0.6m
- 用户目标：看懂孩子睡眠缺口：理想与实际作息在同一钟面比较
- 内容范围（计划记录）：24h 钟面+整点刻度、理想睡眠弧（22:30–6:30）、实际睡眠弧（23:40–6:20）、缺口高亮与分钟数、3 条调整建议
- 视觉主张：SWEEP 昼夜环带 + 24h 双色刻度 + 理想/实际睡眠弧 + 缺口高亮

- 最终版本：v2（B03-c03-v2，2 次请求 / 2 次看图 / 3 条迭代日志）
