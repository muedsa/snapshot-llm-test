- **换乘 = 改变乘坐线路，第一次上车不计**。边数 = 站序长度 − 1；报告同时给出站数（7 / 7 / 5）以免把站数当区间数。
- **无障碍约束**：`accessibility` 是站设施属性，非无障碍站可以被列车驶过，但无障碍旅程不能在它上车、下车或换乘。
  三条查询在 S13→S12 上产生了真实差异：普通最短路在 **S05 东桥**换乘，而 S05 是非无障碍站，因此必须改走经 **S08 工坊 → S04 中心**的两段换乘路线（边数不变，换乘 +1）。
- **没有为了满足无障碍而删除任何线路或车站**；S03、S05、S09、S14 四个非无障碍站全部保留在图上并标注。

## 3. 地图几何（`map-geometry.json`）

几何不是手排，而是由 `solve_map2.py` 求解并硬校验四条约束：

1. **八向合法**：每一段绘制线段都是 0° / 45° / 90°；
2. **节点间距 ≥ 70px**：任何两个不同站不会近到被看成同一个点；
3. **无站落在异线**：任何站到不属于它的线路段的距离 < 24px 就报错；
4. **全部在画布内**（150 ≤ x ≤ 1360，150 ≤ y ≤ 800）。

共享站（S04 中心、S05 东桥、S08 工坊）是**同一个节点**，两条线路在此真正交汇；单纯交叉处使用**两个不同节点**（例如 R 的中心与 B 的中心是两个点），因此不会被误读成换乘。地图线宽 12px，每个绘制小段中点都带 **R / B / G 字母徽标**，颜色从不是唯一线索。

## 5. 实际遇到的问题与修复

| 问题 | 现象 | 修复 |
|---|---|---|
| **路径重建读到了过期的父指针树** | 松弛过程中同一状态的最优值被反复覆盖，重建时按旧父指针走，S01→S11 报成 6 边 2 换乘并绕成 …中心→花园→南门… | 先跑完整松弛、再取目标状态、最后从**最终**父指针重建；修正为 6 边 1 换乘 |
| **换乘计数把首乘算进去、换乘站错位一位** | 三条查询的换乘数都多 1，换乘站显示成上一站 | 只在 `lines[i+1] != lines[i]` 时计一次，换乘站取 `stations[i]`（i 从 1 起） |
| **无障碍判定过宽** | 只要起终点无障碍就判可用，忽略了需在非无障碍站换乘 | 改为检查起点、终点与全部换乘站；S13→S12 因此被正确判为不可用 |
| **手排坐标大量违反 45°/90°** | 首版地图有 9 段既非水平也非垂直也非 45° | 写几何求解器，把八向合法等四条做成断言；未通过就不写文件 |
| 图例压住地图 | 图例初版放在右下角，正压住南门/会展 | 图例移到独立底栏（y 840–932），地图可用高度按站名上边距反推 |
| 站名与线路互相压字 | 站名与点同排、G 线与 R 线共用走廊 | 站名固定放在点上/下独立行带；G 线整体下移到 y=600/720 走廊；S06 左移让开 G 的竖段 |
| 旅行卡站名压线路、说明被截 | 7 站排一行导致单格 88px 放不下「非无障碍」，替代说明超宽 | 站序改为每行 4 站、站名独占一行带；卡片高度按内容带显式给定；替代说明拆两行 |
| `EMPTY_REQUEST` | 生成器把累加器重置后 `add` 仍指向旧列表，第二张图 DSL 为空 | 重置后重新绑定 `add = P.append` |
| `minHeight must be between 0 and maxHeight` | 卡片高度公式在某种行数下算出负值 | 改为按「是否需要替代块 + 行数」显式给定高度 |
