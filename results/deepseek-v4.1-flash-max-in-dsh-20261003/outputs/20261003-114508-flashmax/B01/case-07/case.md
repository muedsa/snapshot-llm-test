# case-07 · 儿童疫苗接种时间轴

- 主图：`final.png`（1240×1560，服务原始响应字节）
- DSL：`final.snapshot`（版本 v2，UTF-8 无 BOM）
- 渲染请求：B01-REQ-0022、B01-REQ-0027、B01-REQ-0039
- 迭代记录：c07-v1-baseline、c07-v2-visual

## 场景

| 项目 | 内容 |
|---|---|
| 受众 | 幼儿家长 / 社区接种门诊 |
| 使用环境 | 竖版打印后贴在家庭文件夹内页，或手机上查看 |
| 要完成的事 | 一眼看出哪些剂次已完成、哪一次漏了、下一次什么时候该去 |
| 内容来源 | 虚构儿童（2024-08-12 出生）的演示接种记录；月龄、剂次统计、延迟天数由脚本计算 |

## 视觉选择

用一条纵向时间轴 + 状态色把所有节点串起来，延迟节点单独标出计划日期与实际日期的差值，避免「以为打过了」

## 用到的 DSL 能力

纵向时间轴、状态徽章、动态宽度标签、日期差计算、表单式底栏

## 自定完成标准

每个节点的状态色必须与其实际日期一致；剂次总数与已完成数必须自洽；状态徽章不得溢出卡片

## 实际自检

1. `final.png` 已用 `read_image` 打开本体逐项核对：每个节点的状态色必须与其实际日期一致；剂次总数与已完成数必须自洽；状态徽章不得溢出卡片
2. 最终 PNG 与临时目录中被审查通过的渲染结果 SHA-256 完全一致（`tmp/.../B01/verify_final.py`）。
3. 所有数值由 `cases/c07.py` 计算并写入 `tmp/.../B01/data/c07-vaccine-timeline.json`，未手工填写。

## 素材情况

纯 DSL 构造，无外部图片、无嵌入素材；主体图形（曲线、网格、弧带、版型、航迹）全部由 `Container` / `Text` / `Transform` 组合生成。
