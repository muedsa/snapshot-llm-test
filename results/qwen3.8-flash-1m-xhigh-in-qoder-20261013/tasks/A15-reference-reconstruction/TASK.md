# A15 · 复杂界面视觉复刻

先完整阅读 [AGENTS.md](AGENTS.md) 的执行、目录、留痕和指标约定；该文件是本任务要求的一部分。

## 任务

inputs/reference.png 是1440×900参考界面，inputs/content.json 仅提供原样文本和
数值以减少OCR歧义，不提供几何坐标。用Snapshot DSL重建参考图的布局、背景、
侧栏、卡片、图表、表格、状态标签和主要装饰。禁止直接嵌入参考图或裁块当素材。
输出尺寸保持1440×900，所有主要结构与信息完整，不改成自己的新设计。
观察原尺寸、缩略与局部放大；主区边界/卡片边界/图表零线/导航选中态等关键
锚点应与参考一致（允许±8像素），颜色可小幅近似，字体从实际服务列表中选择。
重建图表的比例与标记，而不是只放相同数字；表格3行顺序与状态编码准确。
至少记录12个视觉锚点的参考估计坐标和重建坐标，涵盖画布四象限、图表和表格。
交付 reconstruction-audit.json 与 comparison.md：用可测误差及实际视觉说明
残余差异。不要求DSL树与参考来源一致，不必宣称不存在的逐像素完全复刻。

## 锚点测量与颜色判断

reconstruction-audit.json至少覆盖以下12个不同对象：
侧栏右边界、导航选中态外框、主标题可见字形框左上角、三张KPI卡外框（各1项）、
净收入图表卡外框、图表零线左端点、最后一根柱的顶部中心、活动卡外框、
项目表格卡外框、最后一行状态标签外框。可增加锚点；检查位置须覆盖画布四象限。
参考坐标仍由观察公开reference.png估计，不提供作者源码或标准坐标。

原点为画布左上、单位像素；边界项记录x或y，点项记录(x,y)，矩形项记录
[left,top,right,bottom]，均使用外轮廓，不混用文字基线、中心和边界。
±8px指对应分量的绝对误差均≤8，矩形四边分别比较；不平均误差抵消偏移。
每项记录明确对象/测量类型、参考估计、重建实际值、分量误差、测量方法及局部证据。
文字锚点比较可见字形位置；不同字体的其余字形差异在comparison.md如实解释。

颜色采用原尺寸及相同背景下的人工并排判断，不设置未公开的RGB或色差硬阈值。
逐项说明主背景、侧栏、主蓝色、卡片和状态标签的色相、明暗与角色是否接近；
可记录纯色内部采样辅助解释，不能只写“颜色一致”。几何容差合格不替代对
图表比例、全部文字、状态编码和整体视觉的检查。
