# B01 策展说明 · 十张真实场景用例

run `2026-10-12T10-04Z-r001` · 赛道 B（DSL 主导，允许局部辅助素材）· 服务 `https://open-snapshot.muedsa.com`
路径基准 `path_base = suite_root`（相对总任务根）。

## 策展逻辑

十件作品按**使用任务**而不是按视觉风格挑选：每一件回答一个不同的问题——"怎么换乘"、"哪晚没月亮"、
"这袋豆怎么冲"、"今天能不能户外"、"哪段最累"、"我想看的这四组赶得上吗"、"我们四个人坐哪儿"、
"哪儿最热、该在哪降温"、"这块棋为什么死"、"这一趟电量够不够返航"。因此它们的媒介语言天然不同：
交通示意图、历表、产品参数卡、监控看板、剖面卡、排片决策图、座位平面图、气候制图板、棋谱讲义、
作业票。同一套构件（`tmp/<run_id>/_suite/scripts/bkit.py`：实测字宽、文本避让、环形扇段、
ClipPath 多边形、布局审计）被复用到十种版式上，复用发生在几何与排版层，不发生在画面层。

三条贯穿的取舍：

1. **数字必须由图形的那次计算产生。** 十件里有八件把"结论"交给脚本计算：月龄、AQI 等级、
   累计爬升、时间冲突与上界、观影视角、等值线、围棋穷举、逐段能耗。图上的文字与图形的坐标来自
   同一个数组，所以不会出现"色说优、数说差"。
2. **状态色只服务一个决定。** 观看者不需要读图例就能明白"能不能做某事"：红/绿/橙、受限斜叉、
   逆风分段色。case-06 的第一版用风格色描边未选节目，与状态色撞车，v4 改成中性灰。
3. **可读性按目标观看环境校准。** 1920×1080 大厅屏与 1200×1500 手机截图的最小字号同为 20px，
   但行距、色带饱和度和信息密度不同；户外强光下的 case-10 用浅底高对比，暗光现场的 case-06 用深底。

## 逐件用途与最有辨识度的一点

| 用例 | 谁在什么时候用 | 最有辨识度的视觉选择 |
|---|---|---|
| case-01 轨道网络图 | 到访者在站厅灯箱前找换乘 | 全部线段只取 0°/45°/90° 的格点纪律，换乘站是真实交点 |
| case-02 月相历 | 志愿者排开放夜 | 用两条圆弧围出的月牙，凸向随盈亏翻转，全年 12/13 次由过零检测算出 |
| case-03 手冲参数卡 | 顾客在吧台前决定怎么冲 | 24 扇区 × 3 环的真实极坐标风味轮，与雷达多边形共用同一组分数 |
| case-04 空气看板 | 通勤者/校医早上看一眼 | 仪表弧、色带、数字、建议四者由同一等级函数驱动，不可能互相打脸 |
| case-05 徒步剖面卡 | 出发前 5 分钟读图 | 闭合面积图 + 按里程插值的标记，摘要数字由几何反算 |
| case-06 音乐节排片 | 乐迷在入口做决定 | 红/橙/绿三态与"最多 4 场"的上界证明放在一起，动线可复核 |
| case-07 影院选座 | 四人购票 | 建筑平面图语言（尺寸线、分区括线、斜线填充）把"为什么不能坐"画出来 |
| case-08 热岛制图板 | 选址讨论会 | run-length 合并栅格 + marching squares 等值线 + 同函数断面剖面 |
| case-09 围棋讲义 | 学员课后复盘 | 结论由规则引擎穷举 16 条合法次序得出，而不是引用口诀 |
| case-10 巡检作业票 | 起飞前 3 分钟平板确认 | 航线按该段逆风分量着色，电量条上直接画出剩余 10% 红线 |

## 完成标准与证据

- 计划文件：`tmp/<run_id>/B01/work-plan.json`（v2）。case-07..case-10 的标准在首次渲染前建立；
  case-01..case-06 的标准在事后写入，文件里如实标注 `formalized: after_first_render` 并保留
  `change_log`，没有回填时间。
- 逐条检查结果：`outputs/<run_id>/B01/portfolio.json` 的 `criteria_results`，每条给出判据、
  方法与证据路径。
- 共同底线（S1–S5）：构建期布局审计 0 重叠 / 0 出界 / 最小字号 20px；`final.png` 与服务响应
  字节一致（`hashlib` 比对，见 `tmp/<run_id>/B01/` 版本序列）；每件都实际打开看图并迭代；
  图中数字与几何同源；文字对比度按 WCAG 复算。

## 内容真实性

品牌、机构、人名、艺名、场次、票价、温度、棋形、电场全部自拟，属于演示数据；
每件 `case.md` 与画面本身都写明这一点，不宣称是任何真实客户或实测结果。
