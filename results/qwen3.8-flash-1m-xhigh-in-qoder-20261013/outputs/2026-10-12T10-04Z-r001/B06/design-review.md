# B06 · 设计评审（design-review.md）

评审依据只有两样：最终画面本身，以及生成它们的代码与数据。**没有用户实验**，因此凡涉及「读者会更快/更不容易出错」的判断，都明确标为推断而不是结论。

## 一、可观察的改善（从画面本身可验证）

### case-01 · 末班车还赶得上吗

- **原物料的卡点**：时刻表按线路排，乘客要自己做「我的时间 vs 每站末班」的减法
- **重构动作**：把表倒过来：以「你此刻在站台」为唯一输入，列出每个目的地的最迟离开时刻
- **画面上可核对的改善**：
  - 12 个目的地按「最迟离开本站」排序：还剩 17 分到差 21 分
  - 9 地可去、3 地已来不及；最远可达莘庄（车程 26 分，最迟 23:51）
  - 「换 N」标出换乘次数——真正卡住行程的往往是换乘而非本线末班
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：只覆盖一条方向、一种出发站；换方向需另做一张。

### case-02 · 现在要不要等这趟公交

- **原物料的卡点**：站牌只写首末班与间隔区间，回答不了「现在」这一问
- **重构动作**：把一天摊成一条带子，一格 30 分钟，颜色=要等的分钟数；针尖右侧就是答案
- **画面上可核对的改善**：
  - 31 格 × 30 分钟，覆盖 05:30 首班到 21:00 末班
  - 四档间隔 4 / 8 / 10 / 12 分钟各配文字说明，不只靠颜色
  - 现在 20:12 落在夜间档 → 最坏等到 20:24
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：假设间隔在半个时段内均匀，真实公交到站方差远大于此；没有实时数据。

### case-03 · 应发 12000，到手 8700：中间去了哪

- **原物料的卡点**：工资条列了项目和比例，但没说哪些是自己的钱、什么时候能用
- **重构动作**：同一笔钱拆成「谁的口袋 / 什么时候能用」两栏，并按一年重算一遍
- **画面上可核对的改善**：
  - 个人扣款 2,700 + 个税 600 + 到手 8,700 = 应发 12,000（断言）
  - 单位另出 4,704 元，单列一栏说明「不进你当期工资」
  - 第五节把六笔钱按一年重算：到手 104,400、公积金 34,560、个税 7,200
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：费率是示例区间，读者若按此核对真实工资条可能不一致（页面已注明）。

### case-04 · 七个箭头，哪个要紧

- **原物料的卡点**：报告按项目顺序罗列参考区间与箭头，看不出偏离幅度与紧急程度
- **重构动作**：放弃共用坐标轴，改为每项一条自己的参考带，偏离量在各自尺度上可见
- **画面上可核对的改善**：
  - 9 项指标各配自己的参考区间与刻度，不共用一条被压扁的轴
  - 7 项偏离，其中 5 项只超出区间一小截，画面如实呈现
  - 视力一项注明「区间只有 0.2 宽，倍数显得大」
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：每项一条自己的带子，代价是失去了跨项的「谁更偏离」总览；已用排序部分弥补。

### case-05 · 这一包，占掉我一天多少

- **原物料的卡点**：NRV% 以成人 8400 kJ 为基准，且「一份」的分母经常被人忽略
- **重构动作**：把「每 100 g」换成「这一包 / 半包 / 一包半占我一天多少」，双基准并列
- **画面上可核对的改善**：
  - 每 100 g 与每 75 g 两列并排，避免偷换分母
  - 能量 19.6%（成人）/ 23.2%（儿童）双基准同屏
  - 半包 / 一包 / 一包半三档占比由同一份数据算出
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：只做了能量/脂肪/糖/钠四项，蛋白质与膳食纤维未列。

### case-06 · 暴雨预警：颜色之后要做什么

- **原物料的卡点**：四级颜色只表示高低，不告诉居民停课、转移还是照常上班
- **重构动作**：四级并排成四张行动卡，每级写谁受影响、该做什么、何时解除
- **画面上可核对的改善**：
  - 四级 2×2 卡片：触发标准、谁受影响、该做什么、停课/停工/解除
  - 当前生效级别用红框 + 「当前生效」文字双重标注
  - 顶部递进条保留颜色顺序，但每级都写名称
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：四级文案为通用防灾常识，未查证任何城市的具体细则。

### case-07 · 退租时，押金能拿回多少

- **原物料的卡点**：押金规则散在四条条款里，退租前算不清会扣多少
- **重构动作**：把散在四条条款里的规则合成一棵树，另附三条常见路径的金额结果
- **画面上可核对的改善**：
  - 四个判断节点各带合同条款号；「是」向下、「否」向右掉出结果
  - 三条路径的退回金额 = 押金 - 扣款（断言）：3,800 / 1,900 / 3,457
  - N2 的「否」明确写「不扣费」，不与 N3 的修补费混淆
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：四个判断节点是示例合同的简化；真实合同可能有更多分支（如提前退租、转租）。

### case-08 · 这三种事故，你要自己掏多少钱

- **原物料的卡点**：保单写保额与免赔，不发生事故永远不知道哪些不赔
- **重构动作**：换成三个具体事故，每个画「损失→赔付→自己掏」，缺口用斜纹显式标出
- **画面上可核对的改善**：
  - 三场景同一比例（1 元 = 0.00406 px），斜纹严格裁在不赔区间内
  - 自掏 16,000 / 0 / 45,800，合计 61,800 元写在页首
  - 每个缺口都指回一条条款号
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：三个场景是挑选出来的极端对照，不构成对某张保单的整体评价。

### case-09 · 门诊大楼：你要去的科在哪

- **原物料的卡点**：楼层索引按科室拼音排，而人手里只有空间信息
- **重构动作**：画建筑剖切：科室落在各层东西区，并给一条从入口到目标的示例路径
- **画面上可核对的改善**：
  - 六层剖切，每层的东区/西区色块宽度与该层科室数量成比例
  - 红线示例：1 层东门 → 3 层东区抽血室，目标块加红框与圆点
  - 右栏 20 个科室按名称查楼层，与左图同一份数据
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：只画了一条示例路径；不同入口（西门/急诊）需另画。

### case-10 · 水、电、燃气：终于能放在一张表里比

- **原物料的卡点**：三种单位三种单价，无法比较，也看不出哪项在涨
- **重构动作**：统一折算成元/人·月做比较，同时保留原始单位与单价，再给可行动项
- **画面上可核对的改善**：
  - 统一成元/人·月：电 88.3、燃气 54.8、水 38.7，份额 48.6/30.1/21.3%
  - 原始单位与单价单独列出（度/立方米/吨），不让归一化掩盖差异
  - 可行动项里的每个数字（75.3、59.3、40.8% 等）都由 12 个月样本算出
- **几何自检**：overlap 0 / outside 0 / spill 0 / truncated 0 / 最小字号违例 0
- **仍存在的局限**：同比来自同一份示例样本，不能当作真实价格变化的证据。

## 二、无法从画面判断的部分

- 读者是否真的更快做出正确决定：未测。
- 老人 / 儿童等特定人群的实际可读性：未测，字号只是按观看距离设定的工程值。
- 示例数据的分布是否接近真实家庭：未验证，只保证内部自洽。
- 预警、保险、合同、社保等内容的**正确性**：一律以「示例」呈现，不声称与任何现行规定一致。

## 三、跨作品的共同判断

- 十件作品共用一条原则：**读者要做的换算，能搬到图这边就搬过来**（分钟差、比例、归一单位、条款合并、路径连接）。
- 颜色一律有文字或形状冗余；黑白打印与色觉障碍下信息不丢失。
- 三件作品（04、06、07）在评审中推翻了原编码：散点堆叠、四列过窄、清单不成树——这些不是审美调整，而是「编码本身不传递信息」的修正。
- 两处内容级错误（07 的「否 → 扣 200」、10 的「高出约 100 元」）在逐图核对中发现并改由数据计算，说明看图必须连着数字一起看。
