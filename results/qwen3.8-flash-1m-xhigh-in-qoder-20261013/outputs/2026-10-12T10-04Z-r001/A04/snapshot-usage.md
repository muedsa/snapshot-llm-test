## 数据事实（全部由脚本从 CSV 用精确分数计算，非手填）

| | 直接访问 | 推广访问 | 总体（成交总数÷访问总数） |
|---|---|---|---|
| 前期 | 2400/8000 = 3/10 = **30.00%** | 200/2000 = 1/10 = **10.00%** | 2600/10000 = 13/50 = **26.00%** |
| 后期 | 700/2000 = 7/20 = **35.00%** | 960/8000 = 3/25 = **12.00%** | 1660/10000 = 83/500 = **16.60%** |
| 变化 | **+5.00 pp** ↑ | **+2.00 pp** ↑ | **−9.40 pp** ↓ |

访问构成：前期 直接 80% / 推广 20%；后期 直接 20% / 推广 80%（两期总访问都是 10,000）。

分解（顺序分解，已在 `analysis.json → decomposition` 注明顺序依赖）：
只换构成、率保持前期 → 14.00%（构成效应 **−12.00 pp**）；再叠加两渠道率提升 → 16.60%（率效应 **+2.60 pp**）。
恒等式校验：26.00 − 12.00 + 2.60 = 16.60 ✓

错误算法对照：等权平均 (30+10)/2 = 20.00% → (35+12)/2 = 23.50%，会误判为**上升 +3.50 pp**，
与总体实际下降 −9.40 pp 方向相反。

## 实际应用的文档与标签能力

- `Container` 渐变（`gradientType/gradientColors/gradientBegin/gradientEnd`）做柱体立体感；
  `border="1 SOLID …"` + `borderRadius` 组合卡片。
- `Positioned(left, top, width)` 给 `Text` 提供紧宽度，使 `softWrap`/`textAlign` 可控。
- `Text` 的 `height` 是行高倍数而非盒高（`/reference/parser-tags/`），表格行用 `height="1.0"`
  才能压进 28px 行高。
- `ClipRRect` 单角圆角用 `borderRadiusTopLeft` 等四角属性，拼出堆叠条两端圆角。
- 字体取自 `GET /fonts`：`Noto Sans CJK SC` / `Noto Sans Mono CJK SC` / `Inter`。
