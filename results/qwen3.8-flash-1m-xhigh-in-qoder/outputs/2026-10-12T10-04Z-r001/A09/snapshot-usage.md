## 变换语义

印章 120×120，枢轴 (60,60)：红竖条 (8,8,28,92)、蓝横条 (36,72,68,28)、金横条 (64,8,40,28)、
黑圆点 圆心 (91,49) 半径 8。红条在左、金条在右上，圆点只落在右上，因此任何镜像或旋转后的
朝向都能被分辨；蓝、金两条部分相邻，旋转后仍可见相对位置。

约定：像素坐标 x 向右、y 向下，因此标准旋转矩阵取正角度即为图像上的顺时针。
复合顺序 `M = M_n·…·M_2·M_1`（按列表顺序作用），每步都围绕局部 (60,60)；
落位公式 `final(p) = M·(p − pivot) + 格心`。

每个标本只输出**一个列主序 4×4 矩阵**，通过 `<Transform matrix>` 作用在原始印章上；
三个矩形与圆点的坐标从未被手改。

| 编号 | 操作 | 线性部分 det | 手性 | 外接框 |
|---|---|---|---|---|
| T01–T04 | rotate 0/90/180/270° | +1 | 保持 | 96×92 / 92×96 / 96×92 / 92×96 |
| T05 mirror H | −1 | **反转** | 96×92 |
| T06 mirror V | −1 | **反转** | 96×92 |
| T07 mirror H → rotate 90° | −1 | **反转** | 92×96 |
| T08 rotate 90° → mirror H | −1 | **反转** | 92×96 |
| T09 scale 0.75 | +0.5625 | 保持 | 72×69 |
| T10 scale 1.25×0.75 | +0.9375 | 保持 | 120×69 |
| T11 rotate 30° | +1 | 保持 | 129×128 |
| T12 mirror V → rotate 30° | −1 | **反转** | 129×128 |

**T07 与 T08 顺序敏感性**：两者操作集合完全相同，但
`T07 = R90·H = [[0,-1],[-1,0]]`、`T08 = H·R90 = [[0,1],[1,0]]`，
矩阵不同、图像不同（`order_sensitivity.matrices_equal: false`）。

## 实际应用的文档与标签能力

- `Transform` 的 `matrix` 为必填列主序 4×4；平移相对子节点布局盒，
  因此矩阵里写的是 `(cell_w/2, cell_h/2) − M·pivot` 而不是绝对画布平移。
- `Stack clipBehavior="NONE"` 让旋转后的内容不被格盒裁切。
- 圆点用 `shape="CIRCLE"`，与矩形同处一个 120×120 子树，保证共用同一矩阵。
