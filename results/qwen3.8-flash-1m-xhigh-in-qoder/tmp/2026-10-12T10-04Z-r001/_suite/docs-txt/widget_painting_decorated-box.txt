# DecoratedBox

`DecoratedBox` 使用 `Decoration` 绘制颜色、边框、圆角、阴影、渐变或装饰图片。最常用实现是 `BoxDecoration`。

## 函数签名

Section titled “函数签名”

```
`

fun ChildSlot.DecoratedBox(

    decoration: Decoration,

    position: DecorationPosition = DecorationPosition.BACKGROUND,

    content: DecoratedBox.() -> Unit = {},

)

`
```

## 参数

Section titled “参数”

参数 | 默认值 | 说明
``decoration | 必填 | 要绘制的 Decoration
````position | BACKGROUND | 在子节点之前或之后绘制
``content | 空 | 最多一个子 Widget

## BoxDecoration 参数

Section titled “BoxDecoration 参数”

参数 | 说明
``color | 背景色
``image | DecorationImage
``````border | Border / BoxBorder
``borderRadius | 矩形圆角
````boxShadow | Array<BoxShadow>
``gradient | Linear、Radial 或 Sweep Gradient
``backgroundBlendMode | 背景层混合方式
``````shape | RECTANGLE 或 CIRCLE

```
`

DecoratedBox(

    decoration = BoxDecoration(

        color = 0xFF0F172A.toInt(),

        borderRadius = BorderRadius.circular(20f),

        border = Border.all(color = 0xFF334155.toInt()),

        boxShadow = ELEVATION_MAP[8],

    ),

) {

    SizedBox(width = 320f, height = 180f)

}

`
```

`FOREGROUND` 装饰会绘制在子节点上方，可用于蒙层或前景边框。DecoratedBox 本身不会按圆角裁剪子节点；需要裁剪时配合 ClipRRect，或使用 Container 的 `clipBehavior + decoration` 组合。
