# SizedOverflowBox

`SizedOverflowBox` 把自己的布局尺寸设为 `size`，但子节点仍根据父约束布局，因此子节点可以超出该尺寸。

## 函数签名

Section titled “函数签名”

```
`

fun ChildSlot.SizedOverflowBox(

    size: Size,

    alignment: BoxAlignment = BoxAlignment.CENTER,

    content: SizedOverflowBox.() -> Unit = {},

)

`
```

## 参数

Section titled “参数”

参数 | 默认值 | 说明
``size | 必填 | Widget 请求的自身尺寸
````alignment | CENTER | 子节点相对自身盒子的对齐
``content | 空 | 最多一个子 Widget

```
`

SizedOverflowBox(size = Size(120f, 80f), alignment = BoxAlignment.TOP_LEFT) {

    Container(width = 240f, height = 160f, color = 0x5538BDF8)

}

`
```

`size` 仍然会被父约束约束。它控制的是本节点尺寸，不代表创建独立裁剪区域。
