## 一、为什么选这个主题

云是少数「所有人都见过、几乎没人叫得出名字」的日常事物。WMO《国际云图集》
把云分成十属、约百种「种 × 变种」组合，是一套运行了两百年的公众可用的分类系统
（Luke Howard，1803）。对普通人来说，缺的不是资料，而是**一次可执行的阅读路径**：
看到一片云，从哪儿看起、看什么、什么时候能叫出它的名字。

这个主题同时满足本任务的三个约束：

1. **真实且可研究**：权威来源齐全（WMO ICA、CIMO Guide、NOAA JetStream、香港天文台
   电子书、NWS/Meteo.es 晕象页），全部实际访问并逐条摘录；
2. **不依赖实时信息**：分类系统与云底高度表是稳定知识，不存在「过期」风险；
3. **视觉表达空间大**：十属各有可绘制的形态特征（丝缕/颗粒/薄幕/云块/砧顶/对流塔），
   适合用 DSL 逐属绘制示意图，而不是贴十段文字摘要。

## 二、读者与核心问题

- **读者**：想「看懂天上那片云」的普通人——通勤者、郊游者、给孩子讲天的家长。
- **核心问题**（按出现频率排序）：
  1. 这片云叫什么？
  2. 它由冰还是水组成？（决定透光性、降水性格）
  3. 它在告诉我什么天气？（卷层云+晕 → 锋面接近；积雨云砧顶 → 雷雨）
- **不服务的问题**：数值预报、卫星云图判读、航空气象——超出公众图鉴范围，不涉。

## 三、叙述路线（11 件的阅读关系）

特辑被设计成一部**可对照天空使用的图鉴**，而不是十张独立海报：

```
case-01 总览（16:9 纵剖面）      从地面爬到对流层顶，建立三层十属的骨架
   │
case-02 方法图（3:4 判定流）     「一指量天」三步法——先会用，再认属
   │
   ├─ 高云族（6–12 km，冰晶）
   │    case-03 卷云 Ci      四质地：平直丝缕/逗号钩/厚片/缠结
   │    case-04 卷积云 Cc    颗粒波纹，视宽 ＜1° 的硬判据
   │    case-05 卷层云 Cs    22° 晕的几何图解（全特辑唯一光学专页）
   │
   ├─ 中云族（2–7 km，水滴+冰晶）
   │    case-06 高积云 Ac    成排云块，视宽 1–5°，corona 外红内蓝
   │    case-07 高层云 As    毛玻璃日面，无晕无影
   │    case-08 雨层云 Ns    连续降水幕，贯穿三层的例外
   │
   └─ 低云族（地表–2 km，水滴）
        case-09 层积云 Sc    蜂窝排列 + 30° 地平规则
        case-10 层云 St      均匀灰幕，与 Ns 以降水区分（配对页）
        case-11 积云→积雨云  四阶段对流塔（压轴，9:16 竖幅）
```

编排逻辑：**先骨架（01）→ 再方法（02）→ 后逐属（03–11）**；属内按
高→中→低排列，即「爬升」的阅读方向；case-10 与 case-08 是刻意的配对
（St/Ns 外形最像，规则都是「以降水区分」）；case-11 是唯一发展序列页，
把「云会长大」这条时间线补进以静态属名为主的图鉴。

## 四、每页固定栏目（图鉴体例）

九件图鉴页（03–11）统一体例，保证可对照使用：

1. 属名条：EN + 中文 + 缩写 + 所属层
2. 主图：特征示意（DSL 绘制，标注「示意图，非照片」）+ 高度轴 + 常用范围带
3. 云底高度：常用范围 / 更宽范围（CIMO 表两栏，km 与 ft 并列）
4. 构成：冰晶 / 水滴 / 混合
5. 拉丁词根拆解
6. 种（species）与变种（varieties）清单（引自 WMO ICA，经香港天文台电子书）
7. 天气意义与观测提示（只引来源结论）
8. 易混属判别（vs 相邻属的一条硬规则）
9. 页脚：来源编号 + 特辑名 + 页码

case-01/02 两件脱离单属体例：01 是骨架总览，02 是跨属方法图。

## 七、视觉系统的编辑意图

- **纸面暖白 + 天空蓝**：图鉴是「翻页读物」，纸面承托文字，天空蓝只属于主图区；
  数据条/清单用白卡，观测提示用米黄卡——四个层次对应四种信息类型。
- **赭朱（#C75B39）单一强调色**：只用于数据卡标题、判别条与词根，避免彩虹化。
- **每页主图构图不同**：03 四质地曲线、04 颗粒阵列、05 晕几何、06 成排圆块、
  07 毛玻璃日面、08 雨幕降水幡、09 蜂窝+仰角扇区、10 灰幕+破片+透日、
  11 四阶段序列——插画跟着云的形态走，不为统一而统一。
- **高度轴是每页的锚**：右侧 0–12 km 轴 + 该属常用范围半透明带，让读者在任何一页
  都能立刻知道「这属云在哪儿」。

## 八、已知限制

1. 中文译名非官方（见上）；种/变种译名部分为编译者试译，已在 sources.json 标注不确定项。
2. 插画为风格化示意图：云的立体感、云粒尺度都经过夸张，不能作为形态学图谱使用；
   每页已标注「非照片」。
3. 高度数值取温带；极地/热带读者需另查 ICA 表 6（notes 已录，未入图以免一图三套数）。
4. 22° 晕图解只标 22° 环；精确的最小偏向角区间（21.76°–22.37°）未入图
   （来源为条目摘录，作旁证处理）。
5. 「一指量天」是目视近似法，需要臂长处对照手指，图中已附 1 cm 指宽 ≈ 1° 的注记。
