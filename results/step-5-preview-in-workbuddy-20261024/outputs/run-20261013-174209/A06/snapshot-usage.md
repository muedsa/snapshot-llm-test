设计阶段规避的两个潜在问题（未实际触发，记录备查）：

1. 若用等距而非按层分列布局，第 2/3/4 层的并行节点会被压成一条直线，
   无法体现「同层并行」。因此采用 `col_w = (GX1−GX0)/层数` 的等分列布局。
2. 若反馈边与先决边共用层间通道，红色线会与深灰线重叠难以分辨。
   因此反馈边统一绕画布顶部专用通道（`FB_TOP_Y = GY0 − 44`），
   并从目标节点上缘进入，路径与先决边完全分离。

## 6. 设计选择、经验与未解决事项

关键设计选择：

- 分层用 Kahn 算法的批量实现：每轮取「所有前驱都已分层」的节点集合，
  同层即真实并行关系。反馈边不进入 `preds`/`succs`，因此不影响分层。
- 最长路径用 DP：`longest[n] = 1 + max(longest[p])`，再回溯一条具体路径；
  终点取 `longest` 最大的节点（本题为 N14），路径上的节点用蓝色边框高亮，
  让「最长先决路径」在图中可指认。
- 边路由分两类：
  - 先决边（同行或邻行）：从源节点右缘中点到目标左缘中点，跨行时走
    「水平—垂直—水平」折线，中点在两节点之间的空隙，避免压文字。
  - 反馈边：从源节点上缘向上到顶部专用通道，横向移动到目标 x，再向下
    进入目标上缘，与先决边通道完全分离。
- 箭头用两条 4px 粗、±160° 的翼线组成实心三角，方向由边末端的朝向决定。

可复用经验：

1. DAG 分层与「同层并行」用批量 Kahn 最直接；反馈/回退边必须排除在建图层之外。
2. 最长路径 DP + 回溯可以同时给出路径长度和一条具体路径，
   并把路径节点高亮，便于在图中指认。
3. 任意角度线段统一用「旋转矩形」实现（列主序 4×4 矩阵 + `transformAlignment="TOP_LEFT"`），
   箭头用两条翼线近似，比寻找其他绘图原语可靠。
4. 回退/反馈边走独立通道（如画布顶部专用带），并用专用颜色 + 图例区分，
   避免与主流向边混淆。
