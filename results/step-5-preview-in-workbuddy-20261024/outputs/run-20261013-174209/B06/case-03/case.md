# case · 03 · 体检报告：三十个箭头里只有三件事要紧

- 画布：9:16 竖版 1080×1920
- 媒介/观看环境：手机
- 受众：35–55 岁第一次认真看自己体检报告的上班族
- 使用场景：手机竖屏 9:16（1080×1920），报告短信链接里点开的同一张解读卡
- 使用目标：1 分钟内知道：本次有几个真异常、分别意味着什么、接下来 7 天/3 个月/1 年各做什么

- 主导手法：分级色带/参考区间条（标记越界可见）/三段行动轴
- 视觉主张：冷白底 + 琥珀/橙/红三级 + 蓝色辅助
- 内容依据：R7 常用参考区间（注明以报告单所印为准）+ R3 血压分级；患者数据为演示数据
- 虚构声明：演示数据与虚构品牌/角色已在画面或脚注标明；不声称做过用户调研或现场实验
