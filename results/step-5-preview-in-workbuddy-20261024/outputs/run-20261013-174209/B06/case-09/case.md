# case · 09 · 末班车：现在还回得了家吗

- 画布：9:16 竖版 1080×1920
- 媒介/观看环境：手机（夜间）
- 受众：加班晚归的上班族，尤其不愿天天打车的人
- 使用场景：手机竖屏 9:16（1080×1920），晚 10 点后办公室/地铁站单手看
- 使用目标：知道现在出发走哪条路能上车、哪一班是最后一班赶得上的、赶不上的备选与代价

- 重构方案：顶部大倒计时 + 可行链逐段最晚时间与缓冲 + 窄口提示 + 备选阶梯（带时间/费用）
- 主导手法：倒计时大字/时间轨/缓冲徽标/窄口告警/备选阶梯
- 视觉主张：深青底 + 薄荷强调 + 琥珀警示
- 内容依据：末班时刻表为演示数据（R8）；结构参照城市地铁常见首末班信息
- 虚构声明：演示数据与虚构品牌/角色已在画面或脚注标明；不声称做过用户调研或现场实验
