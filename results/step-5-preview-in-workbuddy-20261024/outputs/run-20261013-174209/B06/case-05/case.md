# case · 05 · 超市比价：把价签换算成每 100 克

- 画布：9:16 竖版 1080×1920
- 媒介/观看环境：手机
- 受众：每周采购的家庭成员；价格敏感的学生与合租青年
- 使用场景：手机竖屏 9:16（1080×1920），超市里边走边看
- 使用目标：三秒内看出哪种规格单位价格最低、促销是否真便宜、预算内买哪件
- 原本卡在哪：同一商品多种规格，价签数字不可直接比较，「加量装更划算」常常不成立
- 重构方案：每 100 g 单价横条（组内放大差异并注明）+ 规格卡 + 「加量陷阱」标记；底部预算组合与三条读价签规则
- 主导手法：单位换算横条（组内放大）/升序排列/徽标/预算卡
- 视觉主张：浅灰绿底 + 青/红对比
- 内容依据：自拟演示商品与价格（R8），不引用任何真实门店
- 虚构声明：演示数据与虚构品牌/角色已在画面或脚注标明；不声称做过用户调研或现场实验

- 最终版本：case-05-v02（request_id e423bfbf-e7b2-46da-8fb5-bc8b9f8832a1，耗时 3.953s，DSL 22730B）
