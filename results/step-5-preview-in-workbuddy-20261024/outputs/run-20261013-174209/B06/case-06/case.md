# case · 06 · 中转联程：这段换乘到底赶得上吗

- 画布：16:9 横版 1920×1080
- 媒介/观看环境：电脑/打印
- 受众：第一次独自中转的旅客（含带老人孩子出行的家庭）
- 使用场景：16:9 横版 1920×1080，出行前在电脑上看，也可打印折进行李袋
- 使用目标：判断中转时间是否安全、行李是否直挂、哪段最赶、误了之后的补救顺序
- 原本卡在哪：看不懂「中转 55 分钟」够不够：要算上下飞机、拿行李、重新托运、换航站楼
- 重构方案：一条水平时间轴：「需要 75 分钟」逐段 vs「可用 55 分钟」两条同尺度长条，缺口 20 分钟直接可见；MCT 警戒线；行李直挂判定；误机补救阶梯
- 主导手法：等比分段时间轴/缺口区/警戒线/判定卡/补救阶梯
- 视觉主张：纸米底 + 分段色阶 + 红缺口
- 内容依据：MCT 为航空业通用概念，数值为演示（R8）；航班与时刻为演示数据
- 虚构声明：演示数据与虚构品牌/角色已在画面或脚注标明；不声称做过用户调研或现场实验
