## 6. 设计选择、经验与未解决事项

关键设计选择：

- 网格直接逐格绘制：墙体深灰、通道白色，外加弱化网格线；阻挡格与门洞位置完全由输入决定。
- 路线绘制用「逻辑格心序列 + 垂直偏移」：偏移量取 4px（< 5.04px 上限），
  水平段偏移 y、垂直段偏移 x，保证两条线在共享段并列且都不出可走格。
- R1 用 9px 实线，R2 用 7px 虚线（每段 5 等分画 3 份），叠加方向明确的三角箭头，
  满足「颜色 + 线型 + 符号」三重区分。
- 共享通道按「格间边」判定（两路线 edge 集合取交），不用「格集合」取交，
  避免把仅相交一个点误判为共享段。
- 侧栏分三块：路线图例（含步数/米数）、展区入口点（A–D 及坐标）、两段共享通道说明。
- 地标方块固定在格心，A–D 名称用引导线向上引出，S/E 名称直接放在标记下方，
  避免文字压线。

可复用经验：

1. 字符网格的可走集极易多写一个符号。本题把 `#` 放进可走集后，
   最短路径数从 1 变成 736,281，且路线穿墙。用「打印某行全部可走格」的方式
   能立刻发现这类错误。
2. 「唯一最短解」可以用 DP 计数核验：`cnt[c] = Σ cnt[前驱]`，
   比指数级 DFS 枚举快得多，也能直接给出最短路径条数。
3. 共享段要用「边交集」而不是「格交集」，否则会把擦肩而过的两段算成共享。
4. 两条线并列时，横向偏移按「垂直于该段方向」计算（水平段偏 y、垂直段偏 x），
   比统一偏 x 更自然，也更容易控制在单格 12% 以内。
5. 文字标签要按线段走向选择方位（水平段上方、垂直段侧向），
   固定方位必然在某些段压线。
