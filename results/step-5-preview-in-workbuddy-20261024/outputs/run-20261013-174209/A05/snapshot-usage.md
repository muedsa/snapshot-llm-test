## 6. 设计选择、经验与未解决事项

关键设计选择：

- 横轴严格按真实时间比例：`x = px_start + minute_offset/270 × pw`。
  因此 08:00–08:10（10 分钟）与 09:00–09:15（15 分钟）的像素距离比为 2:3，
  不规则采样在视觉上直接可辨，不会被等距网格掩盖。
- 缺测用「空心灰环 + 缺测文字」画在绘图区底部同一 y，避免与真实数据点混淆；
  同时连线逻辑在缺测处断开，双重保证不补值。
- 压差图范围取 `±max(|min|,|max|)×1.35`，保证 0 位于画布中部、零线清晰，
  负值区用粉色底纹 + 红字标注，并明确写出「仅这 3 个采样点为负」。
- 三张图的 `px_start`/`px_end` 完全一致，纵向参考线（整点灰线 + 09:40/10:50 黄线）
  在三图中位于同一 x，可直接横向比对。
- 纵轴刻度用 nice_ticks 取整，并把范围扩展到覆盖刻度，避免出现 22.476 这类标签。

可复用经验：

1. 多图 + 图例 + 表格的竖向版面必须先做预算再定各图高度，否则表格会被
   `clipBehavior` 静默裁掉（本题基线即如此，且不报错）。
2. 纵轴刻度不要用等分，用「步长取 1/2/2.5/5×10^k」的 nice_ticks，可读性明显更好。
3. 缺测（null）与 0 必须分开处理：连线循环里遇到 null 就重置 prev，
   这样自然形成断线，不需要额外的虚线逻辑。
4. 时间轴类图表把「分钟偏移 → 像素」的映射与 `px_per_minute` 写进审计 JSON，
   便于用数值方式复核比例。
