# case-02 · 山焙 · 季节咖啡菜单板

- 画布：1080×1920（竖屏店内常显）
- 受众：咖啡馆内顾客与咖啡师
- 使用场景：竖屏菜单板 07:00–21:00 常显，观看距离 1–2 米，暖光店内
- 使用目标：30 秒内看清当季特调、风味、价格并完成点单决策
- 内容依据：虚构品牌「山焙 SHANBEI」秋日单；9 个条目（4 季节特调 + 3 经典 + 2 非咖啡）名称/风味/价格均为自拟
- 视觉主张：白底暖褐单色系；编号 01–04 建立季节组视觉序列；温度标记用形状双编码（实心圆=热、菱形=冰、圆环=皆可）

### C02-3 季节特调与经典款有明确视觉分组
- 实际结果：已达成
- 检查方法与证据：view-zoom：分区标题带 + 编号色带 + 分组间距三重编码

### C02-4 温度标记用形状 + 文字双编码
- 实际结果：已达成
