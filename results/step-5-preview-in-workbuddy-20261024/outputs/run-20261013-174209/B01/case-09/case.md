# case-09 · 滨江市区 · 空气质量看板

- 画布：1080×1920（公交站亭竖屏）
- 受众：市民与户外工作者
- 使用场景：公交站亭竖屏，白天自然光，观看距离 1–3 米
- 使用目标：看当前 AQI、主要污染物、24h 趋势与健康建议
- 内容依据：演示数据按国标 HJ 633-2012 断点自洽：AQI 124 → 轻度污染；首要污染物臭氧 O₃ 179 μg/m³（断点 160→100/200→150 线性内插 = 123.8 ≈ 124）；PM2.5 61 → IAQI 82.5；24h 曲线过控制点插值，15 时值 = 124 与显示一致，峰值 124@15、谷值 55@04 由采样值推导
- 视觉主张：浅色 civic 看板；AQI 168px 大数字 + 六级国标色条 + 当前刻度；分层填充 24h 曲线
