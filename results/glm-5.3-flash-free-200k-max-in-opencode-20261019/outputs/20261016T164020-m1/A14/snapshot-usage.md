## 体系设计（沿用 A12 品牌系统——同一活动「Structure / Vision · 2026.11.07」）

- 底 #0E1526 / 主字 #F2F6FF / 强调 #7AA2F7（品牌字）/#F2C94C（时间）；几何沿用圆角 pill + 双色短轨。
- 固定结构：品牌字标（56,48）→ 状态徽标（右上，right=1160，h=48）→ 标题区 y148 起（44px bold，≤3 行，固定区域）→ 讲者（24px，允许两行）→ 分隔线 y512 → 时间（26px 琥珀）+ 日期（20px）。全部元素在 [40..1160]×[40..588]。
- **状态四重编码**（颜色 + DSL 符号 + 原文）：开放 ● 实心圆 #35D07F / 满额 ■ 实心圆角方 #F2C94C / 候补 ○ ClipPath EVEN_ODD 圆环 #7AA2F7 / 取消 ⊘ 环+杠 #FF6B6B。
- 标题折行：greedy 估宽 + 标点优先（，。——、：；）回退；K07 两行（“…——服务、字体、/数据与视觉检查”）、K08 两行（“：”后断行），其余单行；不做全局缩放。
- 含 `< > &` 的 K04 标题走 `<Raw><![CDATA[…]]></Raw>` 原样排版；逐字核对 "A < B & C > D" 保真。

## 迭代链（5 轮 / 34 请求全 200）

- v01 基线：8 张渲染 + 逐张整图查看 + 接触表。发现：候补/取消徽标的环符号完全不可见；徽标文字疑似截底。
- 探针 ×2：① border 绘制行为——空色/全透明 Container 的 border **不绘制**；② 单行 CJK 剪裁——maxLines=1+overflow=CLIP 下字形完整（行盒按字体度量），并逐像素测量证实徽标墨迹 55..81 完整、标题墨迹 161..203 完整。
- v02：引入 ClipPath EVEN_ODD 圆环，但 path 误用全局坐标 → 环仍缺失（放大件核验，只到缺陷即停）。
- v03：path 改 SizedBox 局部 0 基坐标 → 四型符号全部出现（与 A13 孔洞同源教训）。
- v04：徽标药丸 44→48、文字按墨迹高 1.18em 垂直居中（y=top+9）、取消注明 pill 同步 → **八张整图 + 四型徽标/K06 底行/K05 拉丁混排/K07 折行/K08 弯引号放大件全部通过**。
