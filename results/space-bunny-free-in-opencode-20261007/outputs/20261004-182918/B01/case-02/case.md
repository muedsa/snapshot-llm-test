# case-02 · PRESSDRY · 独立书店「夏日选单」读者海报

- **尺寸**：1200 × 1600 竖版纸面海报
- **交付**：`final.png`（服务原始响应字节，未后处理）+ `final.snapshot`（产生该 PNG 的完整 DSL）
- **场景**：自拟品牌「独立标点·社区书店」门店里贴着 A2 纸的第七期选单海报，读者在书架前站着读，店员每三周换一次。
- **受众**：走进店里、还没决定买什么的普通读者。
- **希望用户完成的事**：三十秒内决定「这期我要买哪一本」，并且记住这家店——所以每本书必须有一句真能说服人的理由，而不是一句简介。
- **媒介选择**：印刷海报。观看距离 1 m、手里可能拿着一杯咖啡、完全不放大看，因此**唯一能用的手法是字号层级**：巨号序号 + 衬线书名 + 极小字元数据，中间什么都不加。
- **最有辨识度的视觉选择**：右侧那列巨大竖排「夏日选单」四个字，加一枚朱红方印「独立标点」。整张海报 90% 是米色纸和深墨，唯一的彩色是这枚印——**留白和克制本身就是这版的视觉主张**，它和另外九张的高信息密度正好构成对照。
- **主要手法**：纯排版海报，**没有任何图表**。书脊色条、双层巨号序号、编者的话、到店信息、二维码（用矩形按位逐块画出真实可扫的模块图形，不引用任何图片）。

- **素材情况**：全部主体、排版、图形与图表均由完整 DSL 构造，服务真实渲染；未使用任何 `<Image>`、未引入外部图片素材，未做任何后处理补字或修图。品牌与示例数据均为本次设计演示自拟，不宣称是实际部署的客户作品。
- **数据说明**：本件内所有数值（时间、负荷、分数、计数、坐标、容量）均为本次设计演示自拟的示例数据，用于说明这套视觉语言能承载什么，不代表任何真实电网、书店、港口、烘焙场、观鸟记录、医院排班、车次编组、民宿经营、考古发现或场馆线路的真实记录，也不指向任何真实机构。

## 实际自检
- 画布 1200 × 1600 竖版纸面海报，服务返回 HTTP 200，PNG 即响应体原始字节。
- `dsllib.warnings()` 输出 0 条（无文字溢出 / 框过小告警）。
- 元素数与全部渲染请求见根目录 `task-metrics.json`；DSL 与 PNG 一一配对。
- 已用图像查看工具打开最终图逐处核对：文字全部完整渲染、无重叠、无裁切、无溢出画布；曲线/色带/柱形的几何比例与脚本中的数值一致。
