## 4. 沉淀的经验

1. **服务有 4096 元素上限**（`RENDER_ERROR: Document contains more than 4096 elements`）。
   用矩形拼折线/面积填充时很容易撞到，务必估算元素数：`每个 box = Positioned + Container = 2 个元素`。
2. 引导线的"不穿过标签文本"只要**从标签盒外缘起画**就天然成立。
3. 标签避让的最优解通常不是"按 y 排序"，而是让程序在"换列 + 列内顺序"上搜索目标函数（这里是交叉数）。
