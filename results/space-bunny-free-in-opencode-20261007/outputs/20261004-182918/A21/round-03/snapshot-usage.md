## 主题不是"改两个颜色"（本轮重点回应）

round-03 明确要求"不能只改两种颜色忽略实际叠层"。本轮把**整条叠层链**重新合成，浅色主题下
每一层的取值都换了（完整清单在 `design-tokens.json → changed_vs_round_02`）：

| 层 | 暗色（round-01/02） | 浅色（round-03） | 为什么必须换 |
|---|---|---|---|
| 页面底 | `#0A0F24→#141034` 竖向渐变 | `#FBFAFF→#EDE9FB` 竖向渐变 | 主题基底 |
| 光晕 aura | `#6D4AFF59`（暗底上像加光） | `#6D4AFF33` 径向 | 暗底的 35% 紫在白底上会变脏 |
| 品牌板 1（底） | `#3A1FB0B3`（70% alpha）+ `#6D4AFF5C` 边 | `#C9B6FF` 不透明 + `#6D4AFF80` 边 | 70% alpha 的紫板叠在白底上会几乎消失 |
| 品牌板 2（中） | `#6D4AFF8C`（55% alpha）+ `#9C86FF8A` 边 | `#A78BFA` 不透明 + `#5B2BE099` 边 | 同上 |
| 品牌板 3（顶） | `#8E74FF→#5B2BE0` 线性渐变 + 阴影 | 同渐变（保留，浅底上仍成立） | 唯一不需要改的构件 |
| 光带 beam | `#4BE3C8F2` 薄荷（为暗底设计） | `#0E9E86E6` 深青 | 薄荷色在白底上几乎消失 |
| 光点 / 光环 | `#EAFFF9` / `#4BE3C8CC` | `#FFFFFF` / `#0E9E86` | 光点留在紫板上仍是白，光环改深青 |
| 信息卡 panel | `#FFFFFF0F` 半透明（靠暗底透出层次） | `#FFFFFF` 实心 + `#6D4AFF33` 边 | 浅底上半透明白卡不可见，必须给实底与边 |
| ONLINE LAUNCH pill | `#6D4AFF` 底 + 白字 | `#5B2BE0` 底 + 白字 | 白字在浅紫上对比度不足，需加深底色 |
| 正文 / 次级 / 强调墨色 | `#F5F4FF` / `#B7BEE0` / `#7FE9D6` | `#1B1440` / `#4B4478` / `#5326E8` | 全部重算 |
| tick 竖条、分隔线 | `#4BE3C8` / `#FFFFFF26` | `#5326E8` / `#6D4AFF3D` | 白线在白底不可见 |

所有对比度数值都是**从最终位图里读出来的**：对每张图额外渲染一张"同构图、去掉整个 `Text` 层"
的对照图，字形下方那片像素就是服务真正合成好的背景（页面渐变、光晕、半透明板、卡片、pill 底
全都已叠好），再按 WCAG 2.1 相对亮度公式算比值。**没有**手挑颜色，也没有用色值做算术猜测。
