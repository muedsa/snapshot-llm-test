# case-10 · 核查卡 · 这条说法能不能当证据用

## 场景与受众

- **定位**：整页核查清单 / 展板 / 长图
- **受众**：编辑、事实核查员、需要在转发前判断可信度的普通读者。
- **观看环境**：1300×1820 竖版。
- **使用者要完成的事**：拿到一份带判定标签的说法清单，并知道每条判定的依据、反例或限定。

## 内容依据

十条判定均对应本特辑已引用的来源：IPCC SROCC 与 AR6 WG1 SPM、NOAA 三个页面、Gruber 2023、Kroeker 2013、Jiang 2023、Bednaršek 2019/2014、NOAA Ocean Today 受访表述。十条判定本身是本特辑的编辑判断，不是任何来源自身的分级——这一句写在页面上。

## 视觉意图与手法

- **主要视觉主张**：把特辑的编辑纪律公开化：读者可以看到我在哪里下了判断、依据是什么。
- **画面构成**：顶部五级判定色标（已证实 / 来源结论 / 需限定 / 目前不足 / 本特辑解读，各带定义）；十条编号卡片，每条一句说法 + 判定 pill + 依据段落；底部一句关于这张卡自身前提的说明。
- **实际用到的 DSL 能力**：卡片列表 + pill 标签；判定色与特辑其他九件严格区分，避免「绿色=好」的误读。
- **素材**：无外部素材、无 `<Image>`，主体全部由 DSL 构造（`run-config.json` 的 asset_policy 为 `dsl_primary_with_supporting_assets`，本件未使用任何辅助素材）。
