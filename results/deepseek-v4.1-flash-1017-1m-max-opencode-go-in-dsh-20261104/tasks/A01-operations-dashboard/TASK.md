# A01 · 六个月经营诊断驾驶舱

先完整阅读 [AGENTS.md](AGENTS.md) 的执行、目录、留痕和指标约定；该文件是本任务要求的一部分。

## 任务

为虚构产品 Northstar 制作 1600×1000 经营诊断驾驶舱，给管理者展示 2026-04 至
2026-09 的经营状况。inputs/monthly.csv 是唯一业务数据；金额单位为元，订单为笔，
sessions 为访问次数。gross_revenue 是退款前收入，refund_amount 是当月退款；
operating_cost 不含退款。净收入=收入−退款，经营利润=净收入−成本。

同一屏必须包含：四张 KPI（总净收入、总经营利润、总订单、期间总体转化率），
六个月净收入与经营利润分组柱图、访问量与转化率两个共享月份对齐的小图、
六行明细表（月份/净收入/退款率/利润/转化率）及一条有证据的管理结论。
总体转化率使用总订单/总访问次数，不平均月比例；退款率=退款/退款前收入。
柱图共用零起点和比例，负值若有须正确处理，百分比与金额不能共用混淆的数轴。
KPI 保留金额原值或正确转换成万元；明细金额整数、比例两位小数。
图表刻度、单位、图例、所有月份与表格内容完整可读，正文≥20、脚注≥16。

附 computed-data.json，包含每月计算值、汇总、图轴定义与结论所引用的数值。
做到视觉重点明确而非把数字平均堆满；检查表格对齐、最后一个月标签和图表比例。
