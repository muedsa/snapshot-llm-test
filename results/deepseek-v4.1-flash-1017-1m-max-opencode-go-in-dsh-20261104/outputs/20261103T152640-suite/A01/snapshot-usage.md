## 4. 设计与排版决策

- 版式：36px 外边距 + 三段式栅格（页眉 80 / KPI 142 / 图 360 / 表 224 / 结论 66），所有元素用 Positioned 显式定位，保证多图共享同一基线。
- 色彩：以 #070C16 深底 + #0D1524 卡片承托数据；净收入用青色渐变、经营利润用琥珀色，KPI 强调条与柱色一一对应，使读者不必回看图例。
- 强调：6、8 月退款率 8.00% 用红色，其余 4–5% 用琥珀色；利润率列加低透明度量条，使 21.99%/23.72% 的凹陷与结论呼应。
- 留白：KPI 卡片之间 20px、卡片内 24px；图表卡与表格卡之间 14px，避免数字堆满。

## 5. DSL 能力与文档应用

- 布局：`Stack`+`Positioned` 绝对定位（`Stack` 不提供 width/height，尺寸由外层固定 `Container` 传入的紧约束决定）；文本框统一给 `width` 以启用固定换行宽度。
- 图表：柱体用 `Container` 的 `gradientType="LINEAR"` 上下渐变；圆角只加顶部 `borderRadiusTopLeft/TopRight`；网格线用 1px `Container` 绘制。
- 数字对齐：表格数值启用 `fontFeatures="tnum"`，并统一右对齐到列右边界。
- 文本度量：先按服务真实字体标定（见 tmp/<run_id>/_suite/shared/text-metrics.json：20px 下 CJK 20.00px/字、数字 11.70px/字），脚本内以 `est_width` 预检，超框时在渲染前打印 OVERFLOW 警告。
- 颜色使用 CSS 8 位十六进制 `#RRGGBBAA`（如 `#22D3EE47`），未使用已废弃的 `#AARRGGBB`。

## 6. 实际问题与修复

| 问题 | 原因/判断 | 修复与验证 |
|---|---|---|
| 表头被首行底色覆盖 | 表格行底色在循环内绘制，晚于表头文字 | 改为『先画全部行底色 → 再画表头 → 最后画数值』，重渲染确认表头可见 |
| 柱顶数值被裁成 4 位（11.9 / 13.5） | 标签框宽 34px，小于 5 位数字在 16px 下的宽度 | 标签框加宽到 60px 并居中于柱中心，同时给两序列都加数值标签 |
| 『万元』与副标题重叠 | 两者都在 y≈330–350 的同一列 | 把『万元』下移到轴刻度列顶部 (y=347, 右对齐)，副标题保持 326 |
| 右栏 6,000 刻度压住子图标题 | STOP 与标题行距不足 | 子图标题上移，SESS_TOP 从 362 下调到 390，标题与刻度留 8px 间隙 |
| 结论两行溢出卡片并压住脚注 | 20px 下结论文本估算约 1,440px > 1,345px 可用宽度 | 拆分主句（20px）+ 反事实测算（17px）两行，卡片高度 66px 可容纳 |
| 侧栏峰值注释换行 | 『峰值 12.00%（4 月）· 谷值 10.60%（6 月）』估算 326px > 310px | 缩短为『峰值 12.00% · 谷值 10.60%』并右对齐到 1520，实测单行 |
