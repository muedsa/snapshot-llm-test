# 叠光 / Layerlight — 标志方向与取舍

**两个方向的差异**：方向 A 用三个圆角方块沿对角线逐层叠压（墨黑 → 蓝 → 琥珀），每层只露出两角，中心留一枚白色核点；方向 B 用三条长短不一的横杠加一道竖向光柱，靠"穿透"表达层次。A 的轮廓在任何尺寸下都是"叠"，B 的横杠加光柱在小尺寸会读成字母 l，主体与光柱的主次也不清楚。

**预览与选择依据**：两张 512×512 透明预览都实际渲染查看过。A 在 32 像素缩略中仍能数出三层错位的圆角与中心亮点；B 缩到 32 像素后横杠只剩三条色带，光柱变成一条白线，层次关系丢失。因此选 A，并在同一几何上继续完善。

**小尺寸改进**：把层间错位固定为图幅的 1/6，核点直径放大到 60（32 像素下约 3.2 像素），保证缩略仍能分出面与点；纯黑版改用 0.60 / 0.76 / 0.90 三档 alpha 表达层次，实测全部 alpha>0 像素的 RGB 均为 0。
