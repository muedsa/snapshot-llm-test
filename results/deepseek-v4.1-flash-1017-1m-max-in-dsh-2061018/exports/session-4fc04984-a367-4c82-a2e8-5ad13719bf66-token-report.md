## 5. 方法与口径

- **来源**：本机 DSH session v4 日志  
  `~/.dsh/sessions/--D-mine-test-ds--/<session-id>/session.v4.jsonl.zstd`
- **字段**：`assistant/message.data.usage` 中的 `inputTokens`、`outputTokens`、`cacheReadTokens`、`cacheWriteTokens`、`totalTokens`。
- **去重**：以 `data.message.id` 为唯一键跨会话去重；fork 回放行不重复计入。
- **调用数**：每条带 usage 的 assistant message 视为一次模型响应。
- **模型**：全部为 `deepseek-account / deepseek-flash`。
- **时间**：日志中的 epoch 毫秒转换为 Asia/Shanghai（+08:00）。
- **未换算金额**：报告只统计 provider 返回的 token 用量，未套用价格表，因此不代表账单金额；缓存读取通常有单独折扣，需以实际账单为准。
- **快照边界**：数据截至 **2026-10-18 15:58:56.742**（最后一条已记录 usage），报告生成于 15:58:59。生成这份报告之后产生的最终回复调用不在本快照内，实际总量会略有增加。
