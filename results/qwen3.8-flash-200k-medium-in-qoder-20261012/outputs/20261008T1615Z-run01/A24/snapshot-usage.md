## 3. 真实文档与接口应用（本轮新增可迁移事实）

全部来自真实 HTTP 响应，请求体/响应头/错误 JSON 保留在
`tmp/20261008T1615Z-run01/A24/preview/requests/` 与 `.../requests/`：

1. `background="None"` → **400 PARSE_ERROR** `Attr [background] unsupported CSS color [None]`
   （service requestId `5a18ffb5-b573-44a2-bb42-4787bd5b0a86`）。深色画布须给真实颜色。
2. `Doc.label(x,y,w,h,s,color,size,style,align,…)` 第 8 个**位置**参数是 `style`；
   把 `CENTER/END` 按位置传进去 → **400** `Attr [fontStyle] value is invalid:
   Unexpected font style END/CENTER`（`00b16e25-8264-4595-ac71-0ce8324eb9a`、
   `5e5a56b5-7431-4246-8e72-262601b4d82b`）。对齐一律用 `align=` 关键字。
3. **多行正文**：`Text` 带 `height=` 时整段不渲染（探针 `probe/multiline.png` 变体 A 空白）；
   改用 `maxLines` 后按容器宽自动换行（变体 B 正常）；显式换行符同样生效；
   `Container` 会按自身高度竖向裁切；手工预切行 + `Column` 会二次换行丢字（变体 D）。
4. **标签盒高**：24px 文本放进 `height="26"` 的盒会被切上下沿，24/28、24/30 正常，
   22/26 正常 → 经验规则 **盒高 ≥1.15×字号**，已在 `gen_boards.py` 末尾按 `Positioned`
   逐条自检（三图 0 项不足）。
5. 正文里的 ASCII `->` 由服务渲染成 `→` 字形（DSL 内是 `R01->R04`，图上是 `R01→R04`），
   做字符串一致性校验时两种写法都要接受。
6. 同一 DSL 内容重复请求时 `X-Snapshot-Cache` 头在 `hit`/`miss` 之间不一致，
   但响应字节与 md5 完全相同 → 渲染确定性以 md5 为证，不依赖该头。
7. `curl (28) SSL/TLS connection timeout` 在 `render.py` 里表现为 `http_status 0`，
   原先不在重试集合内，已补（`429/503/504/0/None`）。

## 5. 跨题经验（供 B 类与总报告引用）

- **单一数据源生成多尺寸图**：三图共用 `schedule.json` + `gen_boards.py` 里的同一批常量，
  从根上排除“三图互相矛盾”；再用机检兜底（94 条断言）。
- **文字类缺陷要靠裁片而非整图**：整图看“有没有字”，2× 裁片才看得出“字被切了一线”，
  v04→v05 的唯一动因就是裁片。
- **把经验写成闸门**：盒高 ≥1.15×字号、TextFit 宽度预估（CJK 1.02×、latin 0.58×）
  都做成脚本内的断言，避免下一题重犯。
- **失败请求是资产**：4 个 400 与 1 个 curl 超时直接产出了 3 条可迁移 DSL 事实。
