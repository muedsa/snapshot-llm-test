## 受众与情境

客户设计师带着三个问题来交付：这套品牌字**能用到哪几个字重**、**字距/词距/行高改到多少才真的有效果**、
**文档里写的高级特性在这台渲染器上到底生不生效**。所以这一页不是一张好看的字母海报，而是一份能照着复现的
测量记录：每个样本独占一条测量带，页面上的「实测」列由 PIL 扫描上一版成品 PNG 得到，「预期」列按字宽模型算出，
两列之差就是排版可控的范围。设计师看完可以直接得出「哪些属性可信、哪些要手工兜底」的结论。

## 独到手法

1. **成品即量具**：`case10_measure.py` 读 `data.json.bands` 的坐标带，在 PNG 上按「与背景众数色欧氏色距 > 40」
   判定墨迹，量出首末墨迹列之差（宽度）、墨迹面积占比（字重浓淡）、相邻两行墨迹中心间距（行距）。
   本版把上一版的实测值印回页面，形成「渲染 → 扫描 → 再渲染」的闭环，页面结论不靠肉眼断言。
2. **只用真实安装的字族**：生成前 `assert` 27 族、`Inter Semi Bold` 在列、`IBM Plex Mono`/`Courier New`/`Helvetica`
   不在列——把「回退」做成可证伪的实验而不是猜测。
3. **字重看墨迹不看名字**：7 行同字号同文本，右列印墨迹占比，把 `fontStyle="BOLD"` 与 `Inter Semi Bold` 排成相邻两行。
4. **三组阶梯各证一条律**：letterSpacing 四档验线性、wordSpacing 三档验「只对空格生效」、height 五栏并列验「行距＝字号×倍数」。
5. **不可见差异如实标注**：`fontFeatures` 四组与基准并排，实测全等，页面明写「只被解析、不被应用」，不冒充生效。
6. **TextFit 闸门全程在线**：161 处文本发射前逐条估算宽高，`problems 0` 才提交渲染。

## 实测结论（全部来自成品 PNG 的像素扫描）

| 参数 | 实测 | 结论 |
| --- | --- | --- |
| 字重墨迹 | Thin 5.03% / 400 6.80 / 500 7.26 / 600 7.81 / 800 8.87 / 900 9.42 / **样式 BOLD 9.92%** | 7 个字重是 7 个独立族；样式加粗比 Black 还黑，不是 Semi Bold 的等价写法 |
| letterSpacing | 10 字 @34px：0→198、2→216、4→234、8→270px | 每 1px 字距 ×(n−1) 间隙，严格线性；Δ 恒 +11px 暴露 0.55em 拉丁模型低估 Inter 大写（实测 0.582em/字） |
| wordSpacing | 「type specimen page」（2 空格）@28px：0→266、8→282、18→302px | 差值恰为 2×ws，只对空格生效 |
| height | 17px 三行：默认 20.8、1.0→16.8、1.25→20.8、1.5→25.8、1.9→31.8px | 行距＝字号×倍数（偏差 ≤0.5px）；**默认档实测 1.22em，推翻套件里 1.45em 的估算常数**，不写 height 时行距取自字族自身 metrics |
| 回退 | DejaVu 176、Noto Mono 148、IBM Plex 186、Courier 186、Inter 178px | 两个未安装族实测**同为 186px** 且与任何已安装族都不等 → 回退到同一个平台默认字体 |
| fontFeatures | tnum / lnum smcp / +liga 与基准全为 176px | 差值 0：语法被接受、未量出效果，等宽数字需版式手工兜底 |
| STROKE | 1.0 / 2.4 / 4.0px 三档外框均 129px | 描边只加粗笔画，不改排版宽度；4px 已填满中宫，仅用于展示字 |

## 已知失真与演示值（如实标注）

- 页头「品牌字系统」为示例抬头，非真实客户；本页不含任何虚构数据，所有数字均为实测或按公式计算。
- 「预期」列是字宽模型（CJK 1.0em / 拉丁 0.55em / 等宽 0.60em）的估算，§02 的 Δ 恒 +11px、§04 默认档的
  Δ −3.8px 正是模型与真实字族 metrics 的差距，页面上明写，不做修正掩盖。
- 墨迹判定阈值（色距 > 40）会把抗锯齿边缘计入墨迹，宽度测量因此可能偏 1–2px；这对线性关系的判断无影响，
  但不应把 Δ 列当作亚像素精度使用。
- §04 的 `height=1.0` 档在 v01 的四栏版本里三行墨迹相连量不出间距，v02 起该栏位置变化后测得 16.8px；
  两版差异说明小行距下扫描窗口的位置会影响测量，最终版采用五栏同宽的固定坐标带。
- 服务渲染耗时 931–4650ms 波动，与本用例质量无关。
