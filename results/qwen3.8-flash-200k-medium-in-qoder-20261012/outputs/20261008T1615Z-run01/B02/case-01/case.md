# case-01 门头与橱窗主画面 · 2400x900

## 这一件要解决的问题
店外 3 米、骑车经过的 2 秒内，让人明白「这是一家能借工具的店」，并带走三条硬规则。
因此画面只保留四类信息：标志、店名与一句话定义、三条规则、馆藏构成。

- 受众：路过的居民（第一次看见这个品牌）
- 使用情境：白鹤岭馆临街门头喷绘布 + 橱窗上沿
- 用户目标：判断「我能不能进去借一把电钻」，并知道大概多少钱
- 完成标准：不读小字也能懂；小字（开放时间/页脚）是给已经停下的人看的

## 视觉与品牌
牛皮纸底 + 墨黑 + 朱橙；标志为六角螺母（外沿 + 计量环 + 内孔）与斜穿的扳手柄，
手柄端部的环头压在螺母边上，让「工具」与「馆」两件事咬在一起。
版式按 90/2220 边距切三栏（标志 / 文字 / 规则），底部 26px 高刻度带收口。
