# case-07 · 工具使用安全须知（1080×3000，折叠说明书首页）

## 触点定位

- 媒介：折叠说明书首页，A4 长卷；读者**站在柜台前手持**，距离 30–40 cm
- 受众：要借电动/气动工具（S2 类）的会员，借出前必须读完并签字
- 设计任务：这是一份**受控文件**而不是海报——四段编号条款、可核对的表格、签字确认区，
  读者要能在 60 秒内定位「我借的这一类要注意什么」，最后落到签字栏
- 必须包含（题目要求）：PPE 清单、6 条禁令、类目相关注意事项、签字栏
- 与 case-03（会员端提示）的分工：case-03 在 App 里做「借出前的一句话提醒」，
  本题是完整条文；同一品牌色板与构件，但排版语言换成条款/表格

## 分层

| 层 | 内容 | 数据来源 |
| --- | --- | --- |
| 文件头 | 深色带：品牌标记 + 「借走之前，先把这页读完」+ 文号 `WH-SAFETY-2026-01` + 生效 2026-10-10 + 第 1 页/共 1 页 | `brand.name`；文号与生效日为馆方自编（虚构品牌） |
| 01 两类工具 | S1 基础防护（馆藏 209 件）/ S2 强制防护（馆藏 203 件）双卡，绿/红顶边 | `tools[].safety_level` 计数，`D["safety"]["levels"]` |
| 02 防护装备清单 | 6 行 × 4 列表格（装备 / S1 类 / S2 类 / 说明），六边形「目尘耳手衣发」图标 | `D["safety"]["ppe"]` |
| 03 六条禁令 | 88px 等高等宽红条 + 32px 红色编号，六条同级 | `D["safety"]["prohibitions"]` |
| 04 类目注意 | 9 类逐行：类目色条 + 名称 + 库区 + 「N 件 · S1/S2」+ 该类专属提醒 | `cats[]` 的 `zone`/`count`/`safety_level`，`D["safety"]["cat_notes"]` |
| 签字确认 | 深色卡：声明 + 会员签名/会员编号/日期/馆方见证（志愿者）签名四字段 + 绿色「馆方见证」章 | `D["safety"]["signoff"]`，`b02kit.stamp` |
| 页脚 | footer short + 虚构声明行 | `b02kit.footer` |

**数据口径（重要）**：`data.json` 只提供 `tools[].safety_level`（S1/S2）与 `tools[].power`
两个原始字段，安全条文本身没有现成数据。因此在 `b02data.py` 增写了 `D["safety"]` 块，
并在其中显式标注 `"source": "馆方自定条文（虚构演示品牌），分级依据为工具表 safety_level 字段"`
——条文内容是品牌方（虚构）自定的规则，不是服务返回的数据；而 **209/203 件、9 类件数、
库区字母全部由 TOOLS 现算**，不写死。图内 01 段右上角写明「按工具表分级」。

TextFit 自检：88 条文本，0 条溢出；内容止于 2884 / 3000，底部 116px 为页脚留白（断言 `y < H`）。
