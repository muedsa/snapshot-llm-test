# case-02 · 潮汐声场音乐节三日海报（1080×1800）

## 使用场景
- **谁在用**：音乐节主办方的新媒体编辑；受众是刷到这张图的 20～35 岁乐迷。
- **何时何地怎样使用**：公众号头图 / 朋友圈竖图 / 现场易拉宝缩印，多数在手机 6 寸屏上
  竖向滑动 2～3 秒决定是否购票，因此标题要远看抓眼、阵容要近看能读。
- **希望用户完成的事**：记住品牌名 → 知道三日期与风格 → 查到自己想看的一天 →
  看到票价与购票入口。
- **内容来源**：品牌“潮汐声场 / TIDAL FIELD”、场地“星海湾露天公园”、40 组中的 39 组
  艺人名、票价、日期均为**虚构编造**，海报底部已用中文声明；购票地址是示例地址。

## 视觉与技术选择
- 主标题用 `foregroundColor + foregroundMode="STROKE"` 做 196px 空心字，压在
  `gradientType="SWEEP"` 生成的彩色轮盘上——色轮即“声场”隐喻，也解释了三舞台命名。
- 英文副标题用多层 `textShadow`（粉色实心偏移 + 青色反向偏移 + 白色外发光）做霓虹错位。
- 斜切色带与细线用 `Container transform` 16 值矩阵旋转整棵子树；字距行下方垫
  `#07070FF2` 深色底板，避免琥珀字压在琥珀色带上不可读。
- 场地示意（1080×1800 加长画布后新增）：`gradientType="LINEAR"` 海面 +
  径向落日倒影 + 4 条旋转浪线 + 三个描边圆环舞台 + 入口/露营 `WidgetSpan` 式 chip。
- 艺人总数由 `DAYS` 数据计算（39），不是手写数字。

## 实际自检与修改
- v01：字距行被青线横穿、被黄带同色吞掉；D 徽章偏高；阵容与票务间约 180px 空档。
- v02：垫深色底板后字距行可读；补场地示意面板。
- v03：场地面板压住阵容最后 5 行 → 画布 1620 改 1800，下段整体下移（v04）。
- v04→v05：海面加落日倒影与浪线；v05→v06：删除穿越文字的连线与和 DAY 栏重复的艺人名。
- final = v06（`B01-case-02-v06-20261009T111031Z`）。逐段 1.5x 放大确认无遮挡、
  无截断；`TextFit` 36 项 0 problem。
