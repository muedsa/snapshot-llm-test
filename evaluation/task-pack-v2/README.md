# v2 评测端材料（不要交给被测模型）

被测模型只接收 task-suite/ 完整任务根目录。官方在线文档访问是任务的一部分，
不向模型提供这里的检查点、作者参考DSL或计算参照。评测环境需要
真正限制可读目录；提示“不读父目录”不能代替文件隔离。

## 多轮投递

A21/A22的全部轮次要求已放入 task-suite/tasks/ 对应题目的 rounds/ 目录。
模型完成并归档上一轮后自动继续下一轮；按预置连续执行模式记录，不视为隐藏反馈盲测。
本包不给模型固定请求/迭代上限。平台存在实际时限时记录中断及当前质量，不标成完成。

## 评分与证据

各维度0–4：需求落实35%、视觉质量25%、文档与服务15%、视觉自检15%、可复现交付10%。
创意任务A13/A18可把需求25%、视觉25%、文档服务10%、自检15%、交付10%、创意15%；
A15复刻不因改成自己喜欢的风格加创意分。使用公开需求和 checklists/ 逐项验收，
不用检查点替代完整文字要求。不因调用多扣分，不因调用少加分；一次真实检查通过可以高分。

客观数据、数量、尺寸、计算、路径、布局边界和透明度先核对文件，再对照实际图。
字号以DSL+实际可读性检查；变换后外接框不能当成源几何尺寸。label-layout之类的
模型自报坐标不能独自证明图片正确，须对实际响应复核。普通矩形边界像素容差±1.5；
A15关键锚点±8；A22区域回归±2；alpha采样避开反走样边缘，RGB通道容差3。
语法成功不代表布局正确。声称读文档/看图必须由平台工具记录或实际证据支撑。
快捷检查仅作辅助，不能用模板字符串、日志行数或长报告替代质量判断。

请求记录区分文档/字体/渲染；完整视觉迭代有旧图查看、修改、真实再渲染、再次查看比较。
将语法修复、重试、方案探索、用户轮次另计。质量、首次结果、最终结果、消耗分别报告。
token/费用未知为null，不能要求模型估造。评测者复核渲染请求不计入模型任务消耗。

对开放题至少两名评审盲评图像，隐藏模型身份；技术说明只辅助核查。服务/字体/网络/
图像工具阻塞与模型错误分开，不强行计零。完整跨模型比较需冻结字体/指南/工具/服务配置，
重复运行并报告样本量与波动。24题是公开开发集，正式保留集应改文案/数据/布局且重新验证。
