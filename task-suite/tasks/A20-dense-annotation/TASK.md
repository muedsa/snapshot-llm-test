# A20 · 二十四密集点的无重叠标注

先完整阅读 [AGENTS.md](AGENTS.md) 的执行、目录、留痕和指标约定；该文件是本任务要求的一部分。

## 任务

制作1600×1100示意地图，inputs/markers.json 给24个点，x/y为0–100逻辑坐标，
原点左下，x向右/y向上。主图区固定左上(280,160)，宽1040、高760，映射到
像素时不要反转错误。点圆直径12，严格按位置映射，地图本体不含真实地理。
每点都显示编号、name、value，可在主图内或左右外侧排标签，但不移动锚点。
密集中心点不能相互遮挡，允许缩小该处点至8px并在审计记录；不能删点。
所有标签正文≥20、标签盒间距≥4px，与任何非本点主体不得覆盖。离点>24px
的标签必须用引导线明确连回；线不穿过标签文本、不得连接错点，允许至多
3处线与线交叉，交叉不画连接点。用弯折、分侧排序和层级减少歧义。
标注坐标轴、范围、单位“指数”及value最高3个点。主图完整，不把24标签另做一张
没有对应关系的列表替代。附 label-layout.json（原逻辑坐标、像素锚点、标签
盒和折线）及 layout-audit.json（标签交集、线穿标签、交叉数、边界检查）。
审计可用程序辅助，但必须放大查看指定中心6点M06、M08、M09、M10、M11、M12及引导线，再查看整体。

## 几何检查口径

像素锚点=(280+10.4×x, 920−7.6×y)。所有几何审计使用画布左上原点、x向右/y向下、
像素单位，不先对映射坐标取整。label-layout.json的标签盒为轴对齐外包矩形
[left,top,right,bottom]，覆盖全部文字、内边距及标签底板；不含引导线。
“离点>24px”指锚点圆心到该标签盒的最短欧氏距离，超过24才强制引导线；
不是到盒中心的距离。两标签盒的最短欧氏距离须≥4px，重叠时距离记0。
标签盒与任一非本点的实际圆盘不得相交或接触，按实际8px或12px直径检查。
自有标签也不得遮掉点主体或必需文字；引导线从所属圆周连到本标签盒边界，
不得进入任意标签盒内部，只允许终点接触自身盒边，不以文字之间的空隙绕过检查。

交叉数按不同引导线的中心折线计算：每一“线对+交点”计1，同一线对在同一点
由多个线段求出的交点去重；三条线在同一点相交按三对计3。不同引导线的端点
接触或端点落在另一线段上也计交叉；同一折线相邻线段的正常转角不计。
不允许折线自交或不同线之间出现正长度共线重合，不能把重合线算作一个交点。
计算使用1e-6像素数值容差处理共线与重复交点，保存未舍入坐标和交点线对；
线宽造成的视觉误连仍需看图排除。所有引导线描边不遮标签文字。
最高3个点按value降序取前三（若同值以ID升序定序），不按y坐标选择。
指定中心6点用于统一局部查看范围；其余18点同样接受全部几何规则检查。
