# A19 · 构造可核验的视觉题场

先完整阅读 [AGENTS.md](AGENTS.md) 的执行、目录、留痕和指标约定；该文件是本任务要求的一部分。

## 任务

你来构造一组新的视觉诊断材料，而非回答现成题。制作1600×1600的8×8网格
场景，64个带编号对象G01–G64，编号从左到右/从上到下；每格恰好一个主体。
4颜色（蓝/橙/绿/紫）、4形状（圆/方/圆环/圆角方）、3尺寸（48/64/80；圆按
直径、方按边长）交叉分布，4颜色与4形状各恰好16个，每行至少3颜色与3形状。
圆环外径按尺寸，内径为一半；ID在主体外，不计入主体。不得外部图像。
另构造一组800×800完整遮挡案例，包含A、B两个隐藏内容不同的版本；两版可见
部分完全相同，不能画虚线泄漏。分别交付occlusion与occlusion-alternative的
完整DSL和真实服务PNG。遮挡部分共两张PNG，加上网格图，指定最终图共三张。

为网格图写12道新题，覆盖复合属性检索、严格中心左右关系、距离、排序、
包围框、颜色/形状计数，至少4题需要两步关系；题目写明确比较标准、坐标原点，
不让关系并列导致唯一题多解。为遮挡图写2题，至少1题正确答案为“无法确定”。
交付 scene-data.json（种子与真实几何）、questions.json（题目不含答案）、
answers.json（答案、计算方法、坐标容差、可见性依据）与 equivalence.json
（两遮挡原始PNG哈希/像素对比）。编号≥18；题目只能根据最终可见图回答，
不能把隐藏对象数量作为标准答案。实际看图检查所有目标与标签。

## 属性覆盖与像素等价

64个对象须覆盖全部16种“颜色×形状”组合；每一种颜色和每一种形状都须出现
48、64、80三种尺寸。三种尺寸数量不要求相等，也不要求48种三属性组合全部出现。
原有颜色/形状各16个、每行至少3颜色与3形状的要求仍有效；scene-data.json列出
三类属性频数、组合覆盖和逐行计数，不能只记录随机种子而不记录实际生成结果。

两遮挡版须保持画布、可见前景、遮挡物、背景与渲染参数一致，隐藏内容的不同
在DSL及审计中指出，且其所有绘制影响（含阴影/滤镜）都被完全遮住。
equivalence.json记录两份原始PNG的SHA-256用于文件留痕；像素等价则以同一解码器
解码为8位未预乘RGBA后的逐像素四通道数组完全一致判定，尺寸也必须相同。
不同压缩或元数据导致文件哈希不同，不据此判像素不等价；不合成到白底、不缩放、
不忽略透明通道或透明像素的RGB。记录解码器/版本、不同像素数、最大通道差、
像素数组哈希及结论；不同像素数须为0。两份最终PNG均保留服务原始响应。
