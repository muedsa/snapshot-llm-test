# A08 · 展馆双路线导览与共享通道

先完整阅读 [AGENTS.md](AGENTS.md) 的执行、目录、留痕和指标约定；该文件是本任务要求的一部分。

## 任务

为首次到访“云构展馆”的观众制作一张1560×1080双路线导览图。观众可以选择
“直达出口”，或按顺序到达“结构剧场入口”和“作品巡览入口”后离馆。
两条路线应在同一张图上可独立追踪；展馆结构和路径由输入决定，不自行改造通道。

## 输入与空间语义

- inputs/floor.txt 是26列×16行的通道网格；inputs/legend.json 定义符号、名称、
  尺度及两条路线的必经点。#是墙体或非通行区；.及S/E/A/B/C/D均为可走格。
- S与E是外边界上的入口、出口门格。路径从S的格心开始，到E的格心结束，
  不计算图外路程。A–D是四个展区的入口点，不代表整个展区的面积或边界。
- 格坐标为从0开始的(x,y)，左上格为(0,0)，x向右、y向下。每格是边长2米的
  正方形；只允许上下左右跨相邻可走格，每次跨格为1步、2米。
- 转弯不另计代价；不计参观停留时间，不推算步行分钟数。未指定的展区可以经过，
  不要求依次参观全部四区。保留每个阻挡格与门洞，不增删通道。

## 路线计算

R1“直达出口”：S→E最短路线。
R2“主题参观”：按S→B→D→E顺序，各段取最短路线，再拼接为完整路线。
两条路线分别给出步数与米数，经过共享通道的路程仍计入各自路线。
当前输入经过作者校验：以上各段均有唯一最短解，完整路线无需折返或重复格。
若计算得到多解、断路或重复格，应先检查坐标、邻接与拼接，不擅自修改输入。
各段连接处只保留一次连接点；总步数是完整格心序列长度减1，不是格子数量。

## 导览图要求

1. 完整显示26×16网格、阻挡区、通道和两处边界门洞。地图的格子保持正方形，
   单格边长至少36像素；位置与配色自定，保留侧栏或其他清楚的说明区。
2. 显示标题、S/E名称、A–D入口名称、坐标边缘刻度、比例尺“1格=2米”、
   两条路线的名称/必经点顺序/步数/米数，以及阻挡区、入口点和路线图例。
   只在边缘标坐标，不要求每个格子写格号；不得凭空画出展区内部边界。
3. 路线至少用颜色加线型或符号两种方式区分。开始、分岔、合流与转弯后应有
   足够的方向提示，使人能从S沿指定路线一直追到E，不能只有无方向的色线。
4. 逻辑路径按格心序列计算。绘制时允许同中心线的宽底线/窄虚线组合，也允许
   平行偏移：相对逻辑中心线的横向偏移最多为单格边长的12%。
   无论采用哪种方式，描边和箭头都须处于对应可走格组成的区域内；不能为了
   分开路线而加宽门洞、改变实际路径或在转角抄近路穿入阻挡格。
5. 入馆段和离馆段均有共享通道。每段中两条路线的身份、方向与接续关系均须
   可辨；只在图例里画出两种样式、在共享段却完全盖住一条路线，不算满足。
6. S/E/A–D标记固定在对应格心，文字可移到附近或说明区并用引导线对应。
   小型地标标记可局部遮住经过它的路线，但两侧须能接续追踪；文字不得被路线
   或箭头覆盖，不能为避让文字移动地标、墙体或路径。
7. 正文与展区名称字号≥22，图例≥20，边缘坐标≥16。实际查看整图，并放大
   检查两个共享段、分岔/合流、门洞与地标附近。无需把技术审计内容堆进导览图。

## 路径与绘制审计

交付paths.json，参考templates/paths-template.json。记录：
- 输入网格尺寸、每格米数及S/E/A–D的格坐标；
- 地图左上外边界的像素坐标、单格像素边长，以及路线样式与实际偏移量；
- 两条路线的完整格心序列、必经点、分段序列、各段及全程步数/米数；
- 两段共享通道的格心序列、两条路线的行进方向和实际绘制方式；
- 可走性、四邻接、必经点顺序、最短性、无重复格、距离和绘制对应关系的检查方法
  与结果。不能只填true而没有计算依据；路径数据还须与实际服务图片核对。

格(x,y)的画布中心为(origin_x+(x+0.5)×cell_px, origin_y+(y+0.5)×cell_px)。
路线长度依据逻辑格间边计算，不按描边偏移后的像素长度估算。模板只解释字段，
不是已完成证据；最终删除field_guide等说明字段并填入实际数据。
